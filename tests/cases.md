# 端到端用例（读取本 skill 后逐条试跑，对照合格标准）

| 编号 | 输入 | 合格标准 |
|---|---|---|
| A | 苏云图生视频 8 秒对话镜头（图1 外貌，L2） | 四段齐全且顺序正确（主体 / 场景 / 风格 / 情节，不出现概述段与结尾标题），最后一行是固定句“全片不添加BGM，不添加字幕。”且末尾只有这一行；对白用引号或 {}；默认不写自写否定，必要的写在镜内并逐句点名；不主动等确认，一轮交付表头 + 完整提示词 + 一行检查；表头只写有内容的行 |
| A0 | 极简 L1 请求（无抽象词、无复杂运镜、无素材） | 不等确认；表头全空就不写；不硬凑升级方向；提示词后无例外说明、只有一行检查 |
| A7 | 三镜完整稿，资料充分 | 一轮交付；顺序、总时长、终态准确；镜头表不展示 |
| A8 | 同一三镜，用户说"先看分镜" | 只交表头 + 镜头表并等确认；不成文 |
| A2 | "要一个很有压迫感、高级感的镜头" | 两个抽象词都落成可见画面（低角度 + 前景阴影 / 剪影或微距等），表头"翻译"行记录两个词各自的可见句 |
| A3 | "人不动、背景挤过来那种效果叫什么" | 直答滑动变焦（希区柯克变焦），给可见效果、一句可用中文和理解度"热门"；不写整条提示词 |
| A4 | 三镜，第 2 镜苏云特写、白猿在画外 | 第 2 镜不出现白猿本体，不写全身与场景，不重演第 1 镜动作；画外只用视线或声音线索 |
| A5 | 草稿里一镜用三句描述同一运镜 | 压缩成"术语 + 半句可见结果"（任何理解度都留这半句；未试的这半句点名作用对象和看得见的变化，需解释的写五项）；起点已由上一拍画框写过的不重写 |
| A6 | 把 0916 一条旧提示词按最近案例重写 | 素材映射在主体段最前，不写总览句、不设概述段，跨镜的身份与数量写进主体段，主体段不写动作、随动与背景路线；关键动作只写部位做到哪与结果，不写发力过程；默认不写否定句（必要的写进它管的那一镜并逐句点名）；check_prompt 通过 |
| B | 烛龙打斗 L3 三镜 | 每镜攻防成对、接触后果、运镜起终点；跨镜状态写成现状句；用到词库力度词；特效有来源与退出；力度没有退化成"激烈"，特效没有退化成"震撼"，在最终正文能找到所选机制 |
| B2 | 无人物的纯特效 | 来源、路径、接触或范围、退出与残留在正文可定位；不加表情、对白、对手 |
| C | 输入「自检」 | 三部分输出；综合表六维度按需合并；先跑 check_prompt |
| D | 对 0916 某条成片做诊断 | 抽帧拼图可看；逐句兑现表；三类归因；给出一条新观察（置信度"未试"）；只有授权时才写入 lessons |
| E | 改现有提示词：只改第 2 镜运镜（旧四段外壳） | 只交付第 2 镜（或受影响序列），说明替换父稿哪一段；沿用旧外壳不迁移；台词与其他镜头逐字不变；不加转头转身；用 `--task 生成 --baseline 父稿 --partial` 检查；不先给表等确认 |
| E2 | 合法对白含"上次"，并请求自检 | 不报引用性措辞；自检只报告不改稿 |
| G | 反馈"第 2 镜不要苏云回头" | 找到引出回头的原句删掉，写成正向状态（目光停在门口）；提示词里没有"上一版 / 上次 / 不要像"；禁止项条数不比上一版多；check_prompt 通过 |
| F | 向后延长 视频1 5 秒 | 四段外壳；情节段开头的命令区（第一个镜头标题之前）有"向后延长视频1"与官方约束句，末尾只有固定句那一行；情节从尾帧状态起、只写新增段；check_prompt 通过 |
| H1 | 新稿 + 用户给了一句必须逐字出现的对白（"我不走。"） | 对白逐字在正文，`--lock` 通过；表头"锁定"行写出这句台词；严格审时：requirements 的 exact_locks 收录原句，若做了同音替换则 pronunciation 有完整逐字映射、原台词保留在需求里 |
| H2 | 近景对话镜，但用户要求看到"他一脚踩住对方的鞋尖" | 发现可见性冲突（近景装不下脚部接触）并只在这一处锁定冲突上集中问一次，给两种改法（扩景别 / 拆一镜给脚部）让用户选；不自作主张改掉用户锁定的景别，也不假装两件事都拍到了 |
| H3 | 复杂打斗 + 特效 + 镜内光源变化的三镜稿 | **默认走轻量路径**（复杂度和"第一版"都不触发全套）：头脑里做完六域与矛盾核对，跑一次 `check_prompt.py --report` 就交付，不建 requirements.json、不派复核。**用户说了"严格审"才走全套**：complex=true；独立复核在新上下文做**一次**（Claude Code 用 Agent 子代理 / Codex 新会话），independent.json 有 context 且 saw_author_review=false、reviewer≠author；作者不得自己换个名字补一份；复核后的修复由作者完成，改动点交回**同一个复核者**（Claude Code 用 SendMessage 续用同一子代理 / Codex 同一会话）只核验修复点及其关联影响，由它出具绑定最终正文哈希的新 independent.json，再重跑 verify_delivery；核验修复时只有"没修好"和"修复引入新矛盾"两类进 unresolved，其它新发现写 suggestions、不阻断放行；不做第二次全量复核，作者不得自己改写复核记录的哈希或结论；同一稿之后的修改回到轻量路径 |
| H4 | 镜头环绕人物一圈，场景里有一盏固定的壁灯 | 光源按世界方位锁定（固定在人物斜后方、不随镜头移动），另写它在画面里随环绕从哪侧移到哪侧（L061）；不写"光从画面左侧射来"这类会随镜头转的画面方位断言 |
| H5 | 用户明说"这镜就要一动不动的静止画面" | 不为满足默认偏好偷加微推、微摇或呼吸感；正文不出现"极其缓慢、几乎不可察觉"这类冒充运镜的措辞；严格审时：camera 该镜 mode=fixed 且 source 引用用户原话 |
| H6 | 五镜父稿，只改第 2、4 镜的运镜，其余不动 | 用 --task 生成 --baseline 父稿 --partial --unchanged 1,3,5；只交付第 2、4 镜完整单元；未受影响镜头逐字不变；严格审时：camera 数组仍覆盖合成完整稿全部五镜，未改的两镜写 mode=preserved 并引用父稿 |
| H7 | 用户要直接成稿，但没说清 图2 是人物还是场景，也没上传该图 | 读不到的素材标 status=missing，不猜职责、不编造图里的内容；不放行成"已验收稿"，而是保留待验证候选并把缺项写清楚；缺的是必要事实时集中问一次 |
| H8 | 新稿，作者认为还必须写几条否定（自写预算 0 条） | 能改成正向的先搬走；真正改不了的写进它管的那一镜的正文（不放末尾），用 --negative-exception 逐句点名（"；"分开，每句与镜内那句整句一致，点名了却找不到会报错），且 requirements.negative_exception 里每句有 sentence + reason；用户明确锁定的排除项走 --lock，不提醒；不能只写"质量需要" |
| H9 | 单镜 3 秒里要求"抬手、握住、拧开、抽回"四个动作 | 按用户实测线索判断（L064，不是通过保证）：3 秒 4 个节拍平均 0.75 秒，可以不因密度自动拆镜，但仍按动作依赖与可读性判断——模型加速可能牺牲可读性或漏动作，必须看清的那个动作单独给时间；脚本只在平均 ≤0.5 秒/拍（每秒 2 拍以上）时提醒 |
| I1 | 新稿：灯笼怪 6 秒一镜，原地拧身后把人头扔向镜头 | 每镜内部先定关键事件（松手、人头冲镜头）；松手那一拍在有光处，不和整幅遮挡或大运镜同一瞬；每拍只写镜头、画框切线、主事与终态；发力只写结果（越转越快、袖子被甩平），不出现先转肩、再转胯、引到最后；雨水写场景段一句；主体段只写是谁、长什么样、有几个（不写倒提、磕牙、衣物随动、冤魂在飞）；冤魂的路线写进它在这一镜第一次出现的那一拍（不写进场景段），后面的拍只在它贴镜掠过这类画面事件里再写；衣物随动只在是关键动作的可见结果时写（袖子被甩平）；不写连续镜头锁和“任何时刻”这类总括句；check_prompt 没有“关键动作紧挨整幅遮挡”“发力过程写法”、主体段动作、场景段角色活动、总括保证句提醒 |
| I2 | 把一份书面腔一镜稿（"镜头缓缓向后拉开，逐渐展现出……营造出……氛围"）改成讲戏口吻 | 内容不变只换说法：术语后紧跟半句看得见的结果（景别、机位用画框切线），位置用画面坐标，空间理由每镜最多一句，镜内没有"摄影：/动作：/第一拍"，不写总览句；check_prompt 没有"镜内标签""画质词""空词"提醒；带父稿检查时去空白字数不增加、父稿句子没有被报消失 |
| I3 | 新稿：全片一镜到底 6 秒，中途大幅后拉、人头飞出画面 | 不写“全片是一个不断开的连续镜头，某某任何时刻都至少有一部分留在画面里”；“一镜到底”只作风格段镜头性格或镜头1第一句；每一拍写清画里有谁，没有哪一拍只剩空景（人头出画那一拍写清画里还留着灯笼怪）；数量锁“全片只有一颗人头”可留在主体段；check_prompt 没有总括保证句提醒 |
