# 即梦 Seedance 2.5 操作类任务

> 用于路由表"操作类"任务：延长、编辑、无缝衔接、首尾帧、关键帧、宫格、白模、绿幕、一键成片、超长模式。读第 0.5 节和本次任务对应的一节。
> 读完必须产出：一条使用官方必填词汇、写清母版职责与保持内容的完整操作命令。
> 经验的证据与采用规则以 `lessons/README.md` 为唯一准则：分清"试过的"和"没试过的"，没试过的照常可用但不冒称已验证；经验不能覆盖用户锁定项或已确认事实。

## 0 任务锁定与触发词

素材一律写 `图N`、`视频N`、`音频N`，**提示词里不写 @**（粘进即梦以后在软件里再 @ 出来）；修订旧稿时沿用旧稿的写法。

| 任务 | 必须出现的词 | 平台锁定 | 指代方式 |
|---|---|---|---|
| 延长 | 向前延长 / 向后延长 / 延续 / 续写 | 锁宽高比，时长可设 | 直接写 `视频1`，不写"参考视频1" |
| 编辑 | 编辑视频里的xx / 增加、加上 / 删除、去掉 / 修改、替换、改成 | 锁画幅与时长（可差 ≤0.3 秒） | 同上 |
| 首帧 / 首尾帧 | 图1为首帧（图2为尾帧） | 锁首帧画幅 | — |
| 参考 / 关键帧 / 宫格 / 白模 / 无缝转场 | 参考视频1的…… | 不锁 | 参考类才写"参考" |
| 组合 | 参考图1的<维度>，编辑视频1，<改动> | 按编辑 | 参考件与被改件分开写 |

编辑和延长直接用 `视频1` 指代母版；写成"参考视频1"会被判为参考任务。

## 0.5 四段外壳怎么装操作类

所有操作类命令和生成类一样用 `主体：场景：风格：情节：` 四段，**不设概述段，也不设结尾标题**。**官方必填句全部放在情节段开头的命令区**——写在 `情节：` 之下、第一个镜头标题之前：必填词 + `视频N` + 官方约束句 + 保持内容与契约句，都写进那一句（或那两三句）命令句里。**操作类的视频就在这句命令句里绑定一次职责**（母版负责什么、不采用什么），别在主体段再写一遍；人物与物件图和音频绑在主体段，场景图绑在场景段，材质光影画风参考图绑在风格段，同一素材只绑一次。**末尾只有固定句 `全片不添加BGM，不添加字幕。` 那一行**，它上面一行必须是普通正文（最后一镜的内容）；必填句写到末尾固定句之前，`check_prompt.py` 会报错"操作命令的必填句写在情节段开头的命令区，末尾只留固定句"。确有必要的否定句写进它管的那一镜的正文，不放末尾。

**修订旧壳时例外**：父稿是六段的，修订仍交付六段、必填词仍写在概述段、固定句仍是旧句“不添加字幕，不添加背景音乐。”；父稿是五段的，修订仍交付五段、固定句仍在结尾段（检查时给 `--baseline` 父稿，默认 `--format 继承`），不为通过检查迁移格式。

| 任务 | 主体（人物与物件图、音频） | 情节段开头的命令区（**全部必填句与视频职责都在这里**） | 场景 / 风格 | 情节（命令区之后的镜头） | 末尾 |
|---|---|---|---|---|---|
| 向后延长 | 人物与物件图的职责 + 人物造型 | `向后延长视频1，新增 N 秒：<事件>` + `视频1是需要向后延长的原视频，负责……的延长边界` + 连续项 + 官方约束句`要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。` | 场景图绑在场景段、承接尾帧的时间地点光源不变 / 风格段只写延续下来的画风、材质与镜头性格 | `镜头1（0-N秒）：` 第一个画面直接承接尾帧状态 → 新事件 → 结束状态 | 只有固定句那一行 |
| 向前延长 | 同上 | `向前延长视频1，新增 N 秒：<原视频开始之前的事>` + 母版职责 + 官方约束句 + "只在原视频开始后才出现的素材不在此段提前出现" | 同上 | 最后一帧收束到视频1首帧的位置、朝向、动作阶段、光线、机位 | 只有固定句那一行 |
| 编辑 | 目标素材职责（新衣服、新道具的图） | `编辑视频1，在 a-b 秒把 X 替换为 Y`（或增加 / 删除）+ `视频1是唯一编辑母版，负责……` + `保持……不变` + 目标对象数量 | 保持视频1的环境与光线不变 / 保持画风景别运镜不变 | `镜头1（a-b秒）：` 只写编辑范围与时序，改动如何跟随原动作 | 只有固定句那一行 |
| 白模预演 | 颜色到人物的映射 + 人物图职责 | `参考视频1的<站位、动线、运镜、切镜>，不采用其中的白模外观和场景，生成……` + "沿用视频1的镜头顺序、切点与节奏，不新增镜头或转场" + 粗模契约句 + 一致性句 | 场景图绑在场景段 / 风格段只写画风与材质质感 | `镜头1：` `镜头2：` 不写秒数（白模拥有时长） | 只有固定句那一行 |
| 首尾帧 / 关键帧 | `图1作为首帧……图2作为尾帧……` + 其他人物物件素材 | 从首帧到尾帧的一个连续动作 + "画面从首帧自然开始，经过连续动作后到达尾帧" | 首尾之间不变的环境 / 画风 | `镜头1：` 过程 | 只有固定句那一行 |
| 无缝转场 | 两段里主体的固定短名与外貌短语 | `将视频1和视频2无缝衔接：<触发动作>，不修改视频1和视频2` + 两段各自负责哪一头 | 两段共有的环境 / 画风 | `镜头1：` 触发 → 镜头运动 → 画面变形 → 到达状态 | 只有固定句那一行 |

表里没有的宫格、绿幕、一键成片同样套四段：模板里的“最终画面采用<风格>”写进风格段，“保持角色一致性”这类保持句写进命令区，宫格分镜图作为操作类参考在命令区绑定一次（首帧、尾帧图按上表在主体段）；模板里的“无 bgm”删掉，固定句已经管了。

向后延长示例：
```
主体：图1用于苏云的外貌与服装，不采用图片背景。
场景：承接视频1尾帧的时间、地点、光源方向和天气，不变。
风格：延续视频1的画风与材质质感，长焦浅景深，平稳的手持呼吸感。
情节：

镜头1（0-5秒）：延长片段的第一个画面直接承接视频1的尾帧，苏云仍向画面左侧行进、右脚刚落地、机位平行跟随。随后他停下脚步，眼神变得锐利，双手横棍摆出防御姿态，紧紧盯着画面左侧外。结束时他站定，棍尖指向左侧。
全片不添加BGM，不添加字幕。
```

```
主体：图1用于新上衣的颜色、剪裁与材质。
```

## 1 视频延长

必填词之后加官方约束句：**要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。**

下面是官方原句模板，取句子用；成文时按第 0.5 节装进四段，官方约束句落在情节段开头的命令区，末尾只留固定句，不照抄成无标题的一段。
向后延长模板：
```
视频1是需要向后延长的原视频。向后延长视频1，新增 5 秒。延长片段的第一个画面直接承接视频1的尾帧：保持<主体姿态与朝向>、<道具位置>、<机位与构图>、<光线>、<声音状态>和<运动趋势>连续。随后，<新动作、事件、镜头或声音>。延长过程中保持<人物身份与服装>、<关键道具>、<背景布局>、<摄影轴线>连续；同一主体始终是同一个连续对象，不重复、不分裂。要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。全片不添加BGM，不添加字幕。
```
向前延长：先写原视频开始之前发生的事，再把原视频首帧写成延长片段的明确结束状态。只写"随后承接原视频"会让模型提前引入后续人物或特效；只在原视频开始后才出现的素材不能提前出现。

一镜到底还是切镜：同一动作、对白、情绪、路径用一镜到底延长；换场景、换时间、换主要动作或视点用切镜延长：
```
切镜设定 = 需要在切镜处使用"X转场"（禁止生硬切镜、禁止物体凭空出现）+ 保持镜头呼吸感与时长协调，镜头A展现……随后自然过渡到镜头B…… + 要求必须自然切换场景，并且景别由C转变为D。
```
也可写"请从自然镜头切换 / 遮罩转场 / 水墨转场 / 相似物转场中根据本片风格选择最合适的一种"。

官方 11 种转场（名称：写法）：
- 自然镜头切换：A 直接变 B，强调镜头呼吸感、时长协调，留出切换时间
- 淡入淡出：A 逐渐变暗至全黑（或全白），B 从黑或白中浮现
- 叠化：A 缓慢变透明的同时 B 显现，1 到 2 秒柔和重叠
- 白闪 / 黑闪：瞬间白光（或全黑）一闪而过，极速切入 B，配合重音
- 擦除：B 像推拉门从某方向平滑推进覆盖 A
- 遮罩转场：镜头推进，被某物完全遮挡至全屏变黑，随后穿过黑暗拉开显现新场景
- 相似物转场：A 末帧与 B 首帧形状轮廓颜色极似，无缝过渡（圆月淡化成酒碗）
- 动作转场：A 猛烈甩动产生运动模糊，B 顺同方向从模糊中切入定格
- 动态接力转场：人物在 A 跳出画框，在 B 从画框上方落入
- 拉近 / 拉远转场：极致放大 A 的某细节（瞳孔、锁孔），细节内展开 B 全貌
- 水墨转场：A 像浓墨滴入水中晕开，B 从墨迹中浮现

官方案例：
> 参考@视频1的内容，延长视频5s向后延长。要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现。@图1壮汉战士突然察觉到异样，停下脚步，眼神变得锐利。他迅速摆出防御姿态，紧紧盯着前方。
> 参考@视频1的内容，延长视频10s延长续写。要求需要在切镜处使用"遮罩转场"转场（禁止生硬切镜、禁止物体凭空出现）。镜头A展示正在防御的@图1壮汉战士（近景），一阵风吹过，一片正常大小的落叶飘向镜头，树叶完全遮挡镜头导致全屏变暗；随后镜头穿过树叶拉开，直接显现出下一个场景：@图2的年轻游侠正靠在一棵树旁边，正举起弓箭瞄准。要求必须自然切换场景。由战士的近景自然切换为游侠的中景。
> 在@视频1的基础上续写5秒的视频，讲一只蜜蜂飞来落在画上，接着微距特写……（输出格式选 MOV）

已知：延长只对新增段生效，原片不重生成。底片 ≤30 秒，单次 4 到 30 秒，最长 60 秒。拼接处跳变时后期对齐：前段末尾删 6 帧、后段开头删 1 帧；续写段以切镜时刻结尾更稳。多次续写画质劣化（人脸出斑驳色块）：先把底片转白模再续写，控制次数。

## 2 视频编辑

常规公式：`[修改对象] + [动作与变化] + [生效时序]`。例："在视频的1-8秒，把男生的牛仔裤替换为深黑色的西装裤"。
高级编辑（圈选、画笔、箭头、定位点）：`[标注工具与方位] + [对象] + [变化] + [时序]`。方位如"红框内""沿红色箭头指向的区域""红线左侧"；时序如"全片统一修改""仅在第5-8秒发生""从第3秒起逐渐显现"。

官方模板（取句子用，成文按第 0.5 节装进本 Skill 的四段：编辑目标、唯一编辑母版声明与保持内容 → 情节段开头的命令区，原视频与目标素材职责 → 主体，环境与画风的保持句 → 场景、风格，编辑范围 → 情节里的镜头；末尾只留固定句）：
```
【编辑目标】编辑视频1，在<全片或时间段>对<对象、区域或声音类别>进行<增加 / 移除 / 替换 / 调整>。
【原视频职责】视频1是唯一编辑母版，负责人物、场景、动作、构图、镜头、遮挡关系、声音和事件顺序。
【目标素材职责】图1用于<指定属性>。
【编辑范围】只处理<……>。
【保持内容】保持视频1中的<身份、动作、机位、光线、声音>不变。
```
- 主体替换加"全片目标对象数量为 N"与时间线继承："目标对象继承原对象每次出现、运动、遮挡和离开的时点、时长、路径与速度"。
- 背景替换："只修改主体轮廓之外的背景区域，不修改主体身份、五官、发型、服装、表情、位置、大小和动作。"
- 移除后补全："原本被遮挡的地毯、墙面需要自然补全，不留残影、模糊补丁。"
- 视角修改："将视频1改为从右侧人物背后偏上方45度俯拍。保持两人的身份、服装、坐姿、动作节奏和桌面物体位置不变，合理补全新视角下的肩背、头顶轮廓与背景延展。""把第三人称视角修改为第一人称视角。" 不把固定机位和跟拍写在一起。
- 去 BGM："编辑视频1，只移除原有背景音乐，保留人物对白、口型、环境声和动作音效；画面内容、镜头和剪辑节奏保持不变。" 不写"移除所有声音"，除非用户要静音。
- 音频编辑："将视频中的人声台词翻译成中文，无字幕，口型做出对应的精准改变，其余均保持不变。"
- 绿幕化："把整个视频0-5秒的白色背景都变成绿幕背景。去掉声音，保持静音。"

官方案例：
> 将@视频1中的时间改为月夜，光影变为月光，将@视频1中跳舞的人变为@图片1，画面要有月光笼罩的那种朦胧感，严格保持原视频的景别、运镜。全片都做出指令要求的改变。
> 移除@视频1男孩胸前的蓝色耳机，将男孩脚边的足球替换成一个橙色篮球，在长椅右边增加一只安静坐着的小白狗，小狗偶尔轻微转头，其他与原视频保持一致。

## 7 无缝转场（两段视频）

顺序：转场前视频 → 转场后视频 → 触发动作 → 镜头运动 → 画面变形 → 到达状态 → 声音。五种方式：俯冲或折返、人物旋转、前景遮挡、物体变形、推拉或焦点变化。
```
将视频1和视频2无缝衔接起来，不修改视频1和视频2。视频1尾帧的<主体>开始<触发动作>，镜头<运动>，<画面变形过程>，最终到达视频2首帧的<构图与状态>，<声音>过渡为<声音>。
```
官方案例：
> 将【@视频1】和【@视频2】无缝衔接起来，但是不修改【@视频1】和【@视频2】。视频1尾帧的鲤鱼开始快速向前游，然后快速跃出水面升向空中……最终成功化龙衔接上视频2。
> 将【视频1】和【视频2】衔接起来，【视频1】的视角急需飞行至顶端快速折返，视角垂直向下俯冲，然后无缝自然地衔接转场到【视频2】，在镜头切换的过程中麻将牌慢慢变成高楼……同时不要改变上传的两个视频。
无缝转场不代表两段原视频逐像素不变。三段以上分成两两衔接。

## 9 超长视频（30 到 180 秒）

完整提示词 = 【全局参数】（开头再次强调时长与画幅）+【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】。这是官方的信息顺序，不是本 Skill 的标题或段落清单；倒进当前四段时不保留概述句，把其中的身份与数量、时长、跨段的位置与道具状态、风格控制分别归入主体、镜头标题、各段开场现状和风格段。收尾的禁止项先改成正向句分配到所属段落，改不掉的写进它管的镜头，末尾只留固定句、也不另起 `结尾：`。官方案例全部是连续段落："0-6 秒，极远景，清晨的荒原被薄雾覆盖……以车轮碾过碎石的声音切入下一镜。6-13 秒，低机位近景……"；60 秒咖啡馆案例每段末尾附反向描述"镜头不要晃动，不要有人物入镜，禁止生硬切镜"——倒进本 Skill 时这类句子先改成正向的运镜与在场描述，改不掉的留在它所属那一段的正文里，不集中堆到末尾。按故事节拍分段，不平均切；跨段的身份与数量锁放主体段一次，不把人物外貌复制进每段。

## 10 音色、多语种与文字

- 音色参考在主体段绑定一次（`苏云的台词音色参考音频1，保持低沉悬疑的语调`），台词里只用短名（“苏云说”）；官方案例每句台词后写“音色参考@音频N”，只作背景，不作推荐写法。音色不准时，在主体段那句绑定里补特征：`苏云的台词音色参考音频1：低厚温润、带细碎颗粒感的中年男声`，台词里仍只写“苏云说”。
- 多语种：直接写目标语言台词，口型"必须完美匹配这句印尼语台词的发音"；画面文字"全部为自然规范的日文，不出现任何中文、英文或乱码"（韩文仍有错别字）。
- 迁移创意：点名要参考的 `视频N` 并描述要迁移的内核（可爱状态、喜剧效果、镜头节奏、转场方式）。
- 特效不准时用参考视频定义："数字'2999'出场方式参考视频1"。
