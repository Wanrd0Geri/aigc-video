# 即梦 Seedance 2.5 操作类任务

> 用于路由表"操作类"任务：延长、编辑、无缝衔接、首尾帧、关键帧、宫格、白模、绿幕、一键成片、超长模式。只读本次任务对应的一节。
> 读完必须产出：一条使用官方必填词汇、写清母版职责与保持内容的完整操作命令。
> 经验的证据与采用规则以 `lessons/README.md` 为唯一准则：分清"试过的"和"没试过的"，没试过的照常可用但不冒称已验证；经验不能覆盖用户锁定项或已确认事实。

## 0 任务锁定与触发词

| 任务 | 必须出现的词 | 平台锁定 | 指代方式 |
|---|---|---|---|
| 延长 | 向前延长 / 向后延长 / 延续 / 续写 | 锁宽高比，时长可设 | 直接写 `@视频1`，不写"参考@视频1" |
| 编辑 | 编辑视频里的xx / 增加、加上 / 删除、去掉 / 修改、替换、改成 | 锁画幅与时长（可差 ≤0.3 秒） | 同上 |
| 首帧 / 首尾帧 | 图片1为首帧（图片2为尾帧） | 锁首帧画幅 | — |
| 参考 / 关键帧 / 宫格 / 白模 / 无缝转场 | 参考@视频1的…… | 不锁 | 参考类才写"参考" |
| 组合 | 参考@图片1的<维度>，编辑@视频1，<改动> | 按编辑 | 参考件与被改件分开写 |

编辑和延长直接用 `@视频1` 指代母版；写成"参考@视频1"会被判为参考任务。

## 0.5 五段外壳怎么装操作类

所有操作类命令和生成类一样用 `主体：场景：风格：情节：结尾：` 五段，**不设概述段**。官方必填词放**情节段开头**——写在 `情节：` 之下、第一个镜头标题之前的那一句命令句；官方约束句与保持内容放结尾段，原视频的职责放主体段最前。

**修订六段旧稿时例外**：父稿是六段的，修订仍交付六段，必填词仍写在概述段（检查时给 `--baseline` 父稿，默认 `--format 继承`），不为通过检查迁移格式。

| 任务 | 主体 | 命令句（必填词在这里，写在情节段开头） | 场景 / 风格 | 情节（命令句之后的镜头） | 结尾 |
|---|---|---|---|---|---|
| 向后延长 | `@视频1是需要向后延长的原视频，负责……的延长边界` + 其他素材职责 | `向后延长@视频1，新增 N 秒：<事件>` | 承接尾帧的时间地点光源不变 / 延续原画风与镜头语言 | `镜头1（0-N秒）：` 第一个画面直接承接尾帧状态 → 新事件 → 结束状态 | 官方约束句 + 连续项 + 固定句 |
| 向前延长 | 同上 | `向前延长@视频1，新增 N 秒：<原视频开始之前的事>` | 同上 | 最后一帧收束到@视频1首帧的位置、朝向、动作阶段、光线、机位 | 约束句 + "只在原视频开始后才出现的素材不在此段提前出现" |
| 编辑 | `@视频1是唯一编辑母版，负责……` + 目标素材职责 | `编辑@视频1，在 a-b 秒把 X 替换为 Y`（或增加 / 删除） | 保持@视频1的环境与光线不变 / 保持画风景别运镜不变 | `镜头1（a-b秒）：` 只写编辑范围与时序，改动如何跟随原动作 | 保持内容 + 目标对象数量 + 固定句 |
| 白模预演 | 白模参考声明 + 颜色到人物的映射 + 场景图 | `参考@视频1的<站位、动线、运镜、切镜>，生成……` | 场景图或文字场景 / 画风 + "沿用@视频1的镜头顺序、切点与节奏，不新增镜头或转场" | `镜头1：` `镜头2：` 不写秒数（白模拥有时长） | 粗模契约句 + 一致性 + 固定句 |
| 首尾帧 / 关键帧 | `@图片1作为首帧……@图片2作为尾帧……` + 其他素材 | 从首帧到尾帧的一个连续动作 | 首尾之间不变的环境 / 画风 | `镜头1：` 过程 | "画面从首帧自然开始，经过连续动作后到达尾帧" + 固定句 |
| 无缝转场 | `@视频1 @视频2 的职责，不修改两段` | `将@视频1和@视频2无缝衔接：<触发动作>` | 两段共有的环境 / 画风 | `镜头1：` 触发 → 镜头运动 → 画面变形 → 到达状态 | "不修改@视频1和@视频2" + 固定句 |

向后延长示例：
```
主体：@视频1是需要向后延长的原视频，负责苏云的身份、服装、场景、机位与声音的延长边界。@图片1用于苏云的外貌与服装，不采用图片背景。
场景：承接@视频1尾帧的时间、地点、光源方向和天气，不变。
风格：延续@视频1的画风、景别习惯与镜头语言。
情节：
向后延长@视频1，新增 5 秒：苏云察觉异样停下脚步，摆出防御姿态。
镜头1（0-5秒）：延长片段的第一个画面直接承接@视频1的尾帧，苏云仍向画面左侧行进、右脚刚落地、机位平行跟随。随后他停下脚步，眼神变得锐利，双手横棍摆出防御姿态，紧紧盯着画面左侧外。结束时他站定，棍尖指向左侧。
结尾：要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。保持苏云的身份、服装、长棍归属和机位关系连续，同一主体始终是同一个连续对象。不添加字幕，不添加背景音乐。
```
编辑示例：
```
主体：@视频1是唯一编辑母版，负责人物、场景、动作、构图、镜头、遮挡关系、声音和事件顺序。@图片1用于新上衣的颜色、剪裁与材质。
场景：保持@视频1的环境与光线不变。
风格：保持@视频1的画风、景别与运镜不变。
情节：
编辑@视频1，在 2-8 秒把苏云的灰布上衣替换为@图片1中的服装。
镜头1（2-8秒）：只替换苏云上衣的颜色、剪裁与材质，新衣服跟随原有动作保持褶皱与受光；2 秒之前和 8 秒之后保持原样。
结尾：保持苏云的身份、面部、动作、机位与声音不变；全片目标对象数量为一件上衣。不添加字幕，不添加背景音乐。
```
白模预演示例：
```
主体：@视频1是粗颗粒度白模参考，仅提供人物站位、移动路线、运镜与切镜，不采用其中的白模外观和场景。@视频1中的黄色模型对应@图片1中的苏云，蓝色模型对应@图片2中的罗大娘。@图片3用于竹林山路的地形与晨雾。
场景：清晨竹林山路，晨雾未散，侧逆光。
风格：3D 国风漫画 CG 风格；沿用@视频1的镜头顺序、切点与节奏，不新增镜头或转场。
情节：
参考@视频1的站位、动线、运镜和切镜，生成苏云与罗大娘在竹林山路相遇的预演视频。
镜头1：全景，苏云从画面深处沿山路走来，竹背篓随步伐轻晃，晨雾在竹林间缓慢流动；罗大娘在画面右侧前景背对镜头站着，围裙下摆被风掀起一角。
镜头2：切双人中景，苏云停在罗大娘一步之外，两人相隔一臂对视，他的呼吸在冷空气里凝成白雾，她鬓角的碎发随风微动。
结尾：不要求逐帧复刻，由模型补全关键状态之间的运动过程，保持需要延续的画面元素在切点前后状态一致。保持角色一致性，不穿模不变脸。不添加字幕，不添加背景音乐。
```

## 1 视频延长

必填词之后加官方约束句：**要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。**

下面是官方原句模板，取句子用；成文时按第 0.5 节装进五段，不照抄成无标题的一段。
向后延长模板：
```
@视频1是需要向后延长的原视频。向后延长@视频1，新增 5 秒。延长片段的第一个画面直接承接@视频1的尾帧：保持<主体姿态与朝向>、<道具位置>、<机位与构图>、<光线>、<声音状态>和<运动趋势>连续。随后，<新动作、事件、镜头或声音>。延长过程中保持<人物身份与服装>、<关键道具>、<背景布局>、<摄影轴线>连续；同一主体始终是同一个连续对象，不重复、不分裂。要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。不添加字幕，不添加背景音乐。
```
向前延长：先写原视频开始之前发生的事，再把原视频首帧写成延长片段的明确结束状态。只写"随后承接原视频"会让模型提前引入后续人物或特效；只在原视频开始后才出现的素材不能提前出现。

一镜到底还是切镜：同一动作、对白、情绪、路径用一镜到底延长；换场景、换时间、换主要动作或视点用切镜延长：
```
切镜设定 = 需要在切镜处使用"X转场"（禁止生硬切镜、禁止物体凭空出现）+ 保持镜头呼吸感与时长协调，镜头A展现……随后自然过渡到镜头B…… + 要求必须自然切换场景，并且景别由C转变为D。
```
也可写"请从自然镜头切换 / 遮罩转场 / 水墨转场 / 相似物转场中根据本片风格选择最合适的一种"。

官方 11 种转场（名称：写法）：
- 自然镜头切换：A 直接变 B，强调镜头呼吸感、时长协调，留出切换时间
- 淡入淡出：A 逐渐变暗至全黑（或全白），B 从黑或白中浮现
- 叠化：A 缓慢变透明的同时 B 显现，1 到 2 秒柔和重叠
- 白闪 / 黑闪：瞬间白光（或全黑）一闪而过，极速切入 B，配合重音
- 擦除：B 像推拉门从某方向平滑推进覆盖 A
- 遮罩转场：镜头推进，被某物完全遮挡至全屏变黑，随后穿过黑暗拉开显现新场景
- 相似物转场：A 末帧与 B 首帧形状轮廓颜色极似，无缝过渡（圆月淡化成酒碗）
- 动作转场：A 猛烈甩动产生运动模糊，B 顺同方向从模糊中切入定格
- 动态接力转场：人物在 A 跳出画框，在 B 从画框上方落入
- 拉近 / 拉远转场：极致放大 A 的某细节（瞳孔、锁孔），细节内展开 B 全貌
- 水墨转场：A 像浓墨滴入水中晕开，B 从墨迹中浮现

官方案例：
> 参考@视频1的内容，延长视频5s向后延长。要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现。@图1壮汉战士突然察觉到异样，停下脚步，眼神变得锐利。他迅速摆出防御姿态，紧紧盯着前方。
> 参考@视频1的内容，延长视频10s延长续写。要求需要在切镜处使用"遮罩转场"转场（禁止生硬切镜、禁止物体凭空出现）。镜头A展示正在防御的@图1壮汉战士（近景），一阵风吹过，一片正常大小的落叶飘向镜头，树叶完全遮挡镜头导致全屏变暗；随后镜头穿过树叶拉开，直接显现出下一个场景：@图2的年轻游侠正靠在一棵树旁边，正举起弓箭瞄准。要求必须自然切换场景。由战士的近景自然切换为游侠的中景。
> 在@视频1的基础上续写5秒的视频，讲一只蜜蜂飞来落在画上，接着微距特写……（输出格式选 MOV）

已知：延长只对新增段生效，原片不重生成。底片 ≤30 秒，单次 4 到 30 秒，最长 60 秒。拼接处跳变时后期对齐：前段末尾删 6 帧、后段开头删 1 帧；续写段以切镜时刻结尾更稳。多次续写画质劣化（人脸出斑驳色块）：先把底片转白模再续写，控制次数。

## 2 视频编辑

常规公式：`[修改对象] + [动作与变化] + [生效时序]`。例："在视频的1-8秒，把男生的牛仔裤替换为深黑色的西装裤"。
高级编辑（圈选、画笔、箭头、定位点）：`[标注工具与方位] + [对象] + [变化] + [时序]`。方位如"红框内""沿红色箭头指向的区域""红线左侧"；时序如"全片统一修改""仅在第5-8秒发生""从第3秒起逐渐显现"。

官方模板（取句子用，成文按第 0.5 节装进本 Skill 的五段：编辑目标 → 情节段开头的命令句，原视频与目标素材职责 → 主体，保持内容 → 场景、风格、结尾，编辑范围 → 情节里的镜头）：
```
【编辑目标】编辑@视频1，在<全片或时间段>对<对象、区域或声音类别>进行<增加 / 移除 / 替换 / 调整>。
【原视频职责】@视频1是唯一编辑母版，负责人物、场景、动作、构图、镜头、遮挡关系、声音和事件顺序。
【目标素材职责】@图片1用于<指定属性>。
【编辑范围】只处理<……>。
【保持内容】保持@视频1中的<身份、动作、机位、光线、声音>不变。
```
- 主体替换加"全片目标对象数量为 N"与时间线继承："目标对象继承原对象每次出现、运动、遮挡和离开的时点、时长、路径与速度"。
- 背景替换："只修改主体轮廓之外的背景区域，不修改主体身份、五官、发型、服装、表情、位置、大小和动作。"
- 移除后补全："原本被遮挡的地毯、墙面需要自然补全，不留残影、模糊补丁。"
- 视角修改："将@视频1改为从右侧人物背后偏上方45度俯拍。保持两人的身份、服装、坐姿、动作节奏和桌面物体位置不变，合理补全新视角下的肩背、头顶轮廓与背景延展。""把第三人称视角修改为第一人称视角。" 不把固定机位和跟拍写在一起。
- 去 BGM："编辑@视频1，只移除原有背景音乐，保留人物对白、口型、环境声和动作音效；画面内容、镜头和剪辑节奏保持不变。" 不写"移除所有声音"，除非用户要静音。
- 音频编辑："将视频中的人声台词翻译成中文，无字幕，口型做出对应的精准改变，其余均保持不变。"
- 绿幕化："把整个视频0-5秒的白色背景都变成绿幕背景。去掉声音，保持静音。"

官方案例：
> 将@视频1中的时间改为月夜，光影变为月光，将@视频1中跳舞的人变为@图片1，画面要有月光笼罩的那种朦胧感，严格保持原视频的景别、运镜。全片都做出指令要求的改变。
> 移除@视频1男孩胸前的蓝色耳机，将男孩脚边的足球替换成一个橙色篮球，在长椅右边增加一只安静坐着的小白狗，小狗偶尔轻微转头，其他与原视频保持一致。
> 保留@视频1的构图、机位、光线与表演节奏，只改写画面里女主的样貌与神情：让她从二十多岁自然地老去到六十岁……全程一镜到底，不跳切、不闪烁，五官随年龄渐变而不漂移。
> 场景替换为@图片1，深色衣服男子服饰替换为@图片2……动作仍然保持不变，不改变原始节奏。AI 特效仅做环境和质感强化。

已知：局部编辑常不生效（评论区多次反馈）。对策是写清唯一母版、缩小范围、明确保持内容并再强调一遍；仍不行改用参考图编辑或重跑。编辑不保证逐帧重合；输入 ≤20 秒、参考图 1 到 5 张最稳。

## 3 首尾帧与多关键帧

首尾帧（锁首帧画幅，首尾画幅要相同）：
```
@图片1作为首帧，定义视频开始时的构图、主体位置、姿态、道具状态、场景和镜头方向。@图片2作为尾帧，定义视频结束时的构图、主体位置、姿态和场景状态。@图片3用于苏云的外貌与服装，不改变@图片1定义的首帧构图，不改变@图片2定义的尾帧构图。<一个连续动作>。画面从@图片1定义的首帧自然开始，经过连续动作后到达@图片2定义的尾帧。首尾之间保持<人物身份、道具、光线>连续。
```
多关键帧（不锁，对齐关键帧）：第一句写"以@图片1至@图片4的顺序作为关键帧"，逐张说明关键状态，末尾写"画面依次经过@图片1、@图片2……定义的状态，各阶段之间使用连续动作自然过渡"。官方案例逐镜写"@图片N的……从画面底部滑入……"，末尾"画面无卡顿、无闪烁；文字与 UI 清晰稳定"。

## 4 多宫格分镜

推荐简约线稿或火柴人，≤15 格，分镜图上不要写太多文字（18 宫格易静止、顺序错乱）。不严格对齐分镜图，只提供大致剧情，用提示词补齐。
```
@图片1提供<9格宫格分镜>的镜头顺序和大致构图，按照从左到右、从上到下的顺序读取；不采用图中的线稿画风、文字标注或占位人物。@图片2定义苏云的外貌与服装。@图片3定义白猿的外貌与铁棒。
镜头1（0-3秒）：<景别 + 机位，画面，动作>。台词（苏云）：{……}
镜头2（3-6秒）：……
最终画面采用<视觉风格>，声音包括<……>。不添加字幕，不添加背景音乐。
```
官方 30 秒九宫格案例结构：素材职责 →【主体设定】（两位主体各一段外观）→ 环境 →【整体风格】→【严格排除】（黑白、手绘、分镜稿、移轴、塑料 CG）→【分镜头】9 镜各"镜头N (a-bs)：景别 + 机位，画面。台词（角色）：{……}"。

## 5 白模

粗颗粒度（简单几何体，提供运镜、动线、站位、光影变化、切镜；当前模型对粗颗粒度效果更好）：
```
@视频1是粗颗粒度白模参考，仅提供<动作路径、人物站位、机位、运镜、切镜、光影变化、声音节奏或空间关系>，不采用其中的白模外观、材质和场景。
@视频1中的黄色模型对应@图片1中的苏云，蓝色模型对应@图片2中的罗大娘。
<按时间线描述动作、表情、台词、光影变化，与白模吻合>。
背景场景使用@图片3中的竹林山路。
最终画面采用<风格与画质>，保持角色一致性，不穿模不变脸。不添加字幕，不添加背景音乐。
```
手册公式：【参考声明】参考[视频1]的{运镜｜动作｜动线｜光影变化｜角色站位｜音乐音效｜画面节奏} → 【对应关系映射】→【剧情详述】→【场景处理】→【整体收束】。粗模契约句可加："不要求逐帧复刻，由模型补全关键状态之间的运动过程，保持需要延续的画面元素在切点前后状态一致；保留原剪辑方式，不新增镜头或转场。"
注意：粗模若带四肢或翅膀，必须写出四肢的完整动作序列，否则僵化；最佳实践是不上传带四肢翅膀的模型。白模拥有全片时长时，镜头标题不写秒数，只写"镜头1：镜头2："并沿用视频切点。

细颗粒度（建模完整，直接渲染；上传前去掉轨迹线、坐标线、相机 cone）：
```
@视频1是细颗粒度白模参考，保持<主体结构、动作、空间布局、机位、运镜和切镜>，不采用原有灰模材质和空白背景。@图片1定义苏云的材质、服装与面部。将@视频1中的主体重渲染为苏云，场景重渲染为<最终场景>。无 bgm，只生成环境音和动作音。
```
官方案例：
> 参考@视频1的动态运镜、物理光影变化，将视频中的白色模型精确替换为@图片1里的精灵女王。人物形象需要严格参考图片……保持角色一致性，不穿模不变脸。场景整体为精灵大殿，保留@视频1中的场景。机位与原视频保持一致，精灵女王跟随着参考视频里模型的动作优雅地抬起魔法手杖……最终视频要求电影级 CG 写实画质。
> 对视频1进行渲染，其中行走的主体形象参考图片一，场景渲染为古战场废墟，逆光环境，严格保持原视频运镜。
> 以白模参考视频@视频1作为整支视频唯一的运镜、镜头节奏、景别变化、主体运动轨迹和镜头调度参考，严格保持……不改变镜头结构，不新增镜头……0-3s（首帧参考@图片2）……整体要求：所有画面均参考对应关键帧，白模视频仅作为运镜参考，不参考画面内容。

用户评论：白模有时反而限制真实物理想象，渲染不够真实。先判断粗细，写清继承项。

## 6 绿幕

```
@视频1用于主体表演、动作节奏和身体轮廓，不采用绿幕背景。@图片1用于替换后的场景、光线方向与环境色。主体脚下有匹配的接触阴影，边缘光与新场景光线方向一致，透视与地面关系合理。
```

## 7 无缝转场（两段视频）

顺序：转场前视频 → 转场后视频 → 触发动作 → 镜头运动 → 画面变形 → 到达状态 → 声音。五种方式：俯冲或折返、人物旋转、前景遮挡、物体变形、推拉或焦点变化。
```
将@视频1和@视频2无缝衔接起来，不修改@视频1和@视频2。@视频1尾帧的<主体>开始<触发动作>，镜头<运动>，<画面变形过程>，最终到达@视频2首帧的<构图与状态>，<声音>过渡为<声音>。
```
官方案例：
> 将【@视频1】和【@视频2】无缝衔接起来，但是不修改【@视频1】和【@视频2】。视频1尾帧的鲤鱼开始快速向前游，然后快速跃出水面升向空中……最终成功化龙衔接上视频2。
> 将【视频1】和【视频2】衔接起来，【视频1】的视角急需飞行至顶端快速折返，视角垂直向下俯冲，然后无缝自然地衔接转场到【视频2】，在镜头切换的过程中麻将牌慢慢变成高楼……同时不要改变上传的两个视频。
无缝转场不代表两段原视频逐像素不变。三段以上分成两两衔接。

## 8 一键成片

【素材职责】→【编排方式】→【画面动态】→【成片风格】→【声音】。官方案例："将所有图片进行一键成片，图片顺序自由安排……图片可以微微动起来，live 图的效果，但不要改变原图。"

## 9 超长视频（30 到 180 秒）

完整提示词 = 【全局参数】（开头再次强调时长与画幅）+【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】。这是官方的信息顺序，不是标题清单；倒进本 Skill 的五段时，那句概述写在情节段开头、不另起 `概述：`。官方案例全部是连续段落："0-6 秒，极远景，清晨的荒原被薄雾覆盖……以车轮碾过碎石的声音切入下一镜。6-13 秒，低机位近景……"；60 秒咖啡馆案例每段末尾附反向描述"镜头不要晃动，不要有人物入镜，禁止生硬切镜"。按故事节拍分段，不平均切；只在开头写一次跨段锁定，不把人物外貌复制进每段。

## 10 音色、多语种与文字

- 音色参考：`参考@音频1说……，并保持低沉悬疑的语调`；官方案例每句台词后写"音色参考@音频N"。音色不准时补特征描述："使用@音频1低厚温润带细碎颗粒感中年男声的音色说"。
- 多语种：直接写目标语言台词，口型"必须完美匹配这句印尼语台词的发音"；画面文字"全部为自然规范的日文，不出现任何中文、英文或乱码"（韩文仍有错别字）。
- 迁移创意：@参考视频并描述要迁移的内核（可爱状态、喜剧效果、镜头节奏、转场方式）。
- 特效不准时用参考视频定义："数字'2999'出场方式参考@视频1"。
