# 反模式表：已知失效写法

这张表是"已知失效写法"的唯一清单，`scripts/check_prompt.py` 直接读它生成提醒。
每行必须有经验编号（L 编号，在 `lessons/seedance-2.5.md`，搬走的在 `lessons/archive.md`）；代码索引行里暂时没有条目的，写明「无条目」和规则出处。模式约定（某个 `--mode` 下按约定就不该写的东西，比如白模稿镜头标题的秒数、焦段）没有成片证据，证据写「未试（模式约定，Lxxx）」，指向定下这条约定的经验，提醒标「候选」。
证据等级三档：`两条以上`（两条以上成片或对照）、`单次`（一条成片）、`未试`。`两条以上` 的行是正式提醒，`单次`、`未试` 的行提醒时标「候选」；等级怎么升见 [lessons/README.md](lessons/README.md)「升级门槛」。
经验库新增失效写法时在这里加一行，不在代码里加词表。
要看景别、看距离链这类复杂逻辑的检查仍在代码里实现，表里也有一行，触发列写「实现：代码」，让这张表成为完整索引；这些行的触发脚本不读，为什么、证据、改成三列只有提醒带编号的代码行（现在只有 AP09）会被读来拼提醒。
提醒长这样：`镜1 反模式 AP01（两条以上 L047、L144）：「位置和大小稳住」；为什么；改成：……`。裁定过、要保留的写法记进项目的 adjudicated.txt，见 SKILL.md 必须守住第 4 条。

## 场合

场合只用下面七个。判定词也从这张小表读，改判定词直接改这里。

| 场合 | 扫哪段 | 判定词 |

| 任何 | 全文，剥掉台词、去掉锁定文字；一稿报一条 | — |

| 场景段 | 只扫场景段；一稿报一条 | — |

## 写法约定

- 触发列是 Python 正则，用反引号包住，前面可以先用人话写一句触发什么。正则里的竖线在表格里写成 `\|`（Markdown 表格的要求），脚本读的时候还原。
- 一格可以放几条正则，按先后扫，后面的命中和前面的重叠就不再列。同一行在同一镜（或同一稿）命中多处只报一条，列前 3 个命中。
- 命中词是 `--asks` 有效要求的关键词就不报；锁定文字不扫。
- AP02 的两条正则给「取景写成了“能装下什么”」那条老提醒用：文案沿用老的，末尾标编号与证据；场合固定是镜内。第一条（能装下）先列，第二条（露出 / 看到 + 全身）命中时句末加注 L145。
- 某一行写错（列数不对、场合不在上面七个里、正则编译不过）脚本跳过这一行，checked 里写原因；整张表读不出来时 checked 记「反模式表未加载」，不报错，也不中断检查。
