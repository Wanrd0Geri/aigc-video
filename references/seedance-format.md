# 即梦 Seedance 2.5 提示词格式

> 用于执行清单第 ③ 步（定骨架）与第 ⑦ 步（成文）。
> 读完必须产出：一份四段齐全（主体、场景、风格、情节）、末行是固定句 `全片不添加BGM，不添加字幕。`、素材引用合法、时间戳连续的完整提示词；修改五段 / 六段旧稿时按父稿外壳与父稿那句固定句交付。
> 经验的证据与采用规则以 `lessons/README.md` 为唯一准则（**需要核对某条经验算已试还是未试、或要写入新条目时再读它**，本节已够用就不读）：分清"试过的"和"没试过的"，没试过的照常可用但不冒称已验证；经验不能覆盖用户锁定项或已确认事实。

## 1 新稿四段外壳固定，固定句收尾，修订继承父稿

三份官方来源（即梦使用手册、火山引擎提示词指南、飞书撰写指南）结构一致：素材与主体在最前，然后一句话概述，再全局设定，再分镜，最后收尾。官方另有一句明确的话：**"重要素材前置：越需要精准参考的素材，放在提示词中越靠前的位置。"**

本 Skill 的新稿固定用下面**四个**标题，顺序不变（**不设概述段，也不设结尾标题**）；收尾不是一个段落标题，就是正文末尾的固定句那一行——**末尾只有它**，它上面一行必须是普通正文（镜头内容或命令句）。

```
主体：人物与物件的素材映射（图N 用于谁的什么、不采用什么）+ 音频（音频N 用于谁的音色）+ 人物造型（有参考图只补图里看不出的：伤势、湿发、情绪底色；固定短外貌短语）。最需要精准的素材放最前。
场景：场景图的映射（图N 用于空间布局与光线，不采用图中人物）+ 时间、地点、氛围、光源方向与色温、质感；只写全片贯穿的。
风格：材质、光影、画风参考图的映射（图N 用于材质与画风参考）+ 画风与渲染方式、材质与表面质感、光的质感与层次、镜头性格（焦段、景深、手持还是稳定）。不写表演、不写具体运镜路径、不写动作与事件、不写时序——这些都属于镜内。
情节：
（生成类新稿**不写总览句**，情节段直接从第一个镜头标题开始：时长与镜数由镜头标题表达，风格在风格段；跨镜要保持的身份、数量、服装、道具归属、左右关系写成正向句放进**主体段**；"画面里只有 X 一个人物"也放主体段。第一个镜头标题之前只允许延长、编辑、衔接等操作命令的命令句与官方必填句。check_prompt 在生成类四段稿的情节段开头发现非命令文字时会提醒。）
镜头1（0-5秒）：……（每镜只写当前画面）
镜头2（5-9秒）：……
全片不添加BGM，不添加字幕。（必写，只写一次，整份提示词的最后一行；末尾只有这一行，上面不再写否定句、约束句、"保持…"句）
```

最后一行逐字是 `全片不添加BGM，不添加字幕。`：**必写、只写一次、结束整份提示词**，它后面不能再有任何内容（检查时容忍 BGM 前后的空格与末尾句号有无，写出来一律用这个规范形式）。

四段标题是本 Skill 为新稿选定的固定外壳：官方三份来源里只有"一句话概述"这个**位置**（素材与主体在最前，然后一句话概述，再全局设定，再分镜，最后收尾），官方并没有规定要为它单独起一个 `概述：` 标题，也没有规定所有任务必须用某一组标题，收尾那部分官方案例本来也是直接续在正文后面、不另起标题。本 Skill 判断单独的概述段是重复信息——时长、镜头数在情节段已有，风格在风格段已有——所以新稿**不设概述段**：总览性的一句话由情节段的第一句或风格段承担，同一事实只写一处，不重复；收尾同样**不另起 `结尾：` 标题**，而且末尾只留固定句那一行：确有必要的否定句写进相应镜头的正文，操作命令的必填句写进情节段开头的命令区。**修改已有稿时按 `review/revise-rules.md` 继承原外壳与原固定句**（**改稿时再读那份**）：六段旧稿的修订仍交付六段、必填词仍在概述段、固定句仍是旧句"不添加字幕，不添加背景音乐。"，五段旧稿的修订仍交付五段、固定句仍在结尾段，不为通过检查迁移格式；要换成四段须用户本次明确授权（检查时加 `--format 四段`）。镜头标题在 `镜头N（a-b秒）：` `镜头N：` `【阶段N】` 里选一种全片统一。**案例提供镜内组织参考；具体密度由当前控制点决定，案例不决定外壳**：官方案例没有标题的（丹顶鹤）、用【】标题的（江边告别、九宫格），都按上面四段倒进去。官方 30 秒公式的对应：基础环境与质感 → 场景；视觉风格与镜头性格（焦段、景深、手持还是稳定）→ 风格；表演核心与具体运镜路径 → 相应镜头的正文；人物造型 → 主体；禁止项 → 先改成正向句分配到对应段落，改不掉的写进相应镜头的正文；一句话概述 → 情节段开头那一句。延长、编辑、衔接、首尾帧、白模预演同样套四段：官方必填词与官方约束句**都写在情节段开头的命令区**（`情节：` 之后、第一个镜头标题之前），保持内容也写在那句命令句里，末尾只留固定句，**做延长、编辑、衔接、首尾帧、白模这类操作命令时再读** `seedance-operations.md` 第 0.5 节的逐类装法与例子，写普通新稿不读。

## 2 素材引用与职责

- 统一写 `图N`、`视频N`、`音频N`（N 按上传顺序，没有"片"字，**提示词里不写 @**——粘进即梦以后在软件里再 @ 出来）。镜头正文可以重复用同一个短名指代，官方原话"多次@会更加准确"。不写文件名、路径、UUID、Asset ID。修订旧稿时沿用旧稿的写法（旧稿写 `@图片1` 就继续写 `@图片1`）。
- **每份素材只在用它的那一段绑定一次**：人物与物件图 → 主体段；场景图 → 场景段；材质、光影、画风参考图 → 风格段；音频 → 主体段（音色）；操作类的视频（延长、编辑、衔接、白模的母版或参考片）→ 情节段开头的命令句。情节里需要时用同样的短名指代，不再复述职责。`check_prompt.py` 会提醒同一素材在两个段落都写了职责。
- 职责模板：`图1用于苏云的外貌、服装和竹背篓，不采用图片背景。音频1用于苏云的音色。`（主体段）＋`图3用于街口的空间布局和光线，不采用图中人物。`（场景段）＋`图4用于湿布与石面的材质参考。`（风格段）＋`视频1用于动作节奏与运镜，不采用视频中的人物身份、服装和场景。`（情节段开头的命令句）
- 多人先逐一绑定再写站位：`苏云对应图1，只采用外貌、发型和服装。白猿对应图2，只采用外貌与铁棒。` 不要写"图1至图4分别定义四名角色"。视频里的人物可用"将视频1中的高个子男人定义为警察"，之后一直用同一名字。
- 同一主体多张图：`图1定义苏云的正面外观，图2定义苏云的侧面与背篓结构。两张图共同定义同一个苏云，成片中始终只有一个苏云。`
- 参考视频已经精准给出动作、运镜和顺序时只指代不复述：`严格参考视频1的动作与运镜，顺序与视频保持一致。` 复述会与素材冲突。
- 素材容易误带入时才写"不采用什么"；不为不存在的维度写排除。
- 人物图：单人独立图优先。脸漂移时加一张只含头部的大头照，写"苏云的面部特征参考图1（大头照），服装参考图2（全身照）"。三视图、多视图容易被当成多个人。
- 参考人数多时先检查身份绑定、可见度与交互关系；分组参考图是条件性方案，不能仅因超过4人就自动分组、加生成步骤或改变人物规模。
- 数量：官方推荐总计 4 到 5 个素材（角色图 1 到 2 张 + 场景图 1 张 + 运镜视频 1 段 + 音频 1 段），不建议用满上限。

## 3 情节段开头那一句、场景、风格怎么写

- **情节段开头那一句（需要时才写，六段旧稿的修订仍写在概述段）**：`生成一段 8 秒 3D 国风漫画风格的视频：受伤的少年苏云在雨夜的天门镇街口回头张望，固定机位近景。` 它不另起标题，直接写在 `情节：` 之下、第一个镜头标题之前；里面已经由风格段或镜头表承担的信息不重复写。
- **场景段**（全片贯穿的）：场景图在这里绑定（`图3用于街口的空间布局和光线，不采用图中人物。`）+ 时间 + 地点 + 氛围 + 光源方向与色温 + 质感，按实际场景选择必要动态与响应：有风才判断风吹什么，有雨才描述雨落在哪；安静背景也可成立。不为达到配额加入风、尘、烟、雨或人流。
- **风格段只描述画面质感**（全片贯穿的）：材质、光影、画风参考图在这里绑定（`图4用于湿布与石面的材质参考。`），正文写下面四方面，均须判断适用性；适用的独立控制必须在正文中落实，不限定各写一句，可自然合并。没有相应材质或驱动不编造响应。省略的是不适用内容，不能省略适用控制；不适用依据留在内部审查。**不写表演、不写具体运镜路径、不写动作与事件、不写时序**——这四样都属于镜内，`check_prompt.py` 会在风格段里发现时序词、运镜路径词或动作词时提醒。下面四方面逐条判断：
  1. 画风与渲染方式：3D 国风漫画 CG、2D 日漫、写实；写实材质怎么配风格化角色。有参考图也要写，否则漂真人。
  2. 材质与表面质感（各自怎么受光、怎么受力）：皮肤（细微纹理、柔和透光）、毛发（成束、根部阴影、随动作滞后）、布料（厚薄、织纹、湿了发深、褶皱滞后摆动）、金属石材（弧面高光移动、粗粝）、湿面（反光碎成鳞片）。写表现不写外貌，外貌在主体段。
  3. 光的质感与层次：亮部柔和收束、暗部保留层次、间接光或邻近受光、景深范围。
  4. 镜头性格：焦段、景深、手持还是稳定（长焦压缩还是广角、浅景深还是大景深、手持呼吸感还是稳定器般平稳、常用景别习惯）。**不写具体运镜路径**——推近、后拉、横移、环绕、跟随到哪里，写进它所属的那一镜。
  例："3D 国风漫画 CG 风格，写实材质配风格化人物。粗布上衣织纹明显，淋湿的部分颜色发深贴在肩上；毛领根部有阴影，外缘发丝分束；灯笼纸面透出暖光，青石板的湿面把灯光反射成碎鳞片。亮部柔和收束，门框阴影里保留衣褶层次。中景与近景为主，长焦浅景深，轻微手持呼吸感。"
- **画质词不算描述**：8K、高清、精美、电影感、高级感单独出现就是低质量描述。只能作为风格段末尾的一小段尾巴，前面必须已有具体的材质与光的句子；"电影级真实光影"这类官方案例里的词也一样。
- **主体段的人物造型**：有参考图只补图里看不出的（当前伤势、湿发、情绪底色）和一个固定的短外貌短语；无参考图可用人物七维检查遗漏，按辨识需要和景别取舍，不必填满：年龄种族、肤色与皮肤质感（追求真实加"保留真实的微细毛孔与肌肤纹理""毛发根根分明"）、面部必要辨识细节（3到4点仅为示例，不是配额）、眼神、发型发色、服装材质与新旧、体型气质。

## 4 分镜与时间戳

- 2.5 响应**整数秒**时间戳（2.0 只响应镜头序号）。区间连续：`0-3秒 / 3-8秒`，不留断档、不重叠，总和等于总时长。标题可用 `镜头1（0-3秒）：`、`0s-3s：`、`【阶段一】` 三种，全片统一一种。
- 普通叙事优先"阶段 + 结束时状态"：每阶段一个主要变化，写清结束时画面里能直接看到的状态（人物位置、道具归属、画面状态）。只在关键交接、进出场、转场、卡点时用秒。
- 时间点与相对时间：`第5秒快速向左横移转场`、`3秒后周围的人纷纷摇头`、`按下快门后画面定格1秒`。不用时间戳控制频次。时间段是事件预算，不是精准剪辑点。
- 一镜可容纳多个有序动作，按时长与可读性判断；摄影各移动分量须相容，不按动作数或术语数强制拆镜。
- 镜头句信息顺序（写成自然句，不是参数表）：景别与机位 → 主体当前状态与空间关系 → 动作与因果反应 → 运镜及它带来的可见变化 → 一个视觉焦点 → 对白或关键音效 → 结束状态。固定机位不必反复说明；推、拉、环绕、变焦要写清什么变大、变小、被揭示、被遮住。
- 动作优先概括主要过程，只为关键动作写具体细节（部位 + 幅度 + 速度 + 力度），不重复描述同一动作。
- 每镜只写当前画面里正在发生、镜头能拍到的内容（需要逐条对照三道门与空词清单时再读 `writing-rules.md` 第一组）。
- **运动有依据**：按目标选择主体活动、世界驱动和材料响应，不要求主体以外必须有动态。人物、物件与环境可保持稳定，摄影仍按 SKILL.md 默认有可见运动；物件静止不等于镜头固定。用户明确要求摄影固定或全画面零变化时遵从；不加微抖、呼吸感或无来源环境运动。
- 多镜一致性：每份素材只在用它的那一段绑定一次（人物物件图与音频在主体段，场景图在场景段，材质光影画风参考图在风格段，操作类的视频在情节段开头的命令句），人物造型也只写一次，镜内用名字；跨镜用同一个短外貌短语（"银白瞳的黑发少年苏云"）。

## 5 声音、对白与文字

- 特殊符号：音乐 `( )`、音效 `< >`、台词 `{ }`、字幕 `【 】`。台词也可写 `苏云压低声音说道："……"`。
- 画外与旁白：`旁白：{……}` 或 `旁白（VO，画外，不产生人物口型）：{……}`；`画外传来罗大娘的声音：{……}` 或 `罗大娘（OS，位于画面右侧外）：{……}`。
- 口型：`要求口型与说话时间一致`。台词语言：`台词语言：中文普通话。苏云用沙哑、压低的声音说：{……}`。多音字可按语境改成同音同调常用字，保留原文和逐字发音映射，具体范围与校验见 SKILL.md 摄影与发音偏好及 review/quality-gate.md；不随意改其他字或画面文字。
- 画面内实体文字用引号，写清内容、时机、位置、出现方式；要求精确的文字先做一张参考图。
- 每镜独立判断必要声音：无对白仍可写动作音、环境音或画外声音的来源、时机和关系；没有必要声音才省略。默认只保留对白与必要动作音；末尾固定一句"全片不添加BGM，不添加字幕。"（五段 / 六段旧稿的修订仍用旧句"不添加字幕，不添加背景音乐。"）；需要静音时写"不要任何声音"。
- 音色参考（写在主体段，绑定一次）：`苏云的台词音色参考音频1，保持低沉压抑的语调`。

## 6 末尾只有固定句：保持一致与禁止项怎么写

末尾不是一个可以堆句子的区域，就是固定句那一行。它上面一行必须是普通正文。

```
情节：
生成一段 8 秒的雨夜对峙视频；苏云、白猿的身份、数量、服装、武器归属和左右位置关系全程稳定。
镜头1（0-4秒）：……画面里只有苏云一个人形。
镜头2（4-8秒）：……
全片不添加BGM，不添加字幕。
```

- **跨镜"保持一致"写成正向句，放进主体段**（不写总览句），不接在最后一镜后面，更不单独占末尾那一行。单镜没有跨镜可保持，不写。
- **默认不写否定句**：自写否定预算 0 条（固定句不计）。写每条否定之前先问：这句能不能改成"要什么"？
- **确属特殊情况、没有正向写法的那一句，写在它管的那一镜的正文里**（或操作命令的命令句里）。`check_prompt.py` 会逐句提醒，提醒要当场裁定，确认后用 `--negative-exception` 点名。

| 想写的否定 | 改成正向，放到 | 还要不要写否定 |
|---|---|---|
| 禁止上方鳞面消失、禁止变成露天 | 场景段："上下两片鳞把画面夹成一条狭窄的甬道" | 不写 |
