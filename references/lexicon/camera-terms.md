# 运镜、构图与光学词库

> 用于第 ④ 步（翻译）与第 ⑧ 步（压缩）。查到术语后照写；术语后那半句结果怎么写、写多具体，只在 writing-rules 第 24 条与成文主规则第 6 条维护。
> 读完必须产出：本镜运镜句 = 速度与方向 + 术语 + 终点切线或一处可见结果（推、拉让景别变了时，终点切线就是那一处结果，不另补；writing-rules 第 22 条）；起点就是上一拍结束时的画框，写过就不重写；同一运镜延续到下一拍时只写新终点或主体的新位置。
> 经验的证据与采用规则以 [../lessons/README.md](../lessons/README.md) 为唯一准则：分清"试过的"和"没试过的"，没试过的照常可用但不冒称已验证；经验不能覆盖用户锁定项或已确认事实。

## A 术语辨别：口语 → 术语 → 画面

| 口语说法 | 术语 | 画面上会看到什么 | 可直接用的中文句 | 理解度 |
|---|---|---|---|---|
| 镜头不动 | 固定机位 Static shot | 机位与朝向稳定，运动由画内主体承担；只在用户明确要求时用 | 固定机位中景，画框下缘切在膝盖，人物在画面右侧三分之一处 | 直写；未试 |
| 向旁边看、抬头看 | 摇摄 Pan / 俯仰 Tilt | 原位转向，逐步揭示视野外内容；不是横移 | 镜头原地向右缓慢摇过，露出门口的来人 | 直写；未试 |
| 一下甩过去 | 甩镜 Whip pan | 由清楚起点快速转向，中途模糊，落到清晰目标；不自动产生剪切 | 镜头沿棍端方向猛然急扫，屋檐化作短促横线，骤停在被震退的苏云身上 | 未试 |
| 靠近、退远 | 推轨 / 拉轨 Dolly in / out | 摄影机实际接近或离开，近远比例与视差改变 | 从中景慢推到特写，画框下缘从膝盖收到下巴 | 直写；未试 |
| 放大、猛地放大 | 变焦 Zoom / 急变焦 Crash zoom | 改变焦距收紧取景，无横向视差 | 镜头急速变焦收紧到她握信的手，四周瞬间被裁掉 | 未试 |
| 人不变大、背景挤过来 | 滑动变焦 Dolly zoom（希区柯克变焦） | 移机与反向变焦配合，主体大小不变，背景透视被压紧或拉开 | 镜头后撤同时变长焦，人物大小近似不变，身后通道被视觉压紧 | 热门；未试 |
| 横着跟、擦着前景走 | 横移 Truck / 滑轨 Slider | 镜头平移，近前景掠过快、远景慢；写全相机路线、主体在画面里从哪到哪、一处边缘移入移出 | 摄影机沿桌沿向右滑动，前景杯沿移出视线，露出其后的信封 | 直写；已试（L079，2.0；2.5 同稿幅度保守，L060） |
| 升高一点看 | 升降 Pedestal | 机身垂直平移，看见不同高度的关系 | 摄影机垂直升起半人高，桌面上的物件逐一进入画面 | 未试 |
| 绕一点、绕一圈 | 弧线移动 Arc / 环绕 Orbit | 围绕明确主体移动，保留地面锚点，落到新观看侧；写清从哪侧到哪侧、高度、半圈还是一圈 | 从人物左侧向右环绕半圈，机位高度在腰部，最后停在他的侧后方 | 直写；未试 |
| 跟住他 | 跟拍 Tracking / 后跟 Follow / 反向跟拍 Reverse tracking | 与主体保持指定距离和侧向关系，世界后退；写全距离、主体在画面里的位置、一处视差，冲锋要张力时改逼近放大（L047） | 摄影机在奔跑者左侧两米并行跟拍，让他保持画面右半，近处桥柱迅速掠过 | 直写；已试（L044、L047） |
| 贴地追、追车 | 低位跟拍 Low tracking / 车载跟拍 Vehicle tracking | 沿真实路径，路面与远景显示视差 | 摄影机贴着瓦面追过后滑的脚，碎瓦从镜前掠过 | 未试 |
| 拉开看到很大 | 摇臂 Crane / 航拍 Drone | 改变高度或距离，逐步揭示尺度；写高度、方向、范围 | 从平台边缘人物的中景拉远并缓慢升高，先露出平台断面，再露出下方谷地 | 热门；未试 |
| 人在晃、现场感 | 手持 Handheld | 画面边缘持续不规则地偏移，有动机；剧烈晃动会翻车 | 手持，画面边缘持续不规则地上下左右偏移，像摄影师半跪在他面前端着机器 | 直写；已试（L075） |
| 脸稳、世界乱动 | 胸前固定摄影 Snorricam | 相机相对躯干固定，背景随身体运动 | 摄影机固定在人物胸前正对他的脸，他奔跑时脸稳定不动，街道在身后剧烈晃动后退 | 需解释；未试 |
| 从他的眼睛看 | 第一人称 POV / FPV | 视点在角色眼位，看不到角色自己的脸；FPV 写路径、速度、转向 | 第一人称视角，双手推开木门，门后的院子随脚步逼近 | 直写（第一人称）、热门（FPV）；未试 |
| 前面糊、后面清楚起来 | 焦点转移 Rack focus（移焦） | 机位不动，清晰面从一个对象移到另一个；焦点分段走，每段给实物落点 | 移焦，焦点从前景树叶平滑转移到背景人物，树叶逐渐虚化，人物面部由模糊变清晰 | 直写；已试（L058） |
| 近处很大、速度扑面 | 广角近距 Wide-angle close proximity | 近物夸张、远近尺寸差明显 | 从瓦面贴地仰拍，棍端横压近景，白猿高居后方 | 未试（L001 外部说法：极端广角边缘易崩） |
| 背景像贴近了 | 长焦压缩 Telephoto compression | 从远视点紧取景，前后距离显得紧凑；焦段数值 + 背景压成色块一起写 | 85mm 长焦，背景压缩，人物从虚化的街景中分离出来 | 已试（L046，用户截图单帧；mm 数值单独是否有效未试） |
| 小模型一样 | 移轴外观 Tilt-shift | 窄带清晰区产生微缩感 | 移轴效果，只有街道中央一条窄带清晰，上下都柔焦，行人像微缩模型 | 需解释；未试 |
| 动作慢下来 / 世界飞快 | 慢动作 Slow motion（升格）/ 延时 Time-lapse | 改变事件呈现的时间尺度 | 慢动作，瓷杯在空中缓慢翻转，液体拉出不规则液滴 | 直写；未试 |
| 冻结那一瞬转着看 | 子弹时间 Bullet time | 动作冻结或极慢，镜头环绕；写被冻结的动作、环绕方向，环绕和被冻结的那一下同一瞬，是在呈现它 | 子弹时间，棍与爪相碰的一瞬间几乎冻结，镜头从左向右环绕半圈，火星悬在空中 | 热门；未试 |
| 一下快一下慢、弹回来 | 回弹变速 Speed ramp | 在指定节点加速、减速或回弹；写在哪个节点变速、最终停留 | 接触变形短暂放慢到可读，随即骤然恢复高速，苏云被冲力甩出 | 热门；未试 |
| 不剪、一路走 | 一镜到底 One take | 连续时空，无剪切；写连续经过的主体、空间、事件顺序 | 一镜到底，慢推穿过走廊，墙上的老照片和半开的门从画面两边滑出去，进到客厅 | 热门；未试 |

Infinite zoom、Earth zoom out、Pass-through objects 是特殊空间过渡：只在任务需要时选用，写明尺度变化、可见连接和终点。

## B 景别、焦段、角度、构图

| 口语说法 | 术语 | 画面上会看到什么 | 可直接用的中文句 | 理解度 |
|---|---|---|---|---|
| 交代这是哪 | 远景 / 大全景 / 大远景 | 环境为主，人物很小（大远景里人物只剩一个点） | 远景，他的背影只占画面下方一小块，站在巨大的落地窗前，窗外是一整片都市夜景的灯 | 直写；未试 |
| 谁在哪干什么 | 全景 | 全身 + 环境 | 全景，画框下缘切在苏云脚前半步的石板路，上缘离他头顶一掌，他背着背篓站在街口 | 直写；未试 |
| 看关系和肢体 | 中景 | 膝盖以上，两人关系与肢体可读 | 双人中景，画框下缘切在膝盖，两人相隔一臂，左侧的人肩膀向右转 | 直写；未试 |
| 看上半身动作和表情 | 中近景 | 腰部以上 | 中近景，画框下缘切在腰带，他低头拧开壶盖 | 直写；未试 |
| 看脸上的情绪 | 近景 | 约胸部以上 | 近景，画框下缘切在胸口，苏云皱着眉，嘴角往下压 | 直写；未试 |
| 怼到眼睛、手指 | 特写 / 大特写 | 特写是面部或肩部以上；大特写只剩一处局部（眼睛、手指）占满画面 | 眼睛大特写，瞳孔在光线中收缩，下眼睑轻微抽动 | 直写；已试（L046，大特写） |
| 拍得很近很小的东西 | 微距 Macro | 极近距离，细微运动被放大 | 镜头微距，水滴在花瓣表面滚动 | 直写；未试 |
| 空间拉开、透视夸张 | 广角 16–24mm | 纵深拉伸、边缘夸张 | 广角低角度仰拍，屋檐向天空汇聚 | 未试（L001 外部说法：极端广角边缘易崩） |
| 最自然、像肉眼 | 标准 35–50mm | 接近人眼视角 | 中近景，画框下缘切在腰带，标准视角，墙线平直 | 未试 |
| 人从背景里跳出来 | 中长焦 85–135mm | 压缩空间、背景虚化；数值 + 可见结果一起写 | 85mm 镜头，背景压缩，人物从背景中分离 | 未试 |
| 平等地看 | 平视 / 平拍 Eye level | 观众是旁观者 | 平拍中景，画框下缘切在膝盖 | 直写；未试 |
| 俯视、上帝视角 | 俯拍 High angle / 顶拍（鸟瞰）Bird's-eye | 观众掌控；顶拍在正上方 | 从人物背后偏上方 45 度俯拍，看得到他的头顶和脚下的影子 | 直写；未试 |
| 仰望、压迫 | 仰拍 Low angle | 镜头在膝盖以下 | 低角度仰拍，看得到他的下颌底面，前景有巨大阴影压向人物 | 直写；已试（L050，案例 M002） |
| 画面歪、不安 | 荷兰角 Dutch angle | 相机绕镜头轴滚转，地平线和竖线都斜着 | 荷兰角，地平线朝画面右下斜，门框斜着切过画面左侧 | 未试 |
| 有质感但不夸张的角度 | 微角度 | 略高或略低于视线；角度写看得见的结果，不靠"微微" | 镜头比人物视线略高 10 度，看得到他的头顶和额头 / 从胸口高度往上仰，看得到他的下颌底面和身后的天空 | 已试（L050，案例 M002）；略高 10 度那句未试（T10） |
| 有呼吸空间 | 三分线 / 留白 | 人物在三分线或交点上，另一侧留白 | 人物位于画面右侧三分之一，视线向左，左侧留出大片天空 | 未试 |
| 仪式感、压迫感 | 居中 / 对称构图 | 主体在中轴，左右对称 | 画面严格左右对称，人物站在中轴线 | 未试 |
| 斜着的动势 | 对角线构图 | 主体或路径沿画面对角线排布 | 棍身从画面左下角斜到右上角 | 未试 |
| 显得孤小 | 人物占比 | 人物极小，空间极大 | 人物只占画面下方六分之一，上方是巨大空洞的天空 | 未试 |
| 有层次、有深度 | 前中后三层 + 遮挡 | 前景虚化物、中间那层是主体、背景虚化（纵深层不写“中景”，免得被读成景别） | 前景虚化的铁艺栏杆，中间那层的女人推开咖啡馆门走出，背景模糊的街道融化在黄昏暖光里 | 未试 |
| 从他背后看过去 | 过肩 OTS | 前景肩膀，看到前方 | 过肩，摄影机在他身后一米，他的右肩占住画面右下角，越过肩膀看到前方的门口 | 直写；未试 |
| 让人看某样东西 | 焦点引导 | 其余轻微虚化，焦点锐利 | 画面其他部分轻微虚化，焦点锐利对准手中的怀表 | 直写；未试 |
| 只有一小片清楚 | 浅景深 | 焦点 + 衰减范围 | 焦点落在眼睛上，鼻子开始轻微失焦，背景完全模糊 | 直写；未试 |
| 眩晕 | 主观旋转 | POV + 旋转 + 地平线不稳 | 镜头以人物视角旋转，背景倾斜，地平线不稳 | 未试 |
| 进出画框 | 入画 / 出画 | 主体从画框哪条边进来或出去，写清哪条边；也可当静态切线用（膝盖以下出画） | 人头从画面右下角出画，湿发最后扫过画面下缘 | 已试（L085，前景擦过的入画出画） |
| 开头停在哪、最后停在哪 | 起幅 / 落幅 | 镜头第一帧与最后停住的画框；后面必须紧跟那一帧画面 | 落幅停在远处雨里的灯笼怪身上，灯笼还在晃 | 未试 |
| 最抓人的那一下 | 高光点 | 关键事件那一瞬；这个词不进正文 | 不写这个词，写关键事件那一拍本身：第4秒，手指张开，头离开它的手，朝画面左上方飞出去 | 未试（可能被读成亮部高光，推测） |

## C 高张力打斗运镜 M01–M10（每条：起始 → 路径 → 终态 → 例句）

| 编号 | 用途 | 起始 / 路径 / 终态 | 可直接用的中文句 | 理解度 |
|---|---|---|---|---|
| M01 极速扫镜 + 骤停 | 突发转向、迅速揭示结果 | 从攻击端起点极速摇转 → 中途模糊 → 抵达受击者骤停 | 摄影机沿棍端方向猛然急扫，楼宇化作短促横线，骤停在被震退的防守者近景 | 未试 |
| M02 贴身高速跟飞 | 飞冲仍看清脸 | 侧前方近景 → 随飞行路径快速移动 → 保持飞行或到达接触 | 摄影机贴住飞行者侧前方，焦点钉在他咬紧牙关的脸上，身下屋顶高速退远，衣摆猛烈抽向后方 | 未试 |
| M03 迎击骤推 | 速度扑面 | 广角近距面对攻击端 → 角色前冲同时相机迎近（可和出拳同一瞬，是在呈现它）→ 接触或遮挡切点；拳面遮满画面是整幅遮挡，放在命中之后作切点 | 摄影机迎着来拳骤然逼近，拳爪在广角透视中急剧放大，拳面最终遮满画面 | 未试 |
| M04 攻击端相对锁定 | 武器冲力、接触位置 | 前景紧取棍端 → 跟随使攻击端相对稳定、背景疾掠 → 命中处受力结果 | 摄影机跟住向下砸落的棍端，使其压在前景，身后楼檐猛然向上掠过，最后落到背部接触点 | 未试 |
| M05 交点高速环绕 | 双方接触关系 | 以交点为中心 → 迅速绕向新观看侧（可和交手同一瞬）→ 遮挡变化、锚点连续 | 摄影机围绕爪棍交点快速绕行，棍端从近景擦过，画框下缘切在脚下的屋脊 | 未试 |
| M06 贴瓦掠行 + 上挑 | 脚下位移转入上身威胁 | 低位近景跟脚 → 贴地掠行后随身体上升抬机 → 压来的武器 | 摄影机贴着瓦面追过后滑的脚，随角色重新腾起迅速升高并上摇，落在迎面压来的巨棒上 | 未试 |
| M07 高空俯冲 + 急收 | 高低空间压迫（航拍类） | 高处俯视 → 沿楼檐极速下降 → 近目标急收成俯拍景别 | 摄影机从高檐外侧极速俯冲，数层屋顶从两边飞掠，抵近人物时急收成俯拍中近景 | 热门；未试 |
| M08 受击同步后撤 | 被击飞 | 近处起拍 → 命中瞬间随受击者猛然后撤 → 延续位移 | 命中瞬间摄影机随被击者猛然后撤，攻击端急速远离，身体仍在冲力中倒飞 | 未试 |
| M09 随翻腾滚转 | 失衡 | 翻腾身体为主体 → 相机绕观看轴滚转 → 近落点恢复方向 | 摄影机随角色翻腾滚转，地平线迅速倾倒，接近落点时恢复方向，脚下屋脊重新横入画面 | 未试 |
| M10 碰撞震动 + 立即稳住 | 接触的瞬时重量 | 接触关系可读 → 撞击瞬间短促震动（不算大运镜，和撞击同一瞬）→ 迅速恢复 | 爪棍硬碰的一瞬间画面剧震，随即稳住，双臂被压得往下一沉，脚下倒滑，碎瓦飞散 | 未试 |

"一个主要运镜"指一条连贯有主次的路径，允许兼容的平移、升降、摇摄协调完成；不给相机互相竞争的路径。急扫、急收、震动都是运动而不是剪切。运镜可以和关键触点同一瞬，只要是在呈现它（M03 迎近、M05 绕交点、M08 随被击者后撤、M10 短促震动、子弹时间环绕）；急扫、急收会让触点看不清，触点放在急扫之前的清楚起点，或急扫落定后那段继续运动里，不放在急扫途中，也不让镜头停在落点上等触点（writing-rules 第 29 条）。
