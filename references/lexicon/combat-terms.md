# 打斗招式、兵器与受击反应词库
> 用于：把用户说的“打一拳、砍一刀、被打飞”升成具体的招式名、兵器路线与受击结果，写进打斗镜头的那一拍（基础身法、棍术、攻防关系、碰撞重量见 `action-terms.md`，本表往细里扩，只写结果不写发力过程）。
> 读法：按小类标题 grep，不整份读

## A 拳法、肘与掌

|---|---|---|---|---|
| 【通用】【写实】刺拳 / 伸手快打一下就收 / 前手试探拳 | 刺拳 Jab | 前手沿直线短促打出、打完立刻收回下巴边，拳面点在鼻梁或护架上；被击者头往后一顿、眼睛一眨，两脚原地站着，一秒能打两下。变体：只点在对方护架上量距离 / 连打两下后接后手重拳 / 点中鼻梁后鼻孔淌下一道血 | 他在画面左侧连出两记刺拳，一秒里两次点在对手鼻梁上，对手的头每挨一下就往后一顿、眼睛一眨，两脚仍钉在画面右侧三分线上。 | 未试 |

| 【通用】【写实】勾拳 / 从侧面兜过来一拳 / 弯着胳膊抡脸 | 勾拳 Hook | 手臂弯成直角，拳头沿水平短弧从侧面兜进来，落在颧骨、太阳穴或肋侧；被击者的脸扭向另一侧，额前头发甩到反方向，上身跟着拧过四分之一圈。变体：打在肋侧，对方侧弯腰护肋 / 打空，出拳的人自己转过半圈 / 左右勾拳连打，对手的头左右各甩一次 | 他左臂弯成直角，一记勾拳沿水平短弧从画面左侧兜进来，砸在对手颧骨上，对手的脸扭向画面右侧，额前的头发甩到另一边，上身跟着拧过四分之一圈。 | 未试 |
| 【通用】【写实】上勾拳 / 从下往上掏下巴 / 一拳把人掀起来 | 上勾拳 Uppercut | 拳头从腰下沿竖直短弧向上打进下巴底面，要先贴到对方胸前；被击者下巴猛地抬起、脸朝天，重的一拳让双脚离地半尺，落下后多接后倒。变体：打在腹部，对方弯腰对折 / 出拳后拳头停在头顶高度 / 被击者口中的血沫向上溅起 | 他矮身钻到对手胸前，一记上勾拳从腰下竖直向上打进对手下巴底面，对手的脸猛地朝天，双脚离地半尺，落下时向画面右侧直挺挺倒下。 | 未试 |
| 【通用】【写实】摆拳 / 抡圆了一拳 / 街头打架的大甩拳 | 摆拳 Haymaker | 手臂从肩后抡出一道大弧，弧度比勾拳大、起手看得见，路线从高往斜下；命中耳侧时被击者横着踉跄出去，落空时出拳的人自己转过半圈、背朝对手。变体：过顶往下砸的摆拳 / 两人同时抡摆拳互砸 / 酒馆斗殴里连抡三拳，一拳比一拳慢 | 他一记摆拳从肩后抡向画面左下，拳头砸在对手耳侧，对手横着踉跄两步撞上画面左侧的木柱，一手扶住柱子才站稳。 | 未试 |
| 【武侠】【写实】转身鞭拳 / 转一圈用拳背抽脸 / 回身甩手一拳 | 转身鞭拳 Spinning backfist | 出拳的人原地转过一整圈，手臂甩直，用拳背横抽在对方脸侧；抽中时对方的头被甩向一侧、人歪出两步，出拳的人衣摆张开成一圈；落空时拳背擦着对方鼻尖过去。变体：原地只用前手反背一抽 / 转身时先到的是肘尖（转身肘） / 抽中后接转身侧踹 | 他原地转过一整圈，衣摆张开成圆，一记转身鞭拳甩直手臂，拳背横抽在对手脸侧，对手的头被抽得甩向画面右侧，人向右歪出两步。 | 未试 |
| 【武侠】【写实】连环冲拳 / 咏春那种一串直拳 / 拳头连成一条线往前打 | 连环冲拳 Chain punch | 两拳沿身体中线轮流直线冲出，一秒四五拳，拳头在胸前连成一条线；对手的护架被一拳拳打开，一步步后退，后背抵上墙才停。变体：冲拳全打在对方交叉的前臂上 / 最后一拳加重，把人打得撞墙弹回 / 配合碎步一路前压三米 | 他两拳沿中线轮流冲出，一秒四拳，连环冲拳连成一条直线打在对手胸口和前臂上，对手一步步退到画面左缘，后背贴上土墙。 | 未试 |
| 【武侠】寸拳 / 贴着胸口一拳打飞 / 拳头一顶人就飞了 | 寸拳 One-inch punch | 拳面停在对方胸前一寸，手臂只往前一顶，对方整个人向后弹出去；看点是出拳幅度小、被击者飞得远，拳面贴着的衣服起一圈皱。变体：被击者双脚先离地 / 撞翻身后的椅子或围观的人 / 放在一场打斗的收尾 | 他的拳面停在对手胸前一寸，一记寸拳只往前一顶，对手整个人向画面右侧弹出两米，撞翻身后的木椅，椅腿断成两截。 | 未试 |
| 【武侠】【写实】顶肘 / 用胳膊肘往前撞 / 贴身一肘撞胸口 | 顶肘 Elbow thrust | 前臂横在胸前，肘尖朝前直线撞出，距离只有半步；撞进胸口或心窝时对方前襟凹下一块、弯腰后退，是八极拳进步贴身的招牌动作。变体：进步顶肘，前脚踏地踩起一圈尘土 / 对方双掌护胸仍被撞退 / 向后撞背后偷袭者的后顶肘 | 他前脚抢进半步，一记顶肘沿胸前直线撞进对手心窝，对手前襟凹下一块，弯着腰向画面右侧连退三步，双手捂住胸口。 | 未试 |
| 【写实】横肘 / 胳膊肘横着扫脸 / 贴脸一肘 | 横肘 Horizontal elbow | 手臂折起，肘尖沿水平方向横扫过下巴或颧骨，两人之间只剩一拳宽；扫中时对方的头被打偏，眉骨或额角被肘尖划开一道口子。变体：左右两肘连扫 / 一手按住对方后颈再横肘 / 肘尖只擦过额头，划开眉骨 | 两人贴到只剩一拳宽，他右臂折起一记横肘，肘尖刮过对手颧骨，对手的头被扫向画面左侧，眉骨上裂开一道指节长的红口子。 | 未试 |
| 【写实】砸肘 / 胳膊肘从上往下砸 / 砸后背 | 砸肘 Downward elbow | 肘尖从头顶高处竖直往下砸，落在对方后背、后颈或抓来的手臂上；被砸者上身塌下去、双膝着地，多用在对方弯腰抱腿冲过来时。变体：跳起来的飞身砸肘 / 砸在对方手腕上，对方松手 / 砸向倒地对手的胸口 | 对手弯腰扑向他的腰，他一记砸肘从头顶竖直落下，肘尖砸在对手后颈，对手整个上身被砸塌，双膝跪进画面下缘的尘土里。 | 未试 |
| 【武侠】【仙侠】推掌 / 一掌把人推出去 / 掌根打胸口 | 推掌 Palm strike | 手掌立起，用掌根直线推在下巴或胸口，比拳更推人；被击者整个人向后平移，鞋底擦地后滑，胸口留下一个灰扑扑的掌印。区别于 action-terms 07 的倒滑：这条写掌击本身和掌印。变体：双掌齐推，把人推出三米 / 掌根向上托下巴，对方仰头 / 仙侠版掌心推出一圈半透明的气浪 | 他立掌推出，掌根按在对手胸口正中，对手整个人向画面左侧平移两米，鞋底在青石板上擦出两道灰痕，胸前留下一个巴掌大的灰掌印。 | 未试 |
| 【武侠】【写实】劈掌 / 手刀 / 用掌边砍脖子 | 劈掌 Knife-hand strike | 五指并拢成刀形，用掌外沿斜劈颈侧、锁骨或后颈；劈中时对方肩膀一塌、身子一软歪倒；劈在木板或砖上能把它劈成两截，常用来亮功夫。变体：劈后颈，对方软倒 / 劈手腕，兵器掉落 / 双掌交替连劈 | 他五指并拢，一记劈掌从画面右上斜劈下来，掌外沿砍在对手颈侧，对手肩膀一塌，身子软着向画面左下歪倒，侧脸贴到地面。 | 未试 |
| 【武侠】【写实】贯手 / 指戳 / 手指头戳喉咙 | 贯手 Spear hand | 四指或两指并直，指尖直线戳向咽喉、眼睛或肋下，行程只有一小臂长；戳中咽喉时对方双手捂喉、弯腰连咳、后退。变体：二指戳眼，对方捂眼后仰 / 指尖戳进肋下，对方侧弯腰 / 连戳三处，一秒三下 | 他四指并直，一记贯手从胸前直线戳进对手咽喉，对手双手捂住脖子，弯腰连咳，退到画面右侧的墙根。 | 未试 |
| 【武侠】【仙侠】点穴 / 一点人就定住了 / 定身 | 点穴 Pressure point strike | 两指点在胸口、肩窝或颈侧，点中处衣服陷下一个指尖大的小坑；被点者整个人定在出手的姿势里，只剩眼珠在转。要有武侠或仙侠设定做来源。变体：点哑穴，嘴一张一合只出气声 / 解穴时在同一处补点一下，人一软 / 仙侠版点中处亮起一粒米粒大的光点 | 他两指点在画面右侧对手的右肩窝，衣服陷下一个指尖大的小坑，对手整个人定在挥拳的姿势里，拳头停在他脸前一掌，只剩眼珠左右转动。 | 未试 |
| 【武侠】【写实】鹰爪扣面 / 抓脸 / 一把按住脸往后推 | 鹰爪扣面 Claw strike | 五指弯成钩扣住对方的脸，把整颗头往后推按，或指尖从额头一路抓到下巴；被抓者的视线被手掌挡住，头被按着后仰撞上墙或地面。变体：扣住头发往下扯，对方弯腰 / 扣脸推开后接膝撞 / 指甲在脸颊划出三道红痕 | 他五指弯成鹰爪扣住对手的脸，把整颗头按着往后推，对手后脑撞上画面左侧的土墙，墙皮崩下一片巴掌大的灰。 | 未试 |
| 【通用】耳光 / 拍 / 一巴掌抽过去 | 耳光 Slap | 张开的手掌横着抽在脸颊，声音响、伤得轻，被抽者的头偏向一侧，脸上浮起五道红指印；多用于羞辱、挑衅或把人打醒。变体：正手抽完反手背再抽回来 / 一巴掌把人抽得转半圈 / 抽完手停在半空 | 他张开右掌一记耳光横抽在对手脸上，啪的一声，对手的头偏向画面右侧，脸颊浮起五道红指印，一缕头发落到眼前。 | 未试 |

## B 腿法与膝

| 口语说法 / 效果名 | 术语（中 / 英） | 画面上会看到什么 | 可直接用的中文句 | 理解度 |

| 【通用】【写实】正蹬 / 一脚把人蹬开 / 抬腿往前踹肚子 | 正蹬 Push kick / Teep | 提膝后脚掌直线朝前蹬出，蹬在腹部或胸口，把对方推离；被蹬者对折着向后退三四步，拉开的距离比拳大，常用来截住冲过来的人。变体：蹬在大腿上，截住对方前冲 / 蹬在门板上把门蹬开 / 对方前冲时蹬中，对方一屁股坐倒 | 对手从画面右侧冲过来，他提膝一记正蹬踹在对手腹部，对手对折着向后退出四步，一屁股坐倒在画面右下的草垛前。 | 未试 |
| 【通用】【写实】侧踹 / 侧着身子踹出去 / 一脚踹飞 | 侧踹 Side kick | 身体侧对目标，脚跟或脚刀沿直线踹出，腿完全伸直，路线比正蹬长；踹中胸口时对方平着飞出去，身后的东西被撞倒。变体：低踹膝盖，对方的腿向后一折 / 踹在盾牌上，持盾人连盾带人倒滑 / 连踹两脚，第二脚更高 | 他侧身一记侧踹，脚跟沿直线踹在对手胸口，腿完全伸直，对手平着向画面左侧飞出三米，撞翻一排晾衣竹竿。 | 未试 |
