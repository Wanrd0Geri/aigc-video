# 运镜组合套路词库

> 用于：把"先跟后绕、推完再拉、震一下再拉开、甩出去再甩进来"这类成套的运镜，写成起幅 → 路径 → 落幅 → 一处可见结果，整段照用；单个运镜术语查 camera-terms，打斗运镜 M01–M10 在 camera-terms C 组，这里只引用编号做组合。
> 读法：按小类标题 grep，不整份读

## A 追逐与跟拍组合

| 口语说法 / 效果名 | 术语（中 / 英） | 画面上会看到什么 | 可直接用的中文句 | 理解度 |
|---|---|---|---|---|
| 【通用】后跟转侧跟 / 先从背后跟再绕到旁边跟 / 跟着跑的时候转到侧面 | 后跟 Follow → 侧跟 Side tracking | 起幅：后跟，背影在画面中央、画框下缘切在腰 → 路径：边跟边向人物一侧弧线绕出九十度 → 落幅：侧面平行跟拍，侧脸可见，人物在画面一半、前方留白 → 结果：背景从向前延伸的巷子变成从画面边缘横着掠过的门框。变体：绕到正前方变成反向跟拍 / 绕的同时降到腰下 / 绕到侧面时人物正好回头，正脸转进画面 | 摄影机跟在他身后一米，他的背影在画面中央、画框下缘切在腰带，摄影机一边跟一边向他左侧绕出九十度，变成在他左侧两米平行跟拍，他的侧脸落在画面右半，巷子另一侧的门框一个个从画面左缘进、右缘出 | 未试 |
| 【通用】跟拍急停后拉 / 跑着跑着人刹住，镜头接着往后退 / 人急停镜头拉开看到前面 | 反向跟拍 Reverse tracking → 后拉揭示 Pull-back reveal | 起幅：反向跟拍，人物朝镜头跑，画框下缘切在胸口 → 路径：人物急刹的那一瞬摄影机保持原速继续后拉两三米 → 落幅：画框下缘退到他脚尖前方，露出悬崖、岔路或挡路的人 → 结果：揭示他为什么刹住；落幅停稳放在急刹之后。变体：后拉同时升高半层，看到崖下 / 后拉时镜头下摇，落在他脚尖前的断口 / 刹住的是马，马头高扬 | 反向跟拍，他朝镜头狂奔，画框下缘切在胸口，两边的树干一棵棵从画面两侧滑进来，他两脚一刹停住，摄影机保持原速继续后拉三米，画框下缘退到他脚尖前的崖边，露出崖下翻滚的云海，落幅停在崖边的他和崖下的云海 | 未试 |
| 【通用】追焦反跟 / 人从远处冲过来，镜头边退边跟焦 / 往镜头跑、越来越清楚 | 反向跟拍 Reverse tracking + 跟焦 Follow focus | 起幅：人物在画面深处，一团虚影 → 路径：摄影机匀速后拉，人物跑得比镜头退得快，在画面里由小变大，焦点一路跟在他脸上 → 落幅：近景，画框下缘切在胸口，背景糊成色块 → 结果：人物由小变大、由虚变实。和 camera-terms D 组"逆向拉移"的差别：加了跟焦，人从虚影里冲出来。变体：冲到近景后从镜头一侧擦过 / 后拉途中穿过一道门，门框从四边滑出 / 身后的追兵留在虚焦里 | 摄影机在巷子里匀速后拉，他从巷子另一头的虚影里朝镜头冲来，焦点落在他的脸上一路跟住，他跑得比镜头退得快，三秒里从画面中的一个小人涨到近景，画框下缘切在他的胸口，两侧的门框一个个从画面边缘滑进来，身后的巷子糊成一片灰影 | 未试 |
| 【通用】手持追逐 / 摄影师跟着一起跑 / 晃着追 | 手持 Handheld + 后跟 Follow | 起幅：追赶者身后一米，后脑在画面左上三分之一 → 路径：摄影机跟跑，画面边缘随步子上下左右不规则偏移，转角时墙角从画框边擦过 → 落幅：前方的被追者进入画面中央 → 结果：边缘偏移加上墙角擦过。晃动写成画面边缘怎么偏，剧烈晃动容易翻车（L075）。变体：跑上楼梯时偏移以上下为主 / 追到一半摄影机被路人撞了一下，画面猛偏一下又回来 / 夜里手电光圈跟着晃 | 手持，摄影机跟在追赶者身后一米一起跑，画面边缘随他的步子上下左右不规则地偏移，他的后脑落在画面左上三分之一处，转过巷角时墙角从画面右缘擦过去，前方的被追者进入画面中央 | 未试 |
| 【通用】擦身转跟 / 人从镜头旁边跑过去，镜头转过来追 / 迎面擦过后转身跟上 | 反向跟拍 Reverse tracking → 摇 Pan → 后跟 Follow | 起幅：人物迎着镜头跑来，画框下缘切在膝盖 → 路径：人物从镜头一侧擦过，摄影机向同侧摇一百八十度咬住背影，随即起步跟上 → 落幅：后跟，背影在画面中央 → 结果：前方的街景从他身后换到他前面。变体：擦过的一瞬衣摆扫过画面一角 / 摇过去时追兵从另一侧入画 / 摄影机起步晚半步，背影先变小再被追近 | 他迎着镜头跑来，画框下缘切在膝盖，从镜头左侧擦身而过，摄影机随即向左摇过一百八十度咬住他的背影，接着起步跟在他身后两米，他的背影落在画面中央，前方的路灯一盏盏从画面两侧退出去 | 未试 |
| 【通用】侧跟穿柱 / 跟拍的时候前面一根根柱子挡过去 / 隔着廊柱跟着跑 | 侧跟 Side tracking + 前景擦镜 Foreground wipe | 起幅：隔着一排廊柱侧面平行跟拍，人物在画面一侧 → 路径：近处的廊柱依次从画面一边扫进、另一边扫出，每根挡住人物半秒 → 落幅：廊柱走完，人物完整露出 → 结果：前景快速掠过、人物位置稳定。变体：柱子换成奔跑中的马腿 / 柱子之间透出的光一明一暗 / 廊柱走完时人物正好跃下台阶 | 摄影机隔着一排廊柱在他右侧三米平行跟拍，他在画面左半，近处的廊柱一根根从画面右缘扫进、左缘扫出，每根挡住他半秒，第4秒廊柱走完，他完整地露出来，冲上画面右侧的台阶 | 未试 |
| 【通用】高跟降到贴地 / 从高处跟着拍一路降到地面 / 跟拍时镜头降下来 | 跟拍 Tracking + 降机 Crane down | 起幅：二楼高度俯拍跟拍，人物在画面中下部 → 路径：边跟边下降 → 落幅：贴地低位跟拍，脚步从画面下半踏过 → 结果：两侧招牌从画面上缘升出画外，地面水花迎着镜头。和 M06（贴瓦掠行 + 上挑）方向相反。变体：降到贴地时正好有人从镜头上方跃过 / 降机时穿过一层晾着的布 / 降到马蹄的高度跟马 | 摄影机在他身后三米、从二楼的高度俯拍跟着他跑，他在画面中下部，边跟边降，四秒降到贴着石板，他的脚掌一步步踏过画面下半，每一步溅起的水花迎着镜头扑过来，两侧店铺的招牌从画面上缘升出画外 | 未试 |
| 【通用】顶拍追逐 / 从天上往下看两个人在巷子里追 / 无人机顶着追 | 顶拍 Top-down + 航拍跟随 Drone tracking | 起幅：顶拍，巷子从画面下缘竖直通到上缘 → 路径：高空平移跟随，两侧屋顶从画面下缘退出；拐弯时摄影机顺着拐角旋转九十度 → 落幅：新的巷子重新竖在画面中央 → 结果：屋顶退出加上画面旋转。变体：两人在十字路口分开，摄影机选一个跟 / 屋顶上的晾衣杆一根根横过画面 / 夜里只看见两团灯火在巷子里移动 | 顶拍，巷子从画面下缘竖直通到上缘，两个人一前一后在画面中央沿巷子向画面上方跑，摄影机在高空跟着平移，两侧的屋顶一片片从画面下缘退出去，他们拐进横巷时摄影机顺着拐角旋转九十度，横巷重新竖在画面中央 | 未试 |
| 【通用】反跟移焦看追兵 / 跑的人在前面，焦点换到后面的追兵 / 前面糊掉看清后面追来的人 | 反向跟拍 Reverse tracking + 移焦 Rack focus | 起幅：反向跟拍，被追者近景，焦点在脸上 → 路径：跟拍不变，焦点移到身后的追兵，再回到脸上 → 落幅：焦点回到被追者脸上 → 结果：前后两层轮流清楚；每段焦点都有实物落点（L058）。变体：追兵骑马，焦点转到马头 / 焦点移到追兵手里举起的弓 / 被追者回头，焦点跟着回头的方向转 | 摄影机在她前方两米反向跟拍，两边的摊棚一个个从画面两侧滑进来，她的脸在画面右半，焦点落在她的脸上，第2秒焦点移到她身后二十步的三个追兵身上，她的脸糊成一团，追兵手里的刀光亮起来，第4秒焦点回到她的脸上 | 未试 |

## B 揭示组合

| 口语说法 / 效果名 | 术语（中 / 英） | 画面上会看到什么 | 可直接用的中文句 | 理解度 |
|---|---|---|---|---|
| 【通用】局部升起揭示全景 / 从一个小东西升起来看到整个场面 / 从地上的头盔升到整个战场 | 摇臂升起 Crane up + 下摇 Tilt down | 起幅：近景拍地上的一件局部物（头盔、断剑、一只鞋）→ 路径：垂直升起同时下摇，让那件物保持在画面中间、一路变小 → 落幅：大全景，画框两边切在场地两端 → 结果：物件缩成一个点，四周铺满同类的东西，揭示规模。和 camera-terms D 组"升起显小"的差别：起点是一件物。变体：物件是一只小孩的鞋，升起后看到空荡的村子 / 升起时穿过一层烟 / 升到顶后缓慢旋转 | 起幅是泥地上一顶翻倒的头盔，占住画面下半，摄影机垂直升起、同时向下摇，头盔在画面中间一路变小，五秒升到半空，画框两边切在战场的两头，头盔缩成画面中央一个亮点，四周铺满倒下的旗帜 | 未试 |
| 【通用】绕过前景揭示 / 绕过柱子看到后面的人 / 从树后面绕出来 | 弧线移动 Arc | 起幅：前景一根柱子或一棵树占住画面一半，后面的东西被挡住 → 路径：摄影机贴着前景物弧线绕过去 → 落幅：前景物从画面边缘滑出，后面的人进入画面，中景 → 结果：被揭示。变体：前景是人群的后背，一个个滑开 / 绕过的是一块巨石，露出后面的营地 / 绕过去时后面的人正好抬头 | 起幅里一根朱漆柱子占住画面左半，摄影机贴着柱子向右弧线绕过去，柱子从画面左缘滑出，柱后坐在台阶上的老人进入画面，落幅停在他的中景，画框下缘切在他的膝盖 | 未试 |
| 【通用】从背后绕到正面 / 先拍背影再转到脸 / 绕到前面看清他的脸 | 环绕 Orbit（半圈） | 起幅：人物背影近景，画框下缘切在肩胛 → 路径：肩膀高度绕半圈，发髻、耳朵、侧脸依次转进画面 → 落幅：正面近景 → 结果：揭示正脸上的东西（伤口、面具、泪痕）；人物朝向不变，只有观看侧在变。变体：绕到侧脸就收住，表情先露一半（放在镜尾）/ 绕的同时慢推 / 正面才露出怀里抱着的婴儿 | 起幅是她的背影，画框下缘切在肩胛，摄影机在肩膀高度从她左侧绕过半圈，她的发髻、左耳、侧脸依次转进画面，落幅停在正面近景，额角那道还在渗血的口子露出来 | 未试 |
| 【通用】推过门框进入新空间 / 从门口推进去 / 穿过门进到屋里 | 推轨 Dolly in（穿越门框 Push through） | 起幅：门外中景，门框框住画面四边 → 路径：慢推穿过门框，门框从画面四边滑出 → 落幅：屋内全景 → 结果：新空间展开，屋里的人对进门作出反应。和 camera-terms D 组"遮罩转场"的差别：这一条连续进入，遮罩转场中间有暗场。变体：门框换成山洞口，洞外的光从四边退出去 / 穿过门时门帘擦过画面上缘 / 进门后继续推向屋里最里面的一个人 | 起幅是半开的木门，门框框住画面四边，摄影机慢推穿过门框，门框从画面四边滑出去，屋里的烛光扑进画面，落幅是屋内全景，画框两边切在两面墙上的挂画，桌边的三个人同时抬起头 | 未试 |
| 【通用】鸟瞰下压到人物 / 从天上一路降到人面前 / 航拍降下来落到人 | 顶拍 Bird's-eye → 航拍下降 Drone descent → 平拍 Eye level | 起幅：顶拍大远景，人物是一个点 → 路径：垂直下降，边降边把镜头从朝下抬成平视 → 落幅：平拍中近景 → 结果：人物从一个点涨到中近景。变体：降的途中穿过一层云 / 落到人物背后，变成过肩 / 下降同时旋转半圈 | 顶拍大远景，荒原上的他只是画面中央的一个黑点，摄影机垂直下降，边降边把镜头从朝下抬成平视，五秒后落到他面前两米，平拍中近景，画框下缘切在他的腰带 | 未试 |
| 【通用】拉出揭示 / 从特写一路退出来看到周围 / 拉开才知道在哪 | 拉轨 Dolly out（拉出揭示 Pull-back reveal） | 起幅：大特写（手、一件小物）→ 路径：匀速后拉，周围的东西依次进入画面 → 落幅：全景 → 结果：前后反差揭示所在的环境。变体：拉到最后发现手是从栏杆外伸进来的 / 后拉途中穿过窗框，人物被框在窗里 / 后拉同时升高 | 起幅是捏着一枚黑棋的两根手指的大特写，摄影机匀速后拉，手、棋盘、对坐的两人依次进入画面，第4秒画框两边退到两人身后的崖壁，这张棋盘摆在一块悬空的石台上，脚下翻滚着云 | 未试 |
| 【通用】上摇揭示巨物 / 从脚往上看到巨人的脸 / 抬头看到一个庞然大物 | 俯仰 Tilt up + 拉轨 Dolly out | 起幅：巨物的一只脚或底座占住画面下半 → 路径：边后拉边上摇，膝、腰、胸依次升过画面 → 落幅：巨物的头部在画面上三分之一，下方有人做尺度参照 → 结果：尺度被揭示。变体：巨物是一尊佛像，起幅是佛像的指尖 / 上摇到顶时巨物正好低头 / 夜里只靠脚下的火把照亮 | 起幅是一只踩进泥地的巨大石脚，占住画面下半，摄影机一边后拉一边向上摇，膝、腰、胸依次升过画面，第5秒落幅停在它低头俯视的石脸上，石脸占画面上三分之一，下方的士兵只有它脚趾高 | 未试 |
| 【通用】推近移焦揭示 / 前面的东西糊掉后面的人出现 / 焦点一换，门口有人 | 推轨 Dolly in + 移焦 Rack focus | 起幅：前景物清楚、背景人虚 → 路径：慢推同时焦点移到背景 → 落幅：背景人物清楚，前景糊成色块 → 结果：揭示背景人物。变体：前景是镜子，焦点移到镜中人 / 焦点移到窗外的人影 / 焦点移过去时背景人物正好迈出一步 | 慢推，焦点落在前景桌面那封拆开的信上，门口是一团虚影，第3秒焦点移到门口，信糊成画面下方一块白，门口的黑衣人变清楚，他的手按在刀柄上，慢推到画框下缘切在他的腰带 | 未试 |
| 【恐怖】后景显现 / 人背后慢慢露出东西 / 她没看到但我们看到了 | 横移 Truck + 后景揭示 Background reveal | 起幅：近景人物在画面一侧，身后被她的肩膀挡住一块 → 路径：摄影机向另一侧慢移半米，她身后原来被挡住的门洞或窗口露出来 → 落幅：人物和身后的东西同框 → 结果：观众先于人物看见；焦点留在人物身上，后景的东西保持模糊。变体：身后是镜子，镜中多出一个人 / 慢移时身后的影子动了一下 / 露出来的是一双悬着的脚 | 近景，她在画面右半低头洗脸，身后的走廊一片虚焦，摄影机向左慢移半米，她身后原本被肩膀挡住的门洞从画面中间露出来，门洞里站着一个模糊的白影，焦点落在她的后颈上 | 未试 |
