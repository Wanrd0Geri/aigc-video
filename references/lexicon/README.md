# 词库使用说明

> 用于执行清单第 ④ 步（把口语、抽象词翻译成术语 + 可见句）和第 ⑧ 步（把绕口的长描述压缩成模型认识的术语）。
> 读完必须产出：每个被翻译或压缩的词都附术语、可见句和理解度标记，并写进表头"翻译"行；反向压缩的结果直接进提示词。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)（**需要把某条词条的理解度改成已试、或要核对证据档位时再读**）：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。

四张表，**要查哪一类就只读哪一张，不四张都读**：需要运镜、构图、光学时读 `camera-terms.md`；需要动作、受力、身法时读 `action-terms.md`；需要光线、色彩、材质、天气、特效介质时读 `light-material-terms.md`；需要表情、眼神、肢体、关系时读 `performance-terms.md`。

统一五列：**想要的效果或口语说法 ｜ 术语（中/英） ｜ 画面上会看到什么 ｜ 可直接用的中文句 ｜ 理解度**

理解度列不是创作白名单，也不是使用频率排序。专业方法是否采用，先看当前任务；“未试”不等于不可靠，“已试”不等于本镜最优。

前三个是官方的术语分档，决定怎么写：
- **直写**：官方说可以直接写（景别、推拉摇移跟环绕、低角度俯视、第一人称、手持、慢动作）。
- **热门**：官方说可直接写，但要说明围绕谁、从哪到哪（一镜到底、希区柯克变焦、航拍、FPV、子弹时间、回弹变速）。
- **需解释**：小众术语，写成"术语 + 作用主体 + 画面变化 + 前景背景关系 + 方向速度"。

其余只有两档，说明本项目试没试过：
- **未试**：本项目没有成片或截图对得上（包含原来的"外部好""待验"）；用时后面跟一句可见结果作保险，不裸用。
- **已试**：本项目有能定位的成片或截图对得上，备注 L 编号；**已试不稳**表示已试过但有条件性不稳记录，核对模型、语境、素材与具体风险，必要时补足控制，不默认回避整个术语或手法。

正向用法：用户说"想要人不动、背景挤过来的感觉" → 查 camera-terms 得"滑动变焦 Dolly zoom" → 用可见句"镜头后撤同时变长焦，人物大小不变，身后通道被压紧" → 标"热门"。
反向用法：先辨认真正重复的语义，再查表看是否存在等价、清楚的术语。仅在起点、路径、速度、触发、终态与接力等独立控制完整保留时压缩，不按句数强制合并。理解度是"未试"或"需解释"时保留可见结果句。
改标记：要把一条改成"已试"，必须有能定位的成片或截图对得上这个用法，并备注 L 编号；没有就留"未试"。次数只记录样本量，不按两次/三次自动归因。
