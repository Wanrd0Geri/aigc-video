# 光线、色彩、材质、天气与特效介质词库

> 用于第 ④ 步（翻译）与第 ⑧ 步（压缩）。稳定光源与共享光影原则写全局，镜内只写关键事件那一刻的受光和本镜里光的变化（writing-rules 第 44 条）；特效句写进所属镜头。
> 读完必须产出：光 = 方向 + 色温 + 质感；材质 = 触觉线索；天气 = 物理反应（写场景段一次）；特效 = 来源 + 路径 + 接触 + 残留。
> 经验的证据与采用规则以 [../lessons/README.md](../lessons/README.md) 为唯一准则：分清"试过的"和"没试过的"，没试过的照常可用但不冒称已验证；经验不能覆盖用户锁定项或已确认事实。✓ 标记 = 旧 skill 历史单例曾正确渲染（版本与结果定位不全，按"未试"处理）。

## B 色彩

| 口语说法 | 术语 | 画面上会看到什么 | 可直接用的中文句 | 理解度 |
|---|---|---|---|---|

| 压抑、年代感 | 去饱和 / 灰调 | 低饱和 | 色彩饱和度偏低，整体呈莫兰迪色调 | 未试 |

| 冷色 / 暖色含义 | 色彩情绪 | 冷 = 疏离科技忧郁；暖 = 温馨怀旧；高饱和 = 活力超现实 | 写颜色时同时写它的来源 | 未试 |

阵营色系（打斗特效，选一不叠）：天威霸道 = 赤金、金红（裂隙、洪流、巨日）；冷静守御 = 深蓝、蓝白（镜海、水墙、漩涡）；雷法天罚 = 金雷、白金（雷柱、电弧网）；邪魅魔功 = 血红、暗红（血雾、绸带、红瞳）；仙气星辰 = 紫白、银紫（星月背轮、光柱雨）；妖异兽性 = 橘焰、黑金（兽形虚影、怒焰鬃毛）；生机木系 = 青绿、玉色（法环、藤蔓、玉光）。赤金攻方 vs 深蓝守方 ✓。

## E 特效介质机制（专业词 → 可见行为）

| 口语说法 | 术语 | 可见表达 | 易混淆 |
|---|---|---|---|
| 有流体感 | 平流 Advection | 烟焰或颜色被主流向带走，绕过障碍后顺势偏折 | 先说哪种介质在流 |
| 边缘翻卷 | 涡卷 Vortical roll-up | 大轮廓边缘卷成薄涡，随主流迁移消散 | 不是整束变龙卷风 |
| 更乱更活 | 湍流 Turbulence | 大流向内叠加不同尺度的扰动 | 微噪不能代替宏观路线 |
| 烟往上飘 | 浮力 Buoyancy | 热气失去推动后上升摊开 | 高速喷射阶段由动量主导 |
| 烟薄厚不一 | 密度 / 消散 | 薄处透背景，厚处遮挡，随时间变稀 | 变暗不等于消失 |
| 从里面透亮 | 自发光 / 体积散射 | 亮源从半透明介质间隙透出并照亮内侧 | Bloom 只是亮边扩散 |
| 空气被烫弯 | 热扰动 / 折射扭曲 | 局部背景轮廓摇曳 | 冰冻效果不默认热浪 |
| 火星拖尾 | 粒子尾迹 | 明亮头部后接变细变暗的路径 | 尾迹不是运动模糊 |
| 碎粒有重量 | 弹道运动 | 沿弧线下降，接触后反弹 | 魔法粒子可无重力 |
| 光照到旁边 | 交互照明 | 明确接收面、距离与时序 | 不是全画面加滤镜 |
| 冰在长 | 结晶前沿 | 霜纹从接触点沿表面蔓延 | 不与凭空厚冰混为一谈 |
