# 改现有提示词

> 用于路由"改现有提示词"：优化、修复、局部调整已有的稿。
> 读完必须产出：只改授权字段后的完整受影响单元（整镜 / 整序列 / 全稿 / 整条操作命令）+ 变更摘要 + 一行检查。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。

## 1 取基准

用最新的完整稿加后续有效更改作基准；有摘要时用它定位原稿，不把摘要扩写冒充原稿。候选稿和实际提交稿分开记。缺原稿时可以交付明确标为"重建候选"的稿，不假称未改字段已逐字核对。

## 2 三种简化不是一回事

- 文字简化：只去重、合并、自然化，保留动作因果、独立控制、有效锁；"简短一些但意思不变"只授权这一种。
- 设计简化：减少动作、人物任务、运动距离、摄影负荷；只动用户已开放的字段。删形容词不能解决动作容量问题。
- 执行拆分：改变镜数、切点、生成段落；按结构改动检查时间、连续镜头和边界。
"完整提示词"要求完整交付当前版本，不授权从摘要重造未受影响的镜头。用户同时授权多种改变时一次完成必要依赖，不逐项批准。

## 3 限定变更

- 默认继承现有标题、分区顺序、素材标记、时码表示、声音放置；检查时给 `--baseline 父稿`（默认 `--format 继承`：父稿有什么标题、什么顺序，新稿必须一样），`--task` 仍写命令性质（生成 / 编辑 / 延长 / 衔接），不为通过新稿的五段检查迁移外壳——六段旧稿的修订仍交付六段，必填词仍留在概述段。"用 skill 修改""加强张力""用词库"不单独授权换格式；用户明确说"按 skill 标准格式重编译"这类话才换，换时检查加 `--format 五段`。格式迁移不开放未授权的剧情、动作、运镜。
- 在原稿上改：保留未受影响的有效句子；不先压缩全部再重新扩写。
- 替代还是补充：新说法只有在与旧说法管同一字段、含义不能共存，或用户明确替换时才替代；细化或加条件是补充。最新一条消息没提某个已接受的事实，不等于取消。结果会变又推不出是哪种时，问一次。
- 只改语言时受保护、不得动的：素材标记与顺序、主体数量与身份、镜头数与顺序、锁定的时长与时码、台词旁白歌词画面文字、静音音乐字幕锁、任务类型和编辑延长衔接的必填词、动作顺序、画面方向、继承状态、终态、用户保留的运镜与构图。不把"向后延长@视频1"改成"参考@视频1"。

普通的同音替换按 SKILL.md 用户偏好及 quality-gate.md 发音映射执行；不因此改写其他字段。当前明确字形逐字锁优先。

## 4 相机改动不加动作

摄影默认运动偏好仅作用于本次获准设计的摄影字段；未授权修改的父稿或源视频摄影须保留，记录 preserved。只改机位、角度、景别、运镜、变焦时，重算取景、可见范围、遮挡、画面方向、焦点、受光面；不加转头、转身、视线移动、手势、换位来让锁定的动作更好看。选授权范围内的相机方案，或保留动作的可见性限制；两个锁定要求确实不能共存才问。

## 5 改了什么就复查什么

| 改了 | 复查 |
|---|---|
| 场景区域、门窗、锚点、距离、高度 | 每个用到它的路线、边界位置、取景、可见人物、遮挡、光向 |
| 可见人物、位置、朝向、路线、深度 | 取景、画面顺序、遮挡、画外线索、视线与身体轴、接触、受光面、终点、相邻镜交接 |
| 机位、视角、景别、轴线、运镜、变焦 | 可见范围、第一人称自我可见、过肩前景、嘴部可见、投影方向、遮挡、透视、焦点、光向、边界；可见性损失不授权补动作 |
| 画面重心、焦平面 | 主体主次、次要主体可见、动作可读、结束画面、继承它的下一镜 |
| 锁定动作或终点 | 时序、表演任务、接触物理、世界响应与残留、终态、下一镜开场、打斗接力状态 |
| 台词、旁白、音色、字幕、声音 | 内容与说话人、可见性、口型需求、说话时长、嘴部可见、倾听者反应、声音连续、切点分配 |
| 表演意图 | 主要载体、视线目标、姿态接触、倾听者反应、节奏、终点 |
| 严格编辑的对象颜色材质外观删除 | 该对象在现有倒影、影子里的结果；不动无关表面、光源、运动 |
| 光源、方向、强度、曝光 | 主体受光、接触影、纵深、相邻镜 |
| 世界驱动、物理响应、稳定锁 | 模式、受体、力学、相位、残留、跨镜交接 |
| 时长或镜数 | 每个镜头时码、锁定的镜内时间、动作对白容量、切点、操作区间、终点 |
| 全局风格、场景、平台、政策 | 每个用到它的镜头与操作 |
| 素材职责、上传顺序、版本 | 该素材授权的每个字段与镜头；退役的版本不再出现 |
一个改动的终点变成另一镜的开场，或共享状态跨镜时，扩大到下一个稳定边界为止，不因用户只点名一镜就停在镜界。复查是义务，不是改另一个锁定字段的许可；"联动修改"不是授权来源。

## 6 素材替换与独立镜头

换主要参考、减人物、抽单镜时：区分图中可见事实、用户授权的新设计、已被替代的旧约束；只改数量或参考图不自动重做整段。删失效的身份绑定、动作来源与指代，同步核对旧人物的交互、空间、声音、终态；按本次实际上传顺序重新绑定，不机械搬旧编号，也不删仍有独立用途的参考。原图不等于首帧，用途已指定就沿用。单镜从序列变成独立生成时，最短 4 秒，不照搬原镜短时码。

## 7 视觉要求保留检查

改写前列出现有稿里所有有效的风格渲染、材质、光影色彩曝光、光学构图、运动重量、表演要求；改写后每条都能在新稿里找到主人。精确锁定的短语逐字保留；可以搬家、合并真同义词，但不能把几个独立控制压成"电影感""真实""质感统一"。"改构图"不授权简化风格段；"简短点"不授权删掉一个有效控制。删或改一个要求只在当前请求授权、被更高权威事实替代、或在交付范围内确属重复或失效时。

## 8 修改历史不进提示词，反馈不滚雪球

视频模型没有上一版、上一镜、上次生成的记忆，每条提示词都是它第一次读到的东西。用户说"这镜不要 X"，步骤固定：① 找到引出 X 的原句；② 删掉或改写成当前应有的正向状态；③ 只有找不到正向写法时才留一条局部否定；④ 禁止项从零重推，不在旧清单上加一条。提示词里不得出现"不要像上次那样""上一版""这次改成"。连续几轮修改后如果禁止项只增不减、正文越来越长，说明在滚雪球，回到最新确认的表重写受影响镜头。
诊断语言、排除项、修复理由留在提示词外。"之前生成成了石头"写成预期的枝干；"不要再重复投掷"写成"手臂已完成跟随动作，物体已离手"。保留用户明确的排除项和操作类的保持句；其余优先正向控制，只在没有等价正向写法时留一条局部否定。

## 9 交付范围

- 完整镜：改动和依赖都在一镜内。
- 完整序列：交接、共享状态、对白时序、光与世界连续、位置跨多镜。
- 全稿：素材映射、场景风格规则、平台语法、总时长、镜数、全局政策变了。
- 完整操作命令：编辑、延长、衔接，含母版、区间或方向、完整改动或新增段、继承边界、保持内容。
不交付孤零零的替换句、字段或否定补丁；不重写未受影响的镜头。替换稿要说明它替换的是哪个父稿的哪一段；独立稿要包含全部需要的素材、场景、风格、声音绑定。

## 10 增量输出格式

```
变更摘要（放在代码块外）：
- [直接改动，写清授权字段]
- [只在依赖确实变化时写联动，并说明为什么]
- [复查了哪些依赖；未列出的镜头沿用已确认版本]
- [替换稿说明它替换的是哪个父稿的哪一段]

（代码块内只放完整受影响单元，干净可粘贴，不带任何修改标记；同一单元内未改的句子照抄）
```
不写"已完成内部全量校验"这类没有依据的回执；做了什么检查就写什么。
交付前跑 `python3 scripts/check_prompt.py --prompt 新稿.txt --task 生成|编辑|延长|衔接 --baseline 父稿.txt [--lock "锁定台词"] [--unchanged 1,3] [--partial] [--total 秒]`，保存机械检查结果，但交付结论使用后续 verify_delivery.py 的 `summary`；`--partial` 表示只交了被改的镜头：段里只放镜头块（不带结尾段和固定句），脚本校验镜号、时码与父稿一致后放回父稿合成完整稿检查，不要求它从镜头 1、0 秒重新开始。用户要求先看方案、或两个锁定要求冲突需要用户选时才先给受影响行的表；改机位、站位、终点本身不触发等待。

修改默认走轻量路径：check_prompt 无错误、警告逐条裁定、作者核对完成即可交付，不建需求文件、不跑 verify_delivery。只有走全套路径时（用户要求严格审、事先约定的审核节点，或这是全新 L3 稿的第一版，见 SKILL.md「流程分级」）才执行 `quality-gate.md`：保留原始请求与父稿版本，对覆盖镜头之外的依赖照样复核；所有警告有裁定，最终用 verify_delivery.py 放行。用户只要受影响镜头时使用 `--partial --output-scope affected`，完整父稿仍参与全部依赖检查。机械通过不能单独作为交付结论。
