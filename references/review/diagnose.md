# 成片诊断：逐句兑现、归因、修法、写入经验库

> 用于路由"回传视频 / 反馈"：用户给了生成的视频、截图，或描述了问题。
> 读完必须产出：逐句兑现表 + 归因 + 最小修法（用户要求修改时交完整受影响单元，只要评估时给建议）+ 一条新观察（主题、现象、修法是否试过、置信度、来源定位）+ 词库理解度调整建议；若已触发第 8 节的两次失败规则，则产出换方法的选项交用户选，而不是新措辞。
> 本次结论先记为观察；写入 `../lessons/seedance-2.5.md` 看当次授权。

## 1 收集

- 成片文件；实际提交的提示词原文（不是候选稿；不确定就写 UNKNOWN，不用文件名、时间接近或时长匹配冒充配对）；素材顺序与职责；模型与设置；这是第几次跑。
- 分开记：用户的反馈、我的直接观察（看的是截图、连续帧、视频还是音轨）、历史记录、假设、已确认发现。
- 先分清反馈性质：既定目标没兑现是纠错；用户新提的构图、节奏、风格是偏好更新，走 `revise-rules.md`，不把新偏好记成旧稿失败。同类偏差再次出现时先查上一版候选是否真的提交、修改是否可见、是否还在重复同一假设。

## 2 抽帧

```bash
bash scripts/extract_frames.sh <视频> [输出目录] [每秒帧数]
```
得到首帧、真正的最后一帧（时间在 last.txt）、每秒一帧、切镜检测帧（切点时间在 cuts.txt）和拼图；用 Read 打开拼图看。脚本退出码 3 表示切镜检测失败但首尾帧与抽样帧可用，cuts.txt 里有原因，不要把失败当成"没有切点"；重复运行会先清掉上一次自己生成的图。切镜检测会把闪光误判成切点，核对相关帧。消失、显形、接触、切点、蓄力与释放这类快事件，在相关区间加密到连续帧再判断。抽帧只能定位切点和状态；正常速度的节奏、慢放体验、声音关系需要连续播放和听审，抽帧证明不了。

**帧间差分指标只在主体占满画面时可信（2026-09-22 踩过）**：用 `tblend=all_mode=difference` + `signalstats` 算相邻帧平均像素变化，量的是「整幅画面有多少像素变了」，不是「有多少运动」。后拉之后的大景别里，静止的天空、建筑、远山占掉绝大多数像素，一个又小又快的主体（半空中翻滚的人头）只让 3% 到 10% 的像素变化，读数低到 1.1，和「完全静止」分不开。本会话据此误判过一次「3.5 到 5.0 秒是死的」，实际逐帧看身体在拧、手臂在抡、人头在翻滚，动作齐全。做法：全幅帧差只用于主体占满画面的镜头；大景别改成①直接抽帧看拼图下结论，或②先 `crop` 到主体所在区域再算，并报「超过阈值的像素占比」而不是只报均值。读数低先问一句「是没动，还是动的东西小」，看过帧再下结论。

## 3 复核顺序

1. 镜头数、顺序、切点：要求的 vs 实际的。
2. 每镜取开场、动作中、终态三个代表帧，对照提示词：构图与裁切、可见人物与遮挡、机位与画面方向、动作终点、跨镜不变量（身份、服装、道具归属、位置、光向）、台词与画面文字。
3. 先定位原文是否已经要求该行为：写了受力、形变但结果不足，不能归因为"没写"；没写的先补写法再评价模型。

## 4 逐句兑现表（固定输出）

| 镜号 | 提示词句子 | 成片 | 归因 | 下一步 |
|---|---|---|---|---|
| 镜2 | 白猿的铁棒从画面右上方劈落 | 出现 | — | 记为一次同向（词条：劈棍） |
| 镜2 | 苏云护架被撞回胸前，整个人连退 | 部分：退了但没有护架 | 信息过载：同句三个动作 | 拆成两句，先护架后震退 |
| 镜3 | 目光看向画面右侧外 | 未出现：看向镜头 | 写法模型不懂 / 随机 | 先核对可见性、素材和原句；候选修法（没试过）为"头转向右侧，眼睛看向画外的地面" |

“成片”记录出现 / 部分 / 未出现。先核对实际提交稿、素材职责、可见性、时长和平台条件；措辞、素材影响、容量、平台能力与随机波动都是候选原因。一次或同输入两次失败不能单独确定原因。原因未知就保留未定；只有新增实验能区分明确假设、已有证据不足且获得相应生成授权时，才提出带判据的生成实验。

## 5 归因规则

- 五种"慢"不是同一件事：准备太长、跨镜重复准备、释放本身慢、镜头跟随让主体画内稳定显得慢、后果不明显。分别定位。
- 裁切没有足够方向证据时标"关系不清"，不直接判穿帮。
- 一次相关不是因果；成对成功失败只支持个案假设；同输入的一对成败可归为"生成波动"。
- 多项同改的成片不归功或归罪于某一句。
- 先查稿、再谈模型：把没做出来归因到“模型容量不够”“塞太多了”之前，先在稿子里找三样——几何或距离矛盾（站在尽头 vs 手臂贴镜）、只为防上一次失败而写的围栏句、没有终点的程度词（越变越大 / 越来越快）。多数“没做出来”是这三样之一，`check_prompt` 的距离链、程度词、串行运镜提醒就是查它们的。2026-09-22 灯笼怪一例先归因容量，用户指出是措辞，复查发现“站在透视线尽头”与“手臂贴着镜头掠过”矛盾。
- 参考姿势侵入（人物僵在参考图姿势）：先核实提交素材，区分参考姿势影响、原文"保持姿势"、动作或时长设置；不重复强化同义否定。素材选项：把图中姿势写成动作中短暂经过的状态；裁取可用场景区域；用无人场景；重新明确图片是首帧还是外貌参考。
- 动作与摄影分层诊断：有具体接触冲突时先简化为有可见位移的跟随或平移核对动作关系，再恢复完整摄影表现；固定仅依用户明确要求（含用户确认作者提议）或实际保护范围，不把"先固定一版"当默认排查手段。
- 只继承当前必需的位置锚：跨镜复述位置会影响执行，不无条件每镜复制。
- 先判断下列外部建议是否适合本次已知条件，不能自动套用或代替证据：脸漂移（大头照 + 全身照，重要素材前置）、双胞胎（命名绑定 + 约束句 + 单人图）、风格漂移（写画风或先转风格）、延长跳变（6 帧 / 1 帧）、延长劣化（白模续写、少续写）、字幕（横屏、去素材文字）、特效不准（参考视频）、人数超四（分组出图）、发音（同音字）、音色（补描述）、结尾噪音（淡出）。

## 6 下一步五类

重跑（同输入，带一个新假设和判据）/ 改词（一个字段对应可见失败）/ 改素材（内容、职责、版本、可读性）/ 改结构（锁定的负荷超过时长或单镜：时长过载 → 最小时长改动；单镜过载 → 在动作阶段边界拆成最少镜；混合 → 两者）/ 换工作流（平台硬限制或对照实验确认的边界）。原因不明时保持"未定"，仍可交付一个明确标注假设和判据的候选修复；不宣称原因已确立。

## 7 局部修复表

| 成片现象 | 最小修法 | 别做 |
|---|---|---|
| 画外人物或地标被拉进终帧 | 删掉只为连续性写的那句，保留最小可见线索 | 加人物黑名单、重写所有镜 |
| 场景变成动作路点 | 路线只写起点、方向、目标 | 删掉真正被接触、越过、破坏的场景 |
| 能量、烟、光变成实体 | 只改材料状态与主体性，保留轮廓尺度位置动作 | 堆"无实体 / 仅呈现 / 并非人物" |
| 素材职责泄漏 | 恢复该素材的职责句和"不采用" | 打印一整套禁用维度 |
| 编辑或延长被当成参考生成 | 恢复官方必填词，直接 `视频1` 指代 | 整个改成"参考视频" |
| 运镜互相冲突 | 保留锁定的，删掉冲突的可变运镜 | 加好几个替代运镜 |
| 时长或单镜过载 | 先简化可变的运镜和连接细节，再按第 6 节改结构 | 删或调换锁定的动作台词 |
| 出现文字、Logo、水印 | 去掉素材里不必要的文字，或加一条针对性约束 | 加通用否定尾巴 |
| 声音漂移、多余音效 | 只保留用户或素材提供的声音；写"不要任何声音"（全片静音写主体段末尾、只管一镜的写那一镜，并逐句点名，writing-rules 第 62 条）或"只保留对白与动作音" | 加一段音频政策 |
| 整体不稳但归不到某句 | 保留提示词，做一次带新假设的对照重跑 | 把所有字段一起收紧 |
| 巨物总被拍成全景 | 意图是冲击就换成出画、近场透视、遮挡、边缘局部人物 | 一律否定全景 |
| 两个主体总是等重 | 保留一个画面重心，另一个减到最小可见关系 | 删锁定主体或发明百分比 |
| 人物像贴上去 / 光从错的一边来 | 场景做光的主人，写主体重打光 + 接触影 + 纵深 | 加"光影统一" |
| 召唤物像小物体变大 | 先定最终空间轮廓，材料在分离区域各自成形 | 禁止所有生长 |
| 显形后定住或像参考姿势 | 收窄姿势类素材职责，显形直接接下一动作，保持一个运动载体 | 加一堆运镜 |
| 该拆解的效果被偏转带走 | 换成可见的失去结构链和原地终态 | 反复否定、换整套效果 |
| 要求的紧景别总变宽 | 删掉超出裁切的身体与地标要求，写一个可观察的裁切边界 | 重复"紧近景" |
| 侧向视线读成正视 | 写头、脸、眼的最小朝向链 + 可见目标 | 冻结全身 |
| 反应停在一个表情 / 一闪即回 | 重跑表演容量：起终对比、删竞争线索、终态保持到切 | 加情绪形容词、堆微动作 |
| 静止倾听者张嘴像在说话 | 删掉张嘴线索，把变化转到注意、头肩、下颌、姿态、距离 | 加全局口型禁令 |
| 切镜时人物无故转向彼此 | 把保留的世界朝向和位置写成新镜的现状，再把机位放在既定站位周围 | 堆否定朝向命令、为露脸转人 |
| 一镜到底中途被切成两镜 | 找到画面只剩空景的那一拍（主体全部出画、只剩空岩壁），改写成画里仍留着主体的一部分或另一个在场主体（L087） | 只加一句总括保证、不改那一拍 |
| 锁定不接触却总是接触 | 写可观察的分离终点（停在上方一寸后收回），终帧保持可见空隙作判据；裁切看不清就换景别 | 堆"绝不接触"、指望站位图 |
| 耦合世界全冻住 | 保住主动作，补最小的驱动 → 附属或接触 → 残留链 | 泛泛运动清单 |
| 衣叶水雾一起像一层皮在晃 | 一个驱动，按附着质量刚度深度分开时序 | 冻结环境或随机化 |
| 风向流向烟雾在切镜处重置 | 继承上一镜方向与相位再推进 | 因换机位重启 |
| 次要运动喧宾夺主 | 减少受体链或改成只写主动作 | 删掉所有物理响应 |
| 严格编辑后多出新动态 | 删注入的动态轴，继承原视频世界状态 | 改成参考生成 |
| 远景里要看见的人物没出现 | 写它占画面的比例和一个可见动作（"身高约占画面五分之一"，L110） | 写"米粒 / 拇指大" |
| 群体各看各的 | 写共同注视目标并在每个动作句里带上（L112） | 加"整齐""一致"这类词 |
| 飞行角色落地跑 | 删"贴着 / 蹬 / 四肢着地"，写离地高度与脚下空着（L116） | 加"飞行"标签 |
| 结尾要全遮挡却只占中央 | 写"铺满整个画面，最后半秒纯黑"（L118） | 写"占满画面中央" |
光影失败 6 行见 `../craft/lighting-color.md` 第 7 节。

## 8 两次失败换方法

本节是两次失败换方法的唯一维护处；SKILL.md「用户偏好与改稿保护」只放一句摘要和指向。

硬规则：同一个要求（用户提的要求和作者自拟的设计都算）已经用两个不同写法各跑过一次都没出现，或同一份稿跑两次结果一样，第三版**禁止再改措辞**——换同义词、换动词顺序、调排布顺序、加强调句、改起动时间，全都算改措辞。这时停下来，把下面四个换方法的选项列给用户，由用户选：

- 给它单独一镜，或者换一个景别，让这件事有足够画面和时间；
- 上动作、姿势或形态的参考素材；
- 把要求降到模型做得到的程度（更简单的节拍、更低的相机负担、在因果边界拆开）；
- 接受现状，这一项不再追。

本项目实例：近景召唤巨手两版缩小 → 降低要求成云层撕开（L114）；五尊法相扑镜三版 → 换单一巨掌压镜（L115）。反例：灯笼怪 180° 转身蓄力（2026-09-22）连改五版措辞都没出现，始终没换方法，是本项目最贵的一次浪费——第三版就该停。

已有明确失败证据时可以提前换，不必等满两次。诊断前先在经验库里查同题材有没有已试的失败记录：有就直接按记录换方法，不再花一次生成去重复验证。

**唯一例外（措辞改动）**：第三版允许的措辞改动只有**有已试经验记录支持的修法**——经验库里置信度为“已试”（能定位到成片或截图，或用户本人实测）的那条条目直接给出的写法（例如按 L067 把背景角色的整体位移改回原地肢体动词序列）。采用时必须在说明里引用条目编号与结论，并说明本例为什么适用；这仍算“按记录换方法”，不是再试一版措辞。没有条目依据的同义改写、换动词顺序、调排布顺序、加强调句一律仍然禁止，也不能拿“未试”条目或自己的推测当依据。

## 9 写入经验库

每次诊断结束给一条新观察；用户授权或会话约定允许写入时才运行（来源要能定位：模型版本、实际提交稿、成片文件名；合成测试视频和测试题情境不写入真实项目经验）：
```bash
python3 scripts/log_lesson.py --topic "景别与画外/画外人物" --phenomenon "写了曲伯仍在原位，曲伯进了特写" --a "写画外人物状态→被拉进画面" --b "删掉该句→未出现" --conclusion "画外人物不写" --confidence 已试 --source "0916 jimeng-…-3612.mp4"
```
`--topic` 必须带分类前缀（12 个分类见 `../lessons/README.md`，log_lesson.py 强制校验，前缀不合规不写入）。置信度按 `../lessons/README.md` 的唯一定义，只有已试 / 未试两档：写成已试必须有能定位的成片或截图，次数只是样本信息。观察和修法分开：修法没提交过写"→ 没试过"。词库理解度调整按 `../lexicon/README.md`，同样要有能对上的成片或截图。成功的写法同样记录。修改历史不进提示词：修法写成当前的可见状态（"枝干有树皮纹理，末端逐渐收细"），不写"之前生成成了石头"。

## 10 交付

只要求评估时：证据 + 逐句兑现表 + 最小修复建议，不自动改稿。要求修改时：按 `revise-rules.md` 交付完整受影响单元（整镜、整序列、全稿或整条操作命令）+ 一行检查；例外说明里用人话写本次经验库新条目改变了哪句。
