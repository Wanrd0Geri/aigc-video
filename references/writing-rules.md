# 写法规则

> 用于执行清单第 ④ 步（翻译抽象词）、第 ⑦ 步（成文）和第 ⑧ 步（逐条对照）。
> 读完必须产出：提示词每一句都过了五道门；抽象词全部落成可见句；第一组"只写当前画面"逐镜核对无违反。
> 经验采用与优先级见 [lessons/README.md](lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。

写法：规则一句 → 反例 → 正例。总原则（道哥第 100 条）：提示词是给摄影师的现场口令，不是给画家的说明书；每个词都要能在取景器里被执行，不能执行的词全删。像给盲人做的电影解说词：现在时、只说画面看得见的、按出现先后说、不解释意图、不评价。不是小说、不是分镜脚本、不是导演讲戏。

## 第零组 可见句五道门（每句进提示词前必过）

1. **可拍性**：摄影机能拍到吗？拍不到就翻译成可见句或删除。反例"她很难过" → 正例"嘴角轻微下拉，眉头向内聚拢，下眼睑微微收紧"。
2. **关键关系明确**：身份、动作对象、方向与结果是否会被误解？只消除影响目标效果的歧义，不把所有局部运动都规定成唯一解。反例"慢镜头"（人慢、镜头慢、慢放三种）→ 正例"镜头极其缓慢地推近，人物动作保持正常速度"。反例"环绕" → 正例"从人物左侧向右环绕半圈，机位高度在腰部"。
3. **归属**：这句属于哪一镜、哪个可见对象？局部事件不放风格段，画外内容不放本镜，全片贯穿的不写进单镜。
4. **承重性**：删掉这句会不会改变用户在意的剧情、节奏、力度、构图、材质、光影或情绪效果？会就保留，不能只保剧情。不改变这些效果、也不负责身份或连续性的重复说明可合并；拿不准时保留，已认可内容按改稿保护处理。反例"外套看上去有些年头，透出旧日的气息"（删掉画面不变）→ 正例"外套肘部磨出发白的圆斑"。
5. **尺度一致**：点名的细节，当前景别装得下吗？装不下等于偷偷改景别——模型会自己换一个景别去拍它。织纹、纤维、毛孔、抽丝、绒毛只在特写、大特写或微距里写。反例近景里写"粗麻的织纹、抽丝的破边"（本项目实测：成片多出一组纹理特写插入镜头）→ 正例近景写"粗麻衣摆边缘参差不齐"；确实要织纹，就把这一镜本来就定成特写。

效果词 → 可见句对照：

| 想要的效果 | 可见句 |
|---|---|
| 震撼、气势 | 镜头从高空俯冲向下穿过云层，人物在画面中越来越小 |
| 宏大 | 摄影机缓慢上升，人物在画面中越来越小 |
| 压迫感 | 镜头低角度，前景有巨大阴影压向人物；或画面严格左右对称，人物站在中轴线 |
| 孤独 | 人物周围三米内空无一人，只有自己的影子陪伴；人物只占画面下方六分之一，上方是巨大空洞的天空 |
| 重量感 | 落地时身体明显下蹲缓冲，灰尘从脚底扬起 |
| 轻盈 | 脚步落地无声，裙摆飘起后缓慢落下 |
| 力量 | 手臂肌肉绷紧，青筋从手背延伸到小臂 |
| 紧张 | 手指无意识地敲击桌面，频率越来越快；话到嘴边又停住，喉结上下动了一下 |
| 冷 | 呼吸在冷空气中凝结成白雾，鼻尖发红 |
| 时间流逝 | 影子从脚底慢慢拉长，天色由橙转蓝 |
| 梦境感 | 重力似乎减弱，人物动作漂浮，背景缓慢扭曲 |
| 高级感（微观） | 镜头微距，水滴在花瓣表面滚动 |
| 科幻感 | 全息界面有轻微扫描线抖动，边缘有像素化失真 |
| 拥挤 | 人与人之间只有一掌距离，身体互相摩擦 |
| 恐怖预兆 | 灯管开始频闪，墙上的影子先变形 |
| 让观众看某物 | 画面其他部分轻微虚化，焦点锐利对准手中的怀表 |

可见句之后允许一句情感解析（"她不是在痛诉，而是在等一个早就猜到的答案"）或一小段画质词，但它们不能替代可见句。更多条目查 `lexicon/`。

## 第一组 只写当前画面（防穿帮、防构图错）

6. **可见清单先行**：写一镜前先列出这镜能拍到的人、部位、物件、空间层，只写清单里的。特写不写全身与场景，全景不写微表情。
7. **画外不写**：画外人物只用可见线索表达。反例"白猿在画外举棒"（白猿被拉进特写）→ 正例"苏云目光看向画面右侧外，肩膀微微绷紧"。
8. **已完成不重演**：上一镜结束的动作在本镜写成现状。反例"上一镜刚放下的镊子"（会再放一次）→ 正例"镊子平放在台面上"。
9. **未发生不预告**：本镜还没发生的事不写；不写"随后将要""为下一镜准备"。
10. **景别外不写**：要求近景同时看见双脚、门槛和整扇门，镜头会被拉远。一个景别只写它容得下的信息。
11. **多写一句就多一个人**：反例"曲伯和法相仍在原位"（把画外人物拉进了画面）→ 删除，画面里没有的人不提。
12. **暗处写还留着什么，不写什么都没有**：绝对化的空与黑（压死的黑、再没有第三样东西、什么都没有）会给出一块死区。反例"其余大半幅是压死的黑，再没有第三样东西"（本项目实测：成片里出现一块死黑矩形）→ 正例"薄雾在光边上翻动，一线冷蓝天光勾出屋脊轮廓"。

## 第二组 主体与动作

13. **动词句首，先定运动**：反例"一个女孩，美丽，站在街上" → 正例"女孩从画面右侧缓步走入，风掀起发梢"。
14. **按控制需要展开**：普通过程可概括；易误解、决定观感的接触、受力、转向、空间衔接或构图终点才展开相关部位、幅度、速度和结果。例如“手扣住腰腹，衣料绷紧，下落被截断”分别控制接触、材质响应与受力结果，不能按同义重复删掉。不设关键动作数、每拍句数或物件数配额；细节多少由当前观看目标、可读性和时长决定。
15. **步态、转身、跌倒写顺序**：走路"右脚先迈出，身体略微前倾，手臂自然摆动"；转身"先转肩，再转胯，最后头转过来"；摔倒"脚下一滑，身体后仰，右手向后撑地"。
16. **重复运动给变化**：反例"车轮转动" → 正例"车轮旋转逐渐加快"，否则匀速空转。
17. **服装写运动状态**："长裙被风吹向身体左侧，布料出现斜向褶皱"。布料响应实际动作、风与接触；没有驱动或被固定时允许静止，不为视频形式强加飘动。
18. **人物一致靠固定短语**：每次提示词重复同一面部短语（"银白瞳、方下巴、左眉有断痕"）；有参考图时只补图里看不出的状态。
19. **按依赖串动作**：接触、受力与结果有先后依赖时写清；自然同时发生的摄影、表演和环境响应可并行，不为凑因果强加先后或停顿。可见衔接有助于表达意图，不保证模型逐项执行。反例"他转身。手臂抡起来。人头被扔出去。" → 正例"右脚在湿石板上碾实，腰带和下摆先转过去、肩膀慢半拍才跟上，左臂被甩开到完全伸直，手腕在最远处猛地一抖松开，那颗头脱手飞出。"
20. **因果机制落成可见表现**：力的传递、动量、惯性、过冲、蓄力等可与可见动作并用，不能单独承担控制；写清部位怎样起动、位移或回摆及后果，例如“借转身惯性甩开手臂，手腕掠到最远处才松开”。不因含术语就删有效动作关系；L091 的混杂观察不能证明术语无效，候选修法未试。
21. **程度词配速度与位移证据**：疾爬、密集、飞快可以保留，必须落实可见速度或位移；按目标选用速度对比、单位时间位移、步频或途经参照物。拖影、尘土、残影可辅助，不替代主体运动。L097 的步频与参照物同时修改后位移可见，不能单独证明程度词无效或数字必然有效。

## 第三组 运镜

22. **起点、路径、终点与可见幅度**：写清运动使什么变大、错开或显露；速度按路径和时长选择，匀速与短暂停稳均可，不强制变速。
23. **摄影路径相容**：可围绕一个主要观看任务协调平移、升降、摇摄或变焦；检查实际几何，不能同时发出互斥的路径要求。
24. **术语三档**（官方）：景别、推拉摇移跟环绕、低角度俯视直接写；一镜到底、希区柯克变焦、航拍、FPV、子弹时间、手持、回弹变速直接写但说明围绕谁、从哪到哪；小众术语写"术语 + 作用主体 + 画面变化 + 前景背景关系 + 方向速度"。理解度为"未试"的术语后面跟一句可见结果作保险。
25. **速度与幅度对应**：本用户默认需要可见运镜，缓推或慢横移也要有实际幅度和画面变化；不把“几乎不可察觉”当成缓慢的通用加强词。
26. **手持写幅度**："摄影机轻微上下浮动，偶尔有呼吸感的晃动"；抖动要有动机："爆炸瞬间摄影机剧烈震动，随后慢慢稳定"。剧烈晃动会翻车。
27. **跟拍写距离和方向**："摄影机与人物保持两米距离，平行移动""跟在人物后方一米，越过肩膀看到前方"。
28. **推拉写可见结果**：推、拉、环绕、变焦要写什么变大、变小、被揭示、被遮住；固定机位不必反复说明。
29. **同步大动作核对可读性**：相机与主体可同时大幅运动，写清各自路线、时序与可见变化；不默认停镜、错开或降速。仅在具体容量冲突或类似漏动作时，考虑错开起点等候选修法，不覆盖用户锁定项。L093 的“先收镜再起动作”未试，不是通用顺序。
30. **遮挡期间位移保持连续**：主体可在遮挡中继续移动，写清原有路线、动作进程与再次显露的位置，不要求停在原处。出现类似跳切问题时，可补“岩棱滑开的同时它的头胸继续逼近”这类可见衔接；L095 的候选修法未试，不禁止正常位移。

## 第四组 空间与构图

31. **多人先定空间关系**："两人相隔一臂距离，左边的人肩膀向右转"。谁在哪、朝哪边不写清楚会粘成一团。人数增加时按每人的叙事与动作职责安排可见度，不按人数自动虚化后排；所有必要参与者的动作和关系须看得清。
32. **位置服务观看任务**：居中与三分位置都可有意采用，写清位置、朝向及必要留白，例如"居中正对镜头，两侧对称"或"位于画面右侧三分之一处，视线向左，左侧留白"。数字允许作为控制手段（三分之一、45 度、两米），不按位置预设审美高低。
33. **朝向与视线分写**："身体朝向画面左侧，目光看向画面右下方"。面对面的两人，各自的右手边方向相反；"面朝上"不等于"正面"。
34. **首帧占位**：第一帧就要有的人物写"开场时苏云已站在门框内侧"，否则模型可能从空镜开始、人物晚到。
35. **遮挡写时间顺序**："人物从门后走出，门板遮挡身体半秒，再完全出现"。
36. **按任务组织空间层次**：需要纵深时可用前中后景、尺度或视差建立关系；不强塞前景物体或虚化。前后层均承担动作时，要让必要人物与关系都看得清。
37. **物件首次出现要有锚点**：在画面哪个位置、多大、跟谁相连、随谁一起动，四样至少给两样；没锚点的物件会直接消失。反例"一截垂着的破布"（本项目实测：成片里根本没出现）→ 正例"灯笼正下方紧挨着一大片深色破麻布，斜着占住画面右下的一整块，随灯笼一起晃"。
38. **距离链要连贯**：同一镜里"远处、尽头、深处"和"贴着镜头、掠过镜头、撑满画面"不能直接相邻，中间要有一段逼近或后拉把距离接上。反例"他立在透视线的尽头……手臂贴着镜头掠过"（本项目实测：人被放到远处，掠镜没做）→ 正例先"他立在透视线的尽头"，再"他大步走到镜头前三步之内"，最后"手臂贴着镜头掠过"。

## 第五组 光线、色彩、材质、天气

39. **光写方向 + 色温 + 质感**：反例"电影感打光" → 正例"左侧窗光，硬阴影横跨墙面""阳光从人物正后方射入，发丝边缘过曝"。
40. **颜色写具体关系**：按目标选择统一色调或冷暖对比，例如"琥珀色主光，暗部偏青绿"或"整个场景被一盏老式路灯的暖黄光染色"；不把冷暖对比或借物赋色设为通用升级。
41. **明暗写绝对值**：剪影写"人物完全黑暗，背景曝光正常，只有轮廓可见"。
42. **材质给触觉线索**："粗糙的羊毛大衣，表面有细微起球"；老化具体到形态"铁门生锈，漆皮呈片状翘起"。
43. **天气带物理反应**：反例"下雨" → 正例"雨滴打在柏油路面反弹起水花"；风写被风改变的事物"风把树叶吹得翻转，衣领拍打脖子"，全场景风向一致。
44. **光影放全局，镜内只写变化**：只有"阳光和阴影交替扫过他的眼睛"这类变化才写进镜头；切镜不移动光源。
45. **亮度同步按连续性目标判断**：亮度峰与景别骤变可以同步；目标要求连续且出现类似意外白闪时，可尝试错开峰值或调整光源画面位置。保留本镜已确认的亮度、运动与节奏，不默认停镜或降速。L094 的错开修法未试，同步不等于必然切镜。
46. **效果要有可对比的载体**：遮挡要遮住亮的东西，变暗要有先亮的参照。反例"黑发遮住镜头"写在本来就黑的画面上（本项目实测：亮度确实掉下去，但读不出是遮挡）→ 正例"黑发糊住那张被灯笼照亮、胀满画面的脸"。

## 第六组 表演与情绪

47. **情绪落到可见表现**：选择足以看清起终变化的必要表现，按需要补一句情绪方向；官方 3.4 的 2 到 4 个仅作参考，不是配额。与情绪匹配的视线、面部或动作承担表达，不用裸露情绪词或无关抽动代替。
48. **矛盾情绪写出来**："嘴角轻微上扬，但眼睛保持警觉"，否则只有标准微笑或呆滞。
49. **视线三步**：先写看哪，再写光从哪来，最后写情绪。"目光看向画面右下方，眼底映着一小片窗外的天光"。
50. **给动机不给情绪**："他握紧拳头，指节发白，嘴唇抿成一条线"；动作 + 心理一句两信息："她把玩着无名指上的戒指，透出下意识的不安"。
51. **对话前停顿**："话到嘴边又停住，喉结上下动了一下"。
52. **表演容量**：一镜可以有多个有序、可读变化；检查各变化的起终状态和时间。已皱眉可按实际余量加深，也可换载体，不机械强加手、肩、呼吸动作。

## 第七组 密度与结构

53. **按事件依赖分镜**：笑、转头、挥手、走路、坐下可组成一镜内的连续表演，也可按观看目的拆分；镜数由时间容量、因果与可读性决定，不按动作词数计算。
54. **视觉符号按作用选择**：室内用有用的氛围锚点代替无差别家具清单；3到4个仅为示例数量，不作配额。细节应帮助主体、年代、空间或情绪辨认，不为凑数加物件。
55. **先选必要信息，再决定篇幅**：先在内部明确必须兑现的事件和目标观感（含节奏、力度、构图、材质、光影与情绪），不新增公开概述。用户要求、已认可内容、决定效果的独立控制，以及让动作成立的必要衔接必须保留；作者想到的辅助细节不自动成为硬要求。非关键微动作、尘粒轨迹和精确次数可留给模型安排，用户已指定或已认可的除外。
   参考素材只承担本次明确采用且实际可见的属性：静态图不代替动作路径；参考视频已经提供的动作可按职责继承，不逐动作争夺控制。全局只放始终有效的规则，阶段动作放在对应阶段。合并前核对对象、时序、方向、力度、终点与范围；不同独立控制不能压成泛词。
   字数不决定质量，不设统一上限或压缩率。重复是否合并看作用与范围：无新增信息的复述可合并；必要的指代、阶段交接与已认可表达不得为了去重丢失。成文后只在现有检查中核对“重要效果是否丢失或变弱”“是否增加了无必要的微观安排或冲突”，不新建逐句证明、评分表或额外审核轮次。
56. **风格段只写跨镜成立的画面质感**：渲染媒介、色调、材质、光影原则、镜头性格。限定某镜的事件（闪移残影、撞击震动）以及表演、具体运镜路径、时序写入所属镜头，否则会被泛化到整段。
57. **风格有主次且兼容**：可用主风格统领，多个词只在各自承担独立、兼容的控制时保留；删除空泛同义堆叠，不按词数限制混合风格。
58. **先兑现目标，再处理具体风险**：高速、广角、多人不因经验标签而默认回避。先保用户需要的规模、速度、人数与关系，检查当前取景、交互容量与素材职责；风险确实存在才设计针对性方案，不自动缩成两人近景或用背景模糊替代大场面。模型能力判断须说明条件与证据。

## 第八组 语言与禁忌

59. **空词清单**：高级感、氛围拉满、史诗感、震撼、美丽、自然、灵动、僵硬、单独出现的"电影感"。看到就翻译或删。
60. **引用性措辞禁用**：同上一镜、承接上一镜、继续刚才、如上、之前、再次；也不写"上一版""上次那样""这次改成"。每镜自足，每条提示词自足。
61. **修改历史不进提示词，反馈不滚雪球**：视频模型没有上一次生成的记忆。"之前生成成了石头"要写成"枝干有树皮纹理，末端逐渐收细"；"不要重复投掷"写成"手臂已完成跟随动作，物体已离手"；"这镜不要像上次那样回头"要删掉引出回头的原句，写成"目光始终停在门口"。每轮修改后禁止项从零推导，不在旧清单上追加。
62. **默认不用否定句**：自写否定预算 0 条（固定句不计）。每条否定先问"能不能改成要什么"；能改的写正向句放该去的段，否定不写；确属特殊情况、改不掉的（文字水印、第二个 X）写进**它管的那一镜的正文**，不放末尾——末尾只有固定句“全片不添加BGM，不添加字幕。”那一行，它上面一行是普通正文。`check_prompt.py` 对每条自写否定给一条提醒，提醒要逐条裁定，确认后用 `--negative-exception` 逐句点名；用户锁定项用 `--lock` 保护、不删，必要例外按 review/quality-gate.md 审查。反例"禁止上方鳞面消失、禁止变成露天夜景" → 正例场景段"上下两片鳞把画面夹成一条狭窄的甬道"，别处不再提。描述上一次失败画面的词（那次崩成的露天、起飞、旁观跟拍）不进提示词；当前画面本来就需要起飞或露天时照常写。
63. **参考精准只指代**：参考视频已经给出动作与运镜时写"严格参考视频1的动作与运镜"，不再复述。
64. **不写 UI 参数与内部术语**：分辨率、帧率、画幅在 UI 设；不出现"锁定项、可见清单、L2"这类流程词；不写"注意看"。
65. **台词语言统一**，画面文字用引号，声音用官方符号；不发明素材标签，只用 `图N/视频N/音频N`（不写 @，即梦软件里再 @；修订旧稿沿用旧稿写法）。
66. **自然中文句**：不堆英文、不堆参数、不用嵌套长句；一句一个动作。
67. **比喻只用于材质，不用于动作和情绪**：材质比喻落得到画面上，动作和情绪比喻落不到。正例"像一团浮着的鬼火"；反例"像被激怒的野兽一样扑过来" → "四肢同时离地扑出，落点在他胸口"。
68. **形容词后面跟一个可观察结果**："很快"没用，"一秒内三次"有用；"很重"没用，"落地时地面的浮尘被震起一圈"有用。
69. **解释词删**：仿佛、似乎、像是在、营造、氛围、有一种——这些词只解释画面的意思，不产生画面。反例"她的动作里有一种被压住的恨意" → 正例"她把杯子放回桌面，手指在杯壁上多按了一下才松开"。

四种失效腔调（看到就改）：

| 腔调 | 反例 | 改成 |
|---|---|---|
| 小说腔 | 他仿佛在凝视着什么遥远的东西 | 他的视线越过镜头，停在画面右上方 |
| 参数腔 | 85mm f/1.4，3200K | 长焦浅景深，背景灯串糊成圆斑；暖黄光染在脸的左半边（要写数值就跟一句可见结果） |
| 讲戏腔 | 这里要演出压抑的愤怒 | 下颌线绷紧，鼻翼一张一合，握着杯子的手指关节发白 |
| 清单腔 | 他转身。他挥手。头飞出去。 | 右脚在湿石板上碾实，腰带和下摆先转过去，左臂被甩开到完全伸直，那颗头脱手飞出 |

## 第九组 时间与节奏

70. **时间节点控节奏**："前两秒静止，第三秒突然转头"。没有时间提示，模型只会匀速运动。普通叙事用阶段 + 结束时状态，关键节拍才写秒。
71. **时序词串动作**：先、接着、随后、最后；一镜到底按"起点空间 → 第一个动作 → 镜头运动 → 经过的参照物 → 第二个动作 → 终点空间"。时序词之外，句与句之间靠因果连接：后一句由前一句造成（见第二组）。
72. **动作密度：平均每拍 0.5 秒是经验线索，不是通过保证**（本用户实测，L064）：用户多次实测里模型多会以加速方式完成密的动作序列，0.5 秒一个动作可完成，1 秒里塞 2 到 3 个不同动作离谱。所以平均每拍 ≥0.5 秒可作为"不因密度自动拆镜"的依据，仍按动作依赖与可读性判断：加速可能牺牲可读性或漏动作，真正需要看清的动作单独给时间。check_prompt 在平均 ≤0.5 秒/拍（每秒 2 拍以上）时提醒。台词按真实说话时间算，不按节拍：4 秒容不下长台词 + 取信 + 出画，12 秒可以。
73. **转场写中间帧**："镜头穿过门缝，黑暗持续半秒，然后亮起"；运动匹配"镜头快速甩向天空，再落回地面人物"。
74. **结尾给退出动作**："镜头缓缓拉远，人物逐渐隐入黑暗"。不草草收尾。
75. **慢动作写可见细节**：慢放后才看得见的东西要写出来（液滴在空中拉出不规则形状）；百分比速度是否被理解，本项目没试过。

## 第十组 质感与流动（防 AI 感）

76. **风格段四方面按适用性落实（只描述画面质感）**：画风与渲染方式、材质与表面质感、光的质感与层次、镜头性格（焦段、景深、手持还是稳定）四方面均须判断适用性；适用的独立控制必须在正文中落实，不限定各写一句，可自然合并。没有相应材质或驱动不编造响应。省略的是不适用内容，不能省略适用控制；不适用依据留在内部审查。**表演、具体运镜路径、动作与事件、时序都不写进风格段**，它们属于镜内。反例"3D 国风漫画，电影感，8K" → 正例"3D 国风漫画 CG 风格，写实材质配风格化人物；粗布织纹明显，淋湿处颜色发深；灯笼纸面透光，湿石板把灯光反射成碎鳞片；亮部柔和收束，阴影里保留衣褶层次；长焦浅景深，轻微手持呼吸感"。
77. **画质词不算描述**：8K、高清、精美、电影感、高级感、电影级只能做风格段末尾的一小段尾巴，前面必须已有具体材质与光的句子；单独出现就删。
78. **世界运动有依据**：需要的主动作、接触响应与残留必须可见；环境、衣物和物件是否运动由驱动与约束决定，不强加风尘雨雾。人物或物件静止不等于摄影固定，摄影按 SKILL.md 的用户偏好与保护范围执行。
