# 运动与物理：身体、材料、环境、时间尺度

> 用于执行清单第 ⑤ 步（导演提案）与第 ⑦ 步（成文）；动作、追逐、天气、水火烟雾、粒子、慢动作必读。
> 读完必须产出：本镜的世界模式（耦合 / 只写主动作 / 有意静止）、主动作的可见结果句（做到哪、多快、结束成什么样）；被选中的环境响应写成场景段的一句共享响应，只有是关键事件一部分的才进那一拍；衣物、头发、持物随动的去处见 writing-rules 成文主规则第 3 条。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。词条查 `../lexicon/action-terms.md`、`../lexicon/light-material-terms.md`。

## 1 先定这一镜的世界模式

- **耦合世界**：主动作确实作用于已有环境受体，或明确需要世界响应时，写有用的可见因果链与残留；不为凑模式加持续风雨尘雾。对话戏也按实际受力和节拍判断。
- **只写主动作**：写主动作、必要的身体力学和道具运动。主动作与必要材料响应足以兑现目标时即可采用，不必等用户特意说“干净”；附属材料按实际受力和约束判断。
- **有意静止**：写稳定的场和被要求的活动或持续状态；停住、倾听、等待要写出动机（"屏住呼吸听门外的脚步"），不强加呼吸、烛火、雨等微动。世界静止与摄影运动分开判断；摄影按 SKILL.md 默认有可见运动，用户明确固定或保留既有摄影时例外。
世界模式不是"所有东西都动"。先扫描整张场景图（前中后景）的运动候选：风的受体、雾烟雨雪尘、水与湿地、发衣旗帘草绳纸、移动或被遮的光与影、人群车辆机械。只选可见、有因果、对本镜有用的；不动的不写；画面外的区域不是本镜事实。不发明新的天气、水源、植物、动物、人群、道具、破坏。

## 2 主动作的身体力学

- 概括为主，关键动作写结果：哪个部位、做到哪、多快、结束成什么样。“右手抬过肩，整个人压向右侧。” 重心移到哪、先转哪、力怎么传不写，用户点名要的部位细节除外。
- 步态："右脚先迈出，身体略微前倾，手臂自然摆动"；奔跑："脚步沉重，每次落地膝盖深度弯曲，呼吸急促肩膀耸动"；奔跑回头："脚下节奏不乱，但肩膀开始偏斜"；转身：“转过大半圈，背对镜头，下摆整圈张开”；摔倒："脚下一滑，身体后仰，右手向后撑地"；坠落给参照物："衣角向上翻飞，地面快速逼近"。
- 重量："落地时身体明显下蹲缓冲，灰尘从脚底扬起"；轻盈："脚步落地无声，裙摆飘起后缓慢落下"，写落地与飘落的速度差；力量："手臂肌肉绷紧，青筋从手背延伸到小臂"。
- 动作衔接：后一个动作从前一个的终态直接起，“转身没停，手已经顺势抬起”；重复运动给变化："车轮旋转逐渐加快"，否则匀速空转。
- 时间节奏："前两秒静止，第三秒突然转头"；没有时间提示模型只会匀速运动。
- 兵器和道具有重量：手臂承重可见，手腕角度随质量变化，加速和减速真实，物体不在姿势之间瞬移。
Higgsfield 物理锁（按需选）：重力、质量、惯性、摩擦、接触、重心转移、地面压力、碰撞、跟随动作、布料延迟、头发延迟、液体流动、雪的堆积、火的热浪、门轴阻力。不漂浮、不无重量、不无摩擦、不瞬移、不橡皮质感。这些是设计检查项，不直接写进提示词；写成看得见的结果（落地时膝盖一沉、脚下石板溅起水）。末尾那串“不漂浮、不无重量……”是原文，同样不进提示词。

## 3 附属与接触响应

附属：头发、衣服、饰品、持物随身体滞后回弹，"长裙被风吹向身体左侧，布料出现斜向褶皱"；布料是否运动取决于驱动、固定与材质，不自动飘动。
接触双向：世界可以吹动衣发；主体也会压草、扬尘、扰动水面、改变倒影、碰响挂物。"手指划过积灰的桌面，留下一条痕迹。"
响应差异，不同步摆动：轻布比重布先动、动得远；发梢比发根动得多；近叶比远冠明显；水波在脚离开后才扩散；硬物传振动不弯曲。
（以上三段是内部设计检查；成文时附属响应的去处按 writing-rules 成文主规则第 3 条，关键事件的可见结果才写进那一拍。）

| 层级 | 载体 | 规则 |
|---|---|---|
| 主动作 | 身体、载具、攻击、变身、产品操作 | 保住画面重心与动作时序 |
| 附属 | 发、衣、饰、持物、身体回弹 | 从主动作、附着、重力或共同驱动派生 |
| 接触 | 水、地面、草、门、家具、尘、松散物 | 写出材料相应的响应，传达重量、速度或力；不改锁定的位移与破坏 |
| 环境驱动 | 风、雨、雾、烟、蒸汽、流水、移动光 | 建立一次持续驱动，不在每镜重启 |
| 背景 | 植物、窗帘、人群、车流、机械、云、倒影 | 除非环境是主体，否则压低 |

## 4 环境驱动怎么写

- 风写被风改变的事物，且全场景方向一致："风把树叶吹得翻转，衣领拍打脖子""所有物体向画面右侧倾斜，尘土向右飞散"。满级："穿堂风从画面右侧灌入，长发被整片吹向左侧，裙摆剧烈翻卷，一叠稿纸被掀起在空中散开。"
- 雨带物理反应："雨滴打在柏油路面反弹起水花"；雨的情绪靠密度与落地："雨丝细密，几乎像雾一样悬浮，地面有薄薄积水"；雨后路面是黑色镜子。
- 烟雾三分：烟雾有源头不均匀（一缕青灰色烟笔直上升到一定高度散成絮状）；雾气弥漫均匀（树木成模糊剪影，能见度不超过十米）；水汽短暂上升遇冷凝结。暗室一束光加轻烟就是体积光。
- 火三层：燃烧方向、边缘热浪扭曲空气、周围亮度。
- 水三维度：透明度、表面状态、光线互动；"水面有细小波纹，反射光碎成鳞片状"；液体写路径："水从桌面边缘流下，在下方形成细小水柱"，否则像果冻。
- 粒子：密度 + 运动状态 + 光影互动，"细密的雪花缓慢飘落，每一片在路灯的暖光下短暂闪烁后消失在黑暗中"。
- 爆炸有先后："冲击波先到，物体被推开，随后火球膨胀"；余波比瞬间更有味："烟尘慢慢沉降，碎片在地上弹跳后静止"。
- 温度用身体反应："呼吸在冷空气中凝结成白雾，鼻尖发红。"
- 特效冲击加进去时保留原有的雾、水、风、机械基线，再写事件造成的扰动、传播顺序、材料响应和残留：近处松布先抽动，雾先裂开再卷回，水面剪切扩散，重枝晚响应，远处几乎不动。这一串是设计顺序；成文时镜内只写关键事件需要的那一处响应，其余按 writing-rules 成文主规则第 3 条处理（导演升级选定的次要粒子与地面响应，会动的在它发生的那一拍写一句；没选定的交给模型）。

## 5 时间尺度

- 慢动作：写"慢动作 / 升格"后必须写慢放才看得见的细节："瓷杯在空中缓慢翻转，深褐色液体以近乎凝固的速度拉出不规则的液滴，每一颗都映着窗外天光。" 百分比速度（"以 30% 速度播放"）是否被理解，本项目没试过。慢放范围按观看目的与容量决定，可局部也可整段；发生速度切换时交代进入和退出，不强制每段都变速。
- 延时：明确时间跨度 + 静态参照物，"从午后到黄昏，阳光在地板上的投影从左侧快速移到右侧然后消失，画面中央的摇椅始终静止"。
- 动态模糊两个方向：主体清晰背景拉线（追踪），或主体半透明残影背景清晰（掠过）；王家卫拖影 = 慢动作 + 残影。
- 时间停止："雨滴悬浮在半空，只有人物缓慢移动"；梦境："人物抬脚后缓慢落回地面，衣摆长时间悬在半空，背景缓慢扭曲"；镜像延迟"镜中人物比真实人物慢半秒"；倒影反常"水面倒影比实体更清晰"。

## 6 移动载体与远处巨物

车、船、生物上的场景分开写：载体和附属建筑的共同运动、人物相对载体的运动、摄影机路线、外界的相对退移；按远近层次给视差，不让所有东西同向同速漂，也不因为参考是静图就冻结背景。
"远而巨大"靠中间建筑、遮挡、空间层次和可辨的大轮廓一起成立；虚焦与雾雪降低细节但不抹掉要求的背影和朝向证据。

## 7 放在哪里

- 全片每一镜都有效的物理驱动（风向、流水）在场景段写一次，写方向、强度、背景基线。
- 只在部分镜头起作用、会改变方向或状态的驱动，写在所属镜头。
- 身体动作、道具、接触和关键事件的残留写在所属镜头；天气接触与环境响应默认压成场景段一句共享响应；布料、头发、饰品的附属响应按 writing-rules 成文主规则第 3 条。
- 跨镜只传材料状态：风向、湿度、烟雾漂移、枝与布的相位、扩散中的涟漪、被扰动的尘、移动的影子、机械周期。切镜不重启驱动，也不重演已完成的扰动。
- 用户要求"环境要动起来"时，选中的受体必须出现在最终句子里，不能用一句"微风吹动衣摆和树叶，水面泛起涟漪"应付。（这是用户点名的例外。）

## 8 失败修复

| 成片现象 | 最小修法 | 别做 |
|---|---|---|
| 环境全冻住 | 保住正确的主动作，补最小的一条"驱动 → 附属或接触响应 → 残留" | 加一串泛泛的运动清单 |
| 衣服、树叶、水、雾一起像一层皮在晃 | 恢复一个驱动，再按附着、质量、刚度、阻力、深度分开响应时序 | 冻结环境或随机化 |
| 风向、流向、烟、涟漪、移动光在切镜处重置或反向 | 继承上一镜的方向和相位，在新视角里推进或衰减 | 因换机位而重启驱动 |
| 次要运动喧宾夺主、画面乱 | 重选模式：减少受体链或改成只写主动作 | 删掉所有物理响应或加"环境稳定" |
| 严格编辑替换后多出新的风、水、粒子 | 删掉注入的动态轴，继承原视频世界状态 | 把编辑改成参考生成 |

检查：模式选了；主动作读得清；每条响应链都有原因和受体；方向一致；只有当前画面能看见的才写。
