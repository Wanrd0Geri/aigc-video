# 镜头：景别、角度、光学、构图与运镜

> 用于执行清单第 ⑤ 步（导演提案）和第 ⑦ 步（成文）。按下面的顺序为每一镜做决定。
> 读完必须产出：每镜一句"从哪里、用什么景别和角度、看谁、镜头怎么动、看到什么变化、停在哪"。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。术语查 `../lexicon/camera-terms.md`。

## 1 先问：这一帧最想让观众看见什么 → 景别

远景交代这是哪；全景交代谁在哪干什么；中景看关系和肢体；近景看面部情绪；特写怼眼睛、手指、嘴唇。Seedance 对中近景和特写的表现力远超远景：能用近景就别用全景。例外：孤独、渺小、环境震撼用远景（"渺小的背影站在巨大的落地窗前，窗外是繁华都市夜景，室内只有一盏昏暗台灯"）。
反例"一个女孩在街上走" → 正例"中景，黄昏逆光下，女孩从画面右侧缓步走入，风掀起发梢，背景虚化的城市街道向远处延伸"。
先分清"部分可见、可辨认、完整入画、穿过画面"四种需求：进出近景的物体不必完整装进画面，前缘、经过、离开就能说明事件。不要为了证明人站在哪，让胸部以上的画面同时看见脚、门槛和整扇门；强调下颌不等于只剩下颌。
句式：`<景别>，<主体>在画面<位置>，画面重心是<部位或物件>。`

## 2 角度与高度

平视 = 旁观；俯拍 = 掌控；仰拍 = 仰望。低角度仰拍会把镜头放到膝盖以下，鸟瞰在正上方。电影感多来自微角度：写"镜头比人物视线略高 10 度，微微俯视"，不写"俯拍"；写"从胸口高度微微仰起"，不写"仰拍"。
压迫感：低角度 + 前景巨大阴影压向人物。宏大：摄影机缓慢上升，人物在画面中越来越小。侵略性：镜头快速推向人脸，最后停在眼睛特写，背景迅速抽离。眩晕：镜头以人物视角旋转，背景倾斜，地平线不稳。
句式：`机位在<高度>，<略高 / 略低于视线>，在人物<左前方 / 正面 / 侧后方>。`

## 3 光学：按内容类型选，写可见结果

按内容选：人像与反应 → 保护面部可读与主体分离；观察与对话 → 保留距离和空间关系；环境与调度 → 保留纵深、地理、路线；细节与产品 → 保护表面、边缘、焦点过渡。一个镜头一种光学处理，不把人像、环境地理、微距塞进同一镜。
焦段两说并存：50 组说写"85mm 镜头，背景压缩，人物从背景中分离"有效；Higgsfield 说 Seedance 对 mm 不敏感，应写视角和可见结果（"标准视角，距人物 3 到 5 米，透视自然无畸变""长焦，背景压缩成一片柔和色块，只有人物锐利"）；官方说数值可以写但可见结果更明确。做法：数值 + 可见结果一起写，A/B 结果记入经验库。
景深写焦点和衰减："焦点在眼睛，鼻子开始轻微失焦，背景完全模糊。" 多种柔化各不相同：颗粒加质感，虚焦改可读性，雾气改纵深对比，辉光扩散亮部；叠加时检查关键边缘、触点、路径是否还读得清，不整幅锐化，也不删掉有意的暗部与模糊。
推轨改变距离和视差；变焦只改放大率；滑动变焦两者配合，主体大小不变、背景透视变化。锁定了光学变焦就不能改成推轨。
句式：`<焦段或视角> + <可见结果：压缩 / 展开 / 前景放大 / 背景虚化程度>，焦点在<部位>。`

## 4 构图六法与三个习惯

- 前中后景：不同深度承担主体、路径或尺度参照；前景一个虚化物体、中景主体、背景虚化环境，并有遮挡关系。不是随手加模糊前景。
- 负空间：给攻击、视线或等待的对象留可读区域，威胁逼近时让区域收窄："人物位于画面右侧三分之一，左侧留出大片天空。"
- 轮廓分离：手、武器、头部在关键时刻不叠成一块，背景亮度与色差帮助识别。
- 视线衔接：上一镜结束的注意点与下一镜关键内容位置连贯；先保世界地理和动作轴，不为对齐而镜像战斗位置。
- 显露顺序：每段相机移动说明哪些信息先后进入视野，停在信息完成的构图上，不漫无目的地飘。
- 加速与落定：动作加速时建立速度差，关键关系出现前减速稳定；不是每镜都慢快慢。
三个习惯：对称写"画面严格左右对称，人物站在中轴线"；人物占比写"人物只占画面下方六分之一，上方是巨大空洞的天空"；纵深先选载体（明暗分离、遮挡与尺度、视差、大气衰减）再写具体表面，不写"纵深丰富"。
坐标三条：固定机位下人物移动会改变画面位置，写可见路线；跟拍下人物画面位置稳定而世界位置变化，写相机与人物的关系；环绕或换侧要保留动作轴，跨轴后把同一世界动作换算成新的画面方向。面对面两人的右手边方向相反；"面朝上"不等于"正面"；相机滚转改变投影，不改变人物姿态。
句式：`前景<物>，中景<主体>，背景<环境>；画面重心在<部位或物件>。`

## 5 运镜：先定主要运动关系

本用户默认每镜有可见摄影运动，缓推或缓慢横移也须有实际幅度与画面变化。固定只有两种来源：用户明确要求（fixed，source 引用用户原话）、当前保护范围保留原摄影（preserved）。作者不能自行固定——认为这镜固定更好时（例如对白近景要保口型同步、2.5 在紧景别高速运动下主体易糊、产品微距焦平面经不起机位移动）先问用户：写成表头"待你定"行的一个问题，用户确认之前照常按可见运动设计，用户确认后才按 fixed 记并引用他确认的原话；详见 SKILL.md 与 `../review/quality-gate.md`。先确定主要运动关系，再让兼容的平移、升降、摇摄协调完成，不给相机互相竞争的路径。
运镜明确速度、方向与节奏，并核对路径能否在给定时长内完成。不把"极其缓慢，几乎不可察觉"作为默认；本用户要可辨认的运动幅度；有明确位移或环绕终点时按距离、时长和可读性选择速度。需要速度反差时可写"先快速横移，然后减速停在人物侧面"；匀速及关键读点的短暂停稳也可成立，整镜固定须落在上面两种来源之一，不为所谓电影感强加变速或呼吸感。模型对速度词的响应属于条件性经验，不宣称某写法强十倍。
术语三档（官方）：通识词直接写；一镜到底、希区柯克变焦、航拍、FPV、子弹时间、手持、回弹变速直接写但说明围绕谁、从哪到哪；小众术语写"术语 + 作用主体 + 画面变化 + 方向速度"。
复杂运镜五段，写全才算完整：① 起点：相机从哪开始、已经看清什么关系；② 载体：跟着身体中心、肢体、武器轴、接触点还是世界锚点；③ 路径：平移或旋转方向、高度变化、是否跨轴；④ 信息变化：因为镜头动了，新看见了什么；⑤ 终点锚：停在哪，靠哪个物体或关系让下一镜安全。缺少载体或终点就先补设计；不得以固定机位绕过设计缺项，作者也不能自己把镜头定成固定——想固定先问用户。
常用运镜按功能：急扫从一个清楚的起点出发，只隐藏途中，落到清楚的目标；环绕绑定身体关系或接触点并全程保留世界锚（屋脊、地面、门框）；贴身跟随绑定躯干或武器主人，靠背景视差证明位移，接触或落地时放开跟随；逆向拉移逆着攻击方向压缩距离，保留一个稳定锚点；穿越写清什么逼近镜头、从哪侧经过、真实身体在哪重现，不用前景擦过来遮掩归属、接触或去向。
跟拍三要素（相对距离不变、主体在画面里大小位置不变、背景视差证明位移）只用于要稳定可读的镜头，不是所有冲锋镜头的默认；冲锋、逼近要张力时改逼近放大、穿越或速度反差（L047）；用户明确要的多人或复合运镜按可执行性检查负荷，不因固定规则改写。
手持写幅度和动机："手持跟拍，带有轻微的、自然的不稳定感，仿佛摄影师一边行走一边拍摄"；剧烈晃动会翻车。抖动要有来源："爆炸瞬间摄影机剧烈震动，随后慢慢稳定。" 跟拍写距离与方向："摄影机与人物保持两米距离，平行移动""跟在人物后方一米，越过肩膀看到前方"。
句式：`镜头从<起点>开始，跟着<载体>沿<方向>以<速度>移动，<新看见什么>，最后停在<终点锚>。`

## 6 写运镜句的检查

镜头参数和画面内容互相成立，按实际取景判断而不是按术语：焦距、拍摄距离、取景范围、景深是四件事。长焦可以拍全身（退远即可），广角也不自动等于大全景；特写装不下全身、双脚、远景，远景看不见毛孔、血珠、睫毛；写了浅景深就不写前后景都清楚。背景压缩来自拍摄距离远加长焦取景，透视关系由机位到主体、主体到背景的距离决定，焦距只决定视角；所以写了"背景压缩成色块"就同时写长焦和较远的机位，不再写广角近距。焦点变化靠主动调焦就能让静止主体失焦或重新合焦，不要求人物或相机前后移动，但每一段要有实物落点（落在脸上、移到肩上的围巾、退回脸上），需要强调动作时可让合焦配合关键动作，不强制所有调焦都卡同一节拍；无落点的往复滑动在已有样本里只得到轻微呼吸感（L048、L058，一次对照）。固定机位不等于固定焦距：用户锁定的是机位还是光学，按原话保留，不用术语制造冲突。数值（焦段、光圈）与可见描述冲突时模型多半听描述，所以两者只能同向。
推、拉、环绕、变焦要写什么变大、变小、被揭示、被遮住；固定机位不必反复说明。相机的改动不能借机让人物转头、起身、迎合镜头；反打只改变观看侧，不改变人物朝向。固定不能同时跟拍；第一人称看不到自己的脸；过肩可以露肩背，观察不是第一人称。

## 7 一镜到底、蒙太奇与切点

一镜到底结构：[起点空间] → [主体第一个动作] → [镜头运动方式] → [经过的空间或物体] → [主体第二个动作] → [终点空间]。"镜头从走廊尽头的窗户开始，缓慢向前推进，经过墙上斑驳的老照片和半开的门，进入客厅，一位老人正从沙发上缓缓站起，转身面向镜头，窗外黄昏的光在他身后拉出长长的影子。" 三关键：空间过渡有参照物；先、接着、最后；总时长装得进一个镜头。明确写"一镜到底"，模型会减少剪切倾向。
蒙太奇：写"快速切换、闪现、穿插"并给每个片段最精炼的视觉符号："城市霓虹灯快速闪过，手指敲击键盘特写，咖啡杯被端起又放下，窗外雨滴滑落，最后定格在一双疲惫但坚定的眼睛。" 适合片头、预告、时间流逝。
切点动机：决定形成、接触解决、方向改变、失去或重获支撑、落地、恢复成本出现、主动权转移、新威胁可读时才切。上一镜的终态必须是下一镜合法的起始状态。切在准备上转移注意；穿过加速切只在起落锚点清楚时；接触处切要先建立归属和反应；后果之后切证明位移；停住让人看观察、选择、恢复，不要求每一刻换姿势。
多镜镜头一致：同一空间的多镜保持同一光学性格；换镜头性格只在内容类型变化时，硬切过去，镜内不漂移。
转场：写中间帧"镜头穿过门缝，黑暗持续半秒，然后亮起"；运动匹配"镜头快速甩向天空，再落回地面人物"；官方 11 种转场名见 `../seedance-operations.md`。

## 8 高张力打斗运镜

模式 M01 到 M10 见 `../lexicon/camera-terms.md`。广角近距要写完整的尺度波：清楚的远处起点 → 逼近放大且归属可辨 → 近镜透视沿真实力线夸张 → 从声明的一侧经过或接触 → 恢复真实身体、世界锚与后果。开头和结尾停在同一个畸变姿态、放大无关肢体、身体或武器归属消失，都是失败。
速度短语：清楚锚点 → 骤然缩短距离 → 方向性拖影 → 清楚重现或接触 → 后果与喘息 → 再次加速或定格。拖影只加在快的肢体、武器尖、衣摆、粒子或反向运动的背景上，不给整幅、整段统一模糊。
关键攻击的力量呈现：蓄势（身体压缩、扭转、兵器后引）→ 释放（骤然加速的主体、路线和速度对比）→ 透视强化（哪个部位由远逼近、如何放大、从镜头哪侧经过）→ 接触或交错（具体触点、承压形变或错身距离）→ 后果（沿受力方向的位移、失去支撑、回弹）。阶段可合并或跨镜，不强制四镜、长蓄力或每拳慢放。
