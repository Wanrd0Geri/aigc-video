# 光影与色彩

> 用于执行清单第 ⑤ 步（导演提案）与第 ⑦ 步（成文）；稳定光源与共享光影原则写全局，当前机位的局部受光、焦点和曝光变化写镜内。
> 读完必须产出：一句"光从哪来、什么色温质感、主体哪面亮哪面暗、脚下或邻近有什么融合线索"，加一句色彩关系。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。术语查 `../lexicon/light-material-terms.md`。

光线是优先约束，不是装饰。链条：光源 → 主体受光 → 接触与邻近受光 → 纵深与空气 → 相机看到的曝光。最少写三样：一个光源锚、一个主体响应、一个当前画面里看得见的融合线索（接触影、邻近表面反光、纵深衰减、曝光关系）。

## 1 先定光源：方向 + 色温 + 质感

方向：左侧 45 度斜射、逆光、顶光、侧逆光；色温：暖金、冷白、橙粉、青蓝；质感：锐利清晰、柔和散射、透过树叶的斑驳光斑、百叶窗切割的条纹光。三样都写清，Seedance 给的光才像电影布光。
反例"电影感打光" → 正例"左侧窗光，硬阴影横跨墙面"。
万能自然光句："黄昏的暖金色逆光从人物背后斜射，给发丝和肩膀轮廓镀上一层柔和的发光边缘，正面被环境散射的柔光补亮。"
人造光各有色温、衰减和阴影硬度：台灯暖黄、霓虹冷艳、烛火跳动、屏幕冷白。多光源写色温对比："右侧一盏旧台灯投下暖黄的局部光，左侧窗外渗入冷蓝的暮光，两种色温在面部交汇。" 光源可以不在画面里，写光的效果就行。
夜景：唯一光源 + 阴影色调，"月光是唯一光源，地面阴影呈现深蓝色"。时间用光线角度："太阳低垂，影子被拉得极长，色温偏金"；时间流逝写"影子从脚底慢慢拉长，天色由橙转蓝"。
句式：`<光源>从<方向>射入，<色温>，<质感>；<主体>的<亮面>受光，<暗面>沉入阴影。`

## 2 主体受光与曝光优先级

写清相机看到的是亮面、暗面、轮廓还是剪影。逆光锁定句（Higgsfield）："人物在镜头与更亮的背景之间，相机在人物的暗面一侧；面部保持在深阴影中，只有轮廓光、边缘光、湿润的高光和眼睛的反光揭示细节；不要正面主光，不要平光，不要美颜补光。" 上一次出来太平就加："整个镜头按逆光曝光，不按面部曝光；面部允许落入深黑，剪影和轮廓光承担画面。"
剪影写绝对值："人物完全黑暗，背景曝光正常，只有轮廓可见，边缘被夕阳勾出一道极细的金线。" 高反差："一束顶光从正上方射下，面部一半强光一半浓重阴影。" 柔光低反差："柔和的阴天光线从四面八方均匀笼罩，没有明显的阴影边缘，饱和度偏低，莫兰迪色调。"
材质响应各不相同：皮肤、头发、布、金属、湿面、玻璃、半透明、自发光分别写受光结果；追求真实加"保留真实的微细毛孔与肌肤纹理""毛发根根分明"。

## 3 接触、邻近与反射

接触与空间融合根据实际光源、材质和遮挡检查：接触影、投影或邻近反射应与环境相容；不要求地面总有明显反光，也不默认给暗面加反射面。已有表面确实提供所需反射时可写："金色墙壁的暖光反射到人物的暗面，形成柔和的补光""光线从水面反射到人脸上，形成波动的光影"。法术光是光源时写接收顺序："法术光球是当前主光源，青光先照亮施术手与近侧面部，再扫过石地和浮尘；背景仍保持低曝光。" 没有照到任何主体、地面、粒子、阴影的发光，看起来就是贴片。
外观参考图不拥有它自带的光：人物图只借身份、服装、材质，按当前场景的光源重新打光。场景图可以借光源方向、色温、阴影家族和空气。

## 4 纵深与空气

用光做层次："近处被台灯的暖光照亮，中景处于半暗的过渡区，远处完全沉入黑暗。" 远景通过符合场景的明暗、遮挡、尺度或空气衰减形成纵深，不自动加雾与粒子；人物与背景保持同一曝光和色温世界，否则像两张图贴在一起。
特殊光效：丁达尔光柱（"午后的阳光从窗户射入，光柱像固态的金色瀑布倾泻在空气中，细小的尘埃在光柱里缓慢翻涌"）；体积光（暗室一束光加轻烟）；镜头光晕；焦外光斑；光的形状（"光从百叶窗缝隙射入，在墙面形成平行光条"）；影子叙事（"墙上影子比人物大很多，形状扭曲"）。

## 5 色彩

写色相对比不写"暖色调"："琥珀色主光，暗部偏青绿。" 冷中一点暖制造焦点："整个场景偏冷绿，只有人物外套是暗红色。" 借物赋色比直接写色调高级："整个场景的色彩都被路边一盏老式路灯的暖黄光染色，所有物体蒙上一层琥珀色的光泽。" 去饱和 = 压抑、年代；高饱和 = 活力、超现实。黑白要说哪种：高反差黑白、柔和灰调、暖底银盐；单色写"整个画面呈现深褐色调，像十九世纪的湿版照片"。胶片："35mm 胶片，颗粒可见，高光轻微溢出。"
风格签名跟着媒介走：水墨保留笔触与留白，粘土保留工具痕，二维手绘保留线条起伏；参考图写实时更要写明"3D 国风漫画 CG 风格"或"2D 日漫风格"，否则会漂成真人。风格可以有主次与兼容组合，其余用具体描述补足；不以词数禁止有效控制。

## 6 放在哪里、写多少

- 稳定光源和整体色调在全局设定写一次；每镜只写当前机位下的受光关系与变化（"阳光和阴影交替扫过他的眼睛"）。同镜光影稳定就不重复。
- 切镜不移动太阳、窗户、灯和火：新机位重新算哪一面亮，不能照抄"左侧受光"。反打后写"人物改为左后侧轮廓受光，台阶投影和远山空气透视保持同一方向"。
- 按景别取舍，不铺整套灯光：逆光近景一句够用；侧光、低调光、移动光源、反光材质、多镜同一空间、上一次失败才多写。
- 不为"清晰可读"无依据照亮整个主体，保留要求的暗部和反光强弱。
四个示范句：
- 站台顶灯从人物右上方落下，暖光同时照亮面部、伞面和湿地反光，脚下接触影朝左后方，远处冷雨雾降低对比。
- 法术光球是当前主光源，青光先照亮施术手与近侧面部，再扫过石地和浮尘；背景仍保持低曝光。
- 夕阳世界方位不变；切到反打后人物改为左后侧轮廓受光，台阶投影和远山空气透视保持同一方向。
- 侧后方天光勾亮白猿毛发外缘与肩甲，朝向镜头的脸和胸膛仍暗于天空；屋面积雪的弱反光托出嘴角与下颌；脚掌和棍底的接触影贴着瓦面。

## 7 失败修复表

| 成片现象 | 原因 | 最小修法 |
|---|---|---|
| 人物像贴上去的 | 参考图自带的光被保留，或没有共享的受光链 | 让场景做光的主人；写主体重打光 + 接触影 + 纵深响应 |
| 脚飘、没重量 | 缺接触影或地面响应 | 加一句方向一致的接触影和地面反光 |
| 切镜后脸从错的一边亮 | 照抄了画面左右而不是世界光源 | 保留光源世界方位，重算相机看到的亮面 |
| 特效像贴纸 | 发光没有交互光和曝光后果 | 按因果顺序接到最近的主体、材质、空气 |
| 人物和背景两个色彩世界 | 曝光、色温、黑位或空气衰减不统一 | 写一句两者共用的曝光与色温关系和纵深衰减 |
| 光向对了但画面平 | 没有前后景衰减、遮挡、雾、反射纵深或曝光分离 | 加一个现有的光影纵深载体 |

只修第一个断掉的因果环节；不加画质词，不列一堆合成术语。
