# 打斗：攻防、接触、主动权、状态接力

> 用于路由"打斗/特效设计"和执行清单第 ⑤ 步（导演提案）、第 ⑦ 步（成文）；有真实攻击与回应的近身、兵器、追击、法术交换必读。
> 读完必须产出：每个节拍的内部设计（谁发起、路径、触点、接触状态、双方反作用、位移、主动权、终态）；成文时每拍仍只写三样：镜头、画框、主事（发起 → 接触 → 结果）与终态。决定性接触就是本镜关键事件，放在看得见、有光的位置；跨镜的继承状态写成现状句。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。词条查 `../lexicon/action-terms.md`；运镜模式 M01 到 M10 查 `../lexicon/camera-terms.md`；形态色系查 `../lexicon/light-material-terms.md`。

## 0 先分类

- **纯特效**：烟雾、流水、能量、稳定持续效果，没有对手回应 → 走 `vfx.md`，不造攻防节拍。
- **真实攻防**：价值来自身体、兵器、距离、决策，允许零特效；关掉粒子、闪光、震屏后仍能读懂谁攻击、谁回应、谁得到结果。
- **混合打斗**：先完成攻防链，再把特效挂到可见的力量来源、运动路线或关键触点上；高强度交锋可以连续强烈，不把"大效果只留终结技"当默认。
- **招式奇观**：技术显形、规模、环境后果为主，没有对手回应时用"蓄力 → 爆发 → 余波"，不强造攻防。这个弧线只属于奇观，不套在每一拳、每一挡、每一次反转上。

官方评论区已知：打斗默认容易生成"你砍一刀我砍一刀"，缺高燃。高燃 = 可读的威胁 + 速度反差 + 接触后果 + 主动权变化。

## 1 根因表：弱打斗不靠加"激烈、震撼"

| 成片现象 | 根因 | 诱人但错的修法 | 结构修法 |
|---|---|---|---|
| 动作很多但不紧张 | 没有战术目标和主动权变化 | 加"激烈、快速、燃" | 定义双方即时目标和主动权曲线 |
| 拳脚像隔空比划 | 没有路径、触点和接触结果 | 加火花、震屏、慢动作 | 写清攻击路径、触点、支撑和双方反作用 |
| 人物位置漂移或穿插 | 起始几何和终态没锁 | 重复人物外观 | 锁左右、前后、距离、朝向、行动轴和结束位移 |
| 全程快但没有重量 | 没有速度差和恢复成本 | 更快剪辑、更多模糊 | 战术停顿（对峙本身就是戏时）→ 突然加速 → 接触强调 → 后果停留 |
| 特效很大但看不清谁赢 | 特效抢占动作层级 | 再加颜色和爆炸 | 先完成攻防链，特效只证明触点、力量或阵营 |
| 运镜很炫但肢体失真 | 动作与摄影同时过载 | 加更多机位术语 | 先简化为有可见位移的跟随或平移，核对动作与摄影关系；固定仅依用户明确要求（含用户确认作者提议）或实际保护范围，不默认追加生成试验 |

## 2 多节拍先讲白话故事

只有在设计或重写多节拍打斗、升级、反转、结尾时做；单一节拍、纯力学问题不做。用普通中文两到四段回答七问：① 双方现在各想达到什么；② 什么具体优势或限制让开局困难；③ 第一次有意义的交换改变了什么；④ 危险如何升级而不是只加攻击；⑤ 哪个可见动作转移或争夺主动权；⑥ 要让观众以为要赢，什么证据让他们信，什么已可见的事实让反转成立；⑦ 结尾是分出胜负、暴露代价、分开双方还是揭示新威胁。
每段至少推进一个可见状态：距离、姿态、朝向、高度、位置、兵器关系、行动自由、能力阶段或主动权。删掉把一切状态退回原点又不揭示战术、不付代价的交换。
升级靠改变问题，不靠形容词：距离、角度、高度、支撑、恢复时间、路线、对现有兵器或能力的控制逐步累积。反转必须用先前可见、说过或自然铺垫的事实：揭示之前先给一个独立线索（保护它、反复调整它、舍不得用它、身上带着休眠的征兆）。找不到可用的伏笔就停下来问反转来源，不发明。悬念结尾停在新威胁可读的地方（激活、入场、占据路线、瞄准、射程变化），不继续打。
地形道具只在改变路线、支撑、视线、距离、落点、杠杆、接触受体或恢复选项时用；用完保留位置与状态，不瞬移，不为了显得激烈而毁掉。
打法差异：每方落到可见打法（偏好距离、惯用进攻、挡停或偏转或闪避的方式、恢复代价、可利用的空隙）；元素颜色不同不等于打法不同。反制尽量利用上一招留下的姿势、惯性、路径、支撑或环境条件，让观众看见机会从哪来。例：火方用持续喷流逼退对手，持招限制转身；冰方借后撤落脚沿地面送出冰脊，逼火方中断喷流横移。

## 3 起始几何

第一次交换前写清：左右、前后深度、距离、高度、朝向、支撑面、行动轴。命名一个可见锚（门框、柱子、栏杆、屋脊、地面标记、兵器线），位置要持续时靠它。接触前后保持画面方向，除非相机可见地跨轴或人物可见地交叉。交叉时写谁从前面过、谁从后面过、各自结束在哪、主动权是否变。
一对多：每条威胁路线和攻击归属靠时机、纵深或遮挡读得清；同时进攻允许，但关系必须能看见；只有具体冲突或精度要求才改顺序进攻或用动作参考，不因人数自动降级。
"画面左侧"不够，写深度和遮挡。

## 4 一个节拍 = 一次因果交换，不是拳数

一个节拍只有一个战术意图和一个结果，短连击可以算一个节拍。每个节拍答清：顺序 → 即时战术问题 → 起始几何 → 谁在逼谁反应 → 发起方的准备、肢体或兵器、路线 → 回应（格挡、闪避、吸收、偏转、反击、中断、擒抱、失败）→ 接触状态（命中、格挡、擦过、擦身、缠锁、释放、无接触）→ 触点与时刻 → 力链（地面支撑或既定飞行动量，经躯干肢体兵器传递）→ 双方反作用与位移 → 主动权保持、争夺或反转的可见原因 → 终态（位置、姿态、接触或效果状态、恢复成本、残余运动）。写不清就还不能上特效和成文。
宏观节奏 压 → 抢 → 碰 → 翻 → 留：压 = 用距离、体量、兵器长度、地形、攻击线、伤势或逃生空间制造可读劣势；抢 = 一方先出手，写来源肢体或兵器、路线、目标；碰 = 解决一个明确关系；翻 = 回应必须改变可见的东西（距离、姿态、朝向、兵器位置、行动自由、主动权）；留 = 让代价或结果停留到下一状态成立（踉跄、倒滑、压制、护架破、失兵器、拉开距离、未解的缠锁、重新站稳）。这是诊断模型，不是五镜模板。
主动权曲线例："长枪手以距离压制 → 剑客被迫退至栏杆 → 剑客借栏杆偏开枪尖 → 剑客贴身夺回主动权"。每次变化都要有可见动作，不写"双方激烈交锋""局势突然逆转"。
目标、拦截与触点分开：攻击者想命中的身体目标、防守兵器进入攻击路线的位置、最终接触的位置。"拳攻向胸口，防守者抬棍迎入拳路，在胸前以棍身截住拳面，拳势受阻后收回。" 不把攻击目标改成棍子，不把身体受击写成成功格挡。"轻松防守" = 调整经济、支撑稳定、恢复迅速，仍有迎截与受力，不是兵器不动。攻守转换利用前一招留下的偏转、撤压、失衡或空隙，不例行回到待机姿势。强弱差要有动作结果：强者小幅调整即控制局面，弱者全身抵挡仍被震退。
棍法按立圆、平圆、直线、短促抖弹、下劈区分，耍棍收束到明确攻击线；地面、借力、下落、授权悬浮分别指定力源，空中不写踩地发力，收拢展开只改转速不产生平移冲量。

## 5 接触台账（每个决定性接触）

```
发力者与来源：谁，用哪个肢体或兵器
路径：从哪里沿什么方向到哪里
接触状态：命中 / 格挡 / 擦过 / 闪避 / 偏转 / 缠锁 / 中断
触点：身体部位、兵器部位或现有环境表面
支撑与重心：地面支撑、借力点或既定飞行阶段，稳住还是失衡
力的传递：从支撑或动量，经躯干、肢体或兵器到对方
攻击者反作用：随动、回弹、收势或失衡
承受者反作用：压缩、扭转、滑移、后退、腾空或稳住
位移：方向、相对尺度、新的双方距离
恢复成本：重新站稳、回防、起身、抽出兵器或挣脱
```
台账和力链只用于内部设计；成文写可见结果（被撞得连退、棍身弯下去又弹回、脚下倒滑），不写力从哪经哪传到哪。
一个身体或兵器反作用必写；环境受体可选，且必须已存在或已授权，不要求裂地。用户 2026-09-13 反馈：震退、倒滑、崩棍这类力度词显著改善观感。

## 6 速度、重量与力量呈现

张力来自反差，不是恒定速度：战术停顿（对峙、观察本身就是戏时才写；攻击前的蓄力不单独占时间，写成出手那一拍的起势）→ 突然加速 → 可读的接触或擦身 → 决定性瞬间的短暂停留、压缩或变速（指时间上的慢放或压缩；镜头不在它之前先停下等待，writing-rules 第 29 条） → 后果与恢复 → 再次进攻或定格。慢动作、白闪、震屏、速度线、音效是呈现工具，补不了缺失的接触几何。
关键攻击按"蓄势 → 释放 → 透视强化 → 接触或交错 → 后果"设计（`camera.md` 第 8 节）；普通交手与安静段落保留各自节奏。
**高速连续镜头里不让主体或相机回到中性状态**：相机"甩到位归中"和主体"压缩蓄力"都是低运动姿态，两句连写等于在一镜到底的中间设计出一个停顿。转换处写成继承余势（一扣即蹬、借变向的余势离壁、前冲没停就接上下一个动作）；蓄力必须有就让它与位移同时发生，不单独占一段时间。上面那条"战术停顿 → 突然加速"的反差属于有起止的单次攻击，不要套到连续运动的每个转换点上。

## 7 机位按"必须看见的证据"选

| 观看任务 | 候选构图 | 失效判断 |
|---|---|---|
| 看清直线追击的距离与逼近 | 有纵深锚的斜侧视角或侧跟 | 摄影与目标等速会抹平逼近，检查相对距离和背景视差 |
| 看清格挡类型与受力 | 同时展示攻击线路、触面、防守者支撑的侧斜机位 | 过近只剩发光触点，过正线路重叠 |
| 看清命中后果 | 跟随受击者的肩背、躯干与脚下支撑，或双人同框 | 镜头只追粒子丢掉身体恢复不算力量可见 |
| 看清反击如何利用上一招 | 保留前一招的恢复姿态或路径，再让反制进入已知空隙 | 过早切走像凭空发生 |
| 展示规模与主形 | 保留来源或尺度锚，沿传播方向揭示受影响区域 | 主形与面部细节竞争，分时呈现 |

力量不是地裂数量。接触镜要展示触点、支撑、重心或肩背反应；正面挡停、吸收、偏转各有不同后果。高张力运镜 M01 到 M10 和广角尺度波见 `camera.md` 第 8 节；相机路径要有载体、可见幅度和终点锚，缺项先补设计，不能用固定机位绕过；固定仅依用户明确要求（含用户确认作者提议）或实际保护范围；交点解开后不再环绕虚构的点。

## 8 状态接力：下一镜开场 = 上一镜终态

只追踪影响下一动作、归属、空间、支撑或可见残留的事实，写成现状句，不写"保持一致"。六类：
- **身体**：姿态、朝向、护架、承重肢、占用肢、身体接触（格挡、擒抱、缠锁、压制在可见释放前一直有效）。
- **运动**：世界矢量与画面矢量分开；阶段 = 准备、加速、接触、回弹、恢复、静止；镜内切入继承当前阶段不重启。空中完整链：支撑 → 蹬离与最后接触 → 上升 → 顶点 → 下落或出招 → 接触 → 落地或继续下落 → 恢复；空中不获得新冲量、不悬停、不二次起跳（除非有授权能力）；承诺了接触和落地就都要到达终态，不能用悬停姿势代替。
- **世界**：命名区域、深度、高度、支撑面、与锚点距离、允许路线；环绕、特写、前景擦过可以短暂遮住锚点，结束时必须重新给出足够证据证明没有瞬移。
- **兵器道具**：主人、握法、朝向、接触状态、完损、终点位置。碰到、挡住、压住不等于拥有；转移需要旧主可见释放 + 新主可见获取 + 新的稳定握持。长兵器分开核对握点、棍轴、运动方向、受力方向："向下砸"不等于"棍身竖直"；关系改变要有转腕、换握、解脱这类可读动作。
- **形态特效**：主人、来源附着点、阶段、覆盖边界、传播前沿、拓扑连接、路线、结果、遮挡、残留与退出；分阶段变身从上一覆盖继续，不回到普通身体、不跳到全覆盖、不换主人、不补全没要求的生物；负拓扑锁（无头、无闭合袖、无完整龙）贯穿后续阶段；效果在可见分离前一直连着来源，结束要有消散、分离、吸收、撞击残留。
- **对手与环境**：每个对手的位置、朝向、姿态、距离、当前可动性、恢复状态、威胁路线；不在当前接触里的人不消失、不挤到同一个中心；环境只继承授权的损坏、碎片方向、烟尘、被移动的道具、水火能量残留，不无因修复或新增。
易错起止：消失 = 开镜本体清楚在位 → 离开 → 原位空出或只余衰减残影；显形 = 起初为空 → 本体出现；分别写存在顺序和特效方向，不用一个"闪现"代替两者，残影不是分身。背后过肩按 `staging.md` 第 4 节。反应、面部、武器特写继承正在发生的动作，下一镜进入新阶段，不倒回重新抬棍。变身保留初态、前沿、覆盖、终态，观众看清变化的时间算进容量。
需要可见桥接的转变：起跳、失去或恢复支撑、落地；兵器释放、转移、掉落、断裂、拾回、换握；跨到新屋顶、门口、房间、高度带或障碍另一侧；擒抱锁定或释放；变身开始、覆盖增长、拓扑改变、回退；特效分离、撞击、消散、换主人；环境破坏、道具位移、天气变化。桥接放在出镜、入镜或专门的连接镜；硬切只在授权了时空跳跃并重新建立地点时省略。
相机与状态分开：环绕或跨轴只改视点，位置、朝向、接触、支撑不变；冲刺、坠落、跃起、后坐、击退改变物理位置，要靠视差、锚点、支撑或落地证明；遮挡不能悄悄改写状态；裁掉兵器主人、支撑脚或对手不免除这些状态，控制下一动作时要先重建。

## 9 拆分与失败恢复

拆分只在具体冲突时，不因"风险多、长镜头、运镜野心"自动拆：多人同时进攻、精确兵器接触 + 大幅运镜、交叉走位 + 跨轴、空中追击 + 擒抱 + 撞击、换地点或换目标、复合运镜遮住决定性接触、起止边界写不清。在因果边界拆：格挡后、起跳、落地、压制、分开、失兵器、主动权反转；上一段终态传给下一段。用户锁定一镜到底就保留，真有冲突再问。
| 失败 | 修法 |
|---|---|
| 身份或参考泄漏 | 收窄素材职责，恢复身份锁 |
| 接触失败 | 简化到一次攻击回应，或用动作、姿势参考 |
| 几何漂移 | 恢复可见锚，减少交叉，在节拍处拆 |
| 身体与相机互相干扰 | 简化相机路径并保留可见运动，核对动作可读性；固定仅依用户明确要求（含用户确认作者提议）或实际保护范围 |
| 特效遮住接触 | 调覆盖、深度、构图或时序露出接触，只在必要处减透明度尺度时长 |
| 后果错误 | 重述终态边界，删掉无授权的破坏 |

## 10 检查

- 每个节拍答得出：谁发起、怎么接触、谁改变了局面。
- 每个决定性接触有一个身体或兵器反作用；没有无来源的裂地、冲击波、建筑破坏。
- 起始几何有锚；交叉写了前后和终点；一对多写了归属。
- 每个切点：开场 = 上一镜终态；兵器主人、支撑、空中阶段、特效连接没有无因变化。
- 相机路径有载体和终点锚；特效没有遮住攻击归属、回应和决定性接触。
- 提示词里没有 FightBeat、接触台账、行动轴这类内部词。
