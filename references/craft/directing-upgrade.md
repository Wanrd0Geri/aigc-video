# 导演提案：扩展创作上限

> 用于执行清单第 ⑤ 步。写新提示词时必做，不等用户说"帅一点""电影感"才做。
> 读完必须产出：锁定项之外真正能提升观感的升级点（有几个写几个，成熟方案可以为零，不硬凑），各一句画面效果 + 取舍 + 推荐；意图清楚时默认采用推荐项，写进表头"升级"行。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。

## 1 为什么有这一步

用户的想法是起点，不一定是最好的画面。有权设计不等于可以交付惯性方案：固定中景正面、居中、泛泛修饰。从用户希望观众获得的感受出发，在未锁定范围内选择互相配合的构图、摄影、表演、节奏、材质、光影和特效，把知识变成具体可见关系。安静、日常、产品、环境、战斗都适用；居中与世界静止可以成立；摄影仍执行本用户默认有可见运动的偏好，固定须有用户要求或既有保护范围，不为运动添加奇观或破坏。
先自检再交付：每镜或紧密镜头组能说出"为什么这样拍、观众会感到什么"，不能只靠"清楚、连续、合理"过关。能指出机制、幅度、对比是否足以支撑目标观感；出现概念词或轻微动作不算兑现。

## 2 提案怎么写

意图清楚：直接给推荐方案并采用，在表头"升级"行写"原 = … → 升 = …（可撤回）"。
有会改变核心观感的歧义（压迫感还是孤独感、人慢还是镜头慢还是慢放）：给少量以可见效果描述的方向，说明各自会看到什么、主要取舍，推荐一种，问用户想要的画面感受，不考术语。格式：
```
我的理解：<引用依据，说当前读法>
不确定点：<什么会改变结果>
方向 A：<画面效果一句>，<取舍>
方向 B：<画面效果一句>，<取舍>
我的建议：<选哪个，为什么>
```
示例："第 3 镜无法判断你想突出压迫感还是孤独感。近处遮挡与逼近构图会更压迫；保留远景空白会更孤独。按前面的追击情节，我推荐前者。" / "这里的'梦幻'可以是柔和的逆光尘粒，也可以是空间逐渐失真；前者温柔可信，后者更超现实，按重逢主题我推荐前者。"
只在真实歧义时问，不制造问题；不把同义措辞、标题位置这类表现差异当选项；问题合并到一轮。

## 3 边界

- 可自主：未锁定的镜头数、动作分配、跟拍路线、景别、粒子运动、材质、局部光照、题材配方内的实现方式。
- 需讨论：上下文支持多个互不兼容的意图，且选择会改变故事意义、人物关系、胜负结局或核心视觉机制，用户又没委托。
- 不能补成事实：不可读的参考、缺失的身份或项目事实、冲突的时长与对白。问必要缺口，继续无关工作。
- 用户明确的场景、构图、机位、人物、动作、风格、时长、素材职责按范围锁定，不为"更帅"改动；未指定不等于某种意图；补充设计不冒充源事实。
- 升级不加剧情、人物、道具、闪回、符号、反转。

## 4 按观众感受选手法

| 想让观众感到 | 可选组合（各一句可见效果） |
|---|---|
| 压迫、威胁 | 低角度 + 前景巨大阴影压向人物；正对镜头缓步走近；负空间随威胁逼近收窄；画面严格对称人物在中轴线；顶光一半脸在浓影里 |
| 孤独、渺小 | 远景，人物只占画面下方六分之一，上方是空洞的天空；周围三米内空无一人，只有影子；大面积冷绿中一点暗红；渺小背影对着巨大落地窗 |
| 亲密、信任 | 过肩跟拍，跟在人物后方一米越过肩膀看前方；两人距离从一臂缩到不到一臂；焦点从递出的手转到接的人的眼睛；柔光无阴影边缘 |
| 紧张、悬念 | 镜头快速推向人脸停在眼睛特写，背景迅速抽离；手指敲桌面频率越来越快；灯管频闪、墙上影子先变形；只写声音的后果（杯子晃、液面涟漪） |
| 宏大、震撼 | 镜头从高空俯冲向下穿过云层；摄影机缓慢上升人物越来越小；广角低角度仰拍加对称构图；正对建筑立面的大全景 |
| 梦幻、超现实 | 重力减弱、动作漂浮、背景缓慢扭曲；镜中人物慢半秒；倒影比实体清晰；雨滴悬浮只有人物在动；柔焦橘色光晕 |
| 时间流逝 | 影子从脚底拉长、天色由橙转蓝；延时里光影快速移动而摇椅始终静止 |
| 高级、克制 | 逆光剪影只留一道金线；微距细微运动；一虚一实；柔光低反差莫兰迪；三分留白；一个风格词统领 |
| 力量、重量 | 落地下蹲缓冲灰尘扬起；肌肉绷紧青筋延伸；接触变形短暂放慢后骤然恢复高速；受击者连退鞋底刮出破痕 |
| 温柔、治愈 | 阴天散射光无阴影边缘；呼吸凝成白雾鼻尖发红；窗口柔光；日系低饱和 |
| 恐怖、不安 | 怪物出现前环境先反应；影子比人大且扭曲；大雾能见度不到十米；镜头以人物视角旋转地平线不稳 |
| 结尾余味 | 镜头缓缓拉远人物隐入黑暗；爆炸后烟尘沉降碎片弹跳后静止；空门口停留、脚步声远去 |

## 5 目标明确时的方案示例（不是审美高低表）

| 待明确的方案 | 特定目标下可选的细化 |
|---|---|
| 正面中景人物说话，希望增加观看关系 | 可缓推拉近距离；需要侧面空间或遮挡时再选择门框前景与侧光，不默认叠加。用户明确固定时保留固定，靠表演与构图完成 |
| 镜头靠近 | 从远景推近到特写，先快后慢停在人物侧面 |
| 很有压迫感 | 镜头低角度仰拍，前景有巨大阴影压向人物 |
| 一个人很孤独 | 远景，人物只占画面下方六分之一，上方是巨大空洞的天空 |
| 电影感打光 | 黄昏的暖金色逆光从人物背后斜射，发丝和肩膀镀上发光边缘，正面被环境散射的柔光补亮 |
| 暖色调 | 整个场景被一盏老式路灯的暖黄光染色，暗部偏青绿 |
| 她很难过 | 嘴角轻微下拉，眉头向内聚拢，下眼睑微微收紧，眼眶泛红但泪没落下 |
| 两个人在对峙 | 两人相隔一臂对视，左边的人肩膀向右转，剑尖微微颤动 |
| 下雨了 | 雨丝细密像雾一样悬浮，地面薄薄积水倒映着灯光，雨滴打在檐下石阶上反弹起水花 |
| 切换到下一个场景 | 镜头快速甩向天空，再落回地面人物；或人物推开一扇门，门后是完全不同的空间 |
| 结束 | 镜头缓缓拉远，人物逐渐隐入黑暗，只剩呼吸声 |

## 6 按观看目的选方案

| 观看目的 | 方案句 |
|---|---|
| 揭示被遮住的信息 | 摄影机沿桌沿向右滑动，前景杯沿移出视线，露出其后的信封，最后停在仍按住信封的手上 |
| 持续逼近的压迫 | 从人物正前三分之二侧面缓慢推近，他保持右侧位置，左侧空出的走廊逐渐缩窄，停在脸与抬起的手仍同框的近景 |
| 追击速度与路线 | 摄影机在奔跑者左侧并行跟拍，让其保持画面右半；近处桥柱迅速掠过，远岸移动缓慢，抵达桥头时随减速落定 |
| 双人攻防接触 | 稳定的斜侧中全景保留两人的支撑脚和兵器交会处，沿进攻路线短距侧移，挡开后才跟进双方拉开的距离 |
| 察觉或突发威胁 | 沿人物听声转向的方向快速摇到门口，模糊在途中结束，来者踏入门框时画面已清晰 |
| 招式或建筑尺度 | 从平台边缘人物的中景拉远并缓慢升高，先露出平台断面，再露出下方谷地，人物留在画面下方作尺度参照 |
| 失衡或主观冲击 | 镜头后撤同时缓慢变长焦，人物大小近似不变，身后通道被视觉压紧 |
| 安静的关系变化 | 双人中景缓慢横移，长椅边缘与背景产生可辨视差，两人分处长椅两端；递出的杯子停在中间空隙，焦点从递杯的手转到接杯者抬起的眼睛 |
| 产品表面与轮廓 | 沿瓶身弧面短距侧滑，保持标签在清晰面，侧上方条形灯的窄高光沿曲面移动 |
| 力量释放后的结果 | 跟随碎块的落向短促下摇，停在被压弯后回弹的栏杆与人物重新站稳的脚上 |

风格锚点（可选，放在空间、光学、动作、光线之后，一个就够）：卢贝兹基自然光手持、迪金斯克制剪影、卡隆亲密广角、伯格曼侧脸表演、雷弗恩慢步极简。

## 7 检查

- 升级只动了锁定项之外的字段。
- 升级的机制落到了最终句子里：属于关键事件的落到那一拍，装饰性的（次要粒子、地面响应）落成全局一句（内部选了橙色包络、粒子衰减、地面响应，最终不能只剩"金色能量射线，电影级特效"）。
- 每镜说得出"为什么这样拍、观众会感到什么"。
- 没有为了不一样而加运动、奇观、破坏；安静和克制按自己的目标判断。
