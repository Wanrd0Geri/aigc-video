# 场景、氛围与风格

> 用于执行清单第 ⑤ 步（导演提案）与第 ⑦ 步（成文）；环境空镜、室内外场景、风格设定、成品 CG 细致度必读。
> 读完必须产出：全局设定里的"基础环境与质感 + 视觉风格"两句；每镜按辨识、空间与情绪作用选择必要视觉符号（不设数量配额）；风格签名落到具体表面与行为。
> 经验采用与优先级见 [../lessons/README.md](../lessons/README.md)：分清"试过的"和"没试过的"；没试过的照常可用但不冒称已验证，专业方案按当前任务适配性判断。

## 1 三层与五维

骨架 = 景别、镜头高度、光从哪来、人物位置；血肉 = 衣服材质、皮肤质感、背景道具；灵魂 = 情绪氛围。多数人只写骨架"一个人站在房间里"，少数加血肉"穿白色衬衫，阳光从窗户照进来"，几乎没人写灵魂"午后的倦怠感弥漫，空气中浮动着微尘，他望向窗外，眼神里有说不清的怅惘"。Seedance 2.5 对氛围词和情绪词理解力强，但灵魂层要跟在可见句后面，不能单独承担。
五维公式：[景别 + 焦段] + [主体 + 位置 + 动态] + [光线 + 色彩] + [氛围 + 情绪] + [画质词]。"中近景、50mm 定焦，一位银发老人在画面右侧三分之一处缓缓点燃烟斗，火柴的暖光映亮他半张脸，深蓝色暮光从背后窗户渗入，空气中飘着稀薄的烟雾，安静、孤寂、仪式感，电影颗粒感、浅景深。" 不必每次写满，但要知道在哪一维取舍；新手最容易漏氛围情绪。

## 2 室内：氛围锚点代替家具清单

反例：沙发、茶几、电视、书架、落地灯全列一遍，模型全摆上但毫无灵魂。正例："午后的书房，阳光透过百叶窗在木地板上切出一道道光栅，空气中悬浮着细小的灰尘，一把旧皮椅沉默地蹲在角落。" 没写书架，所有人都知道是书房。
选择真正有辨识与叙事作用的视觉符号，用光线和质感串起；3到4个只是示例数量，不是最低数或上限。不凑物件，也不因求少删掉独立控制。
生活气与年代：陈旧痕迹比干净可信，"墙角有脱落的墙皮，桌上杯底留了一圈茶渍"；道具要有使用痕迹，"木桌边缘有刀痕，扶手被磨得发亮"；年代藏在边缘和角落，"海报边缘卷曲发黄，角落有霉斑"。Seedance 不懂历史，写时代最独特的三个视觉符号：19 世纪伦敦 = 煤气灯在石墙投下摇晃光影、马车轮碾过鹅卵石溅起水花、高顶礼帽绅士裹黑斗篷；八十年代中国 = 绿色吊扇吱呀转动、褪色港星海报、燕舞牌双卡录音机。

## 3 室外：先锁时间和天气

第一句锁时间与天气："初冬清晨六点""盛夏午后两点""深秋傍晚五点，刚下过雨"，色温、天色、空气透明度就有了。然后近中远三层："近处沾着露水的草叶，中景一片白桦林，远景的山脉在晨雾中若隐若现。" 有真实驱动且能帮助表达时再写动态元素，例如："风穿过树林，落叶在地面打旋，远处湖面被微风吹起细密的波纹。"
天空："云层有明确体积感，底部被夕阳染成紫色。" 天气是情绪外化：雨忧郁沉思、雪宁静浪漫、雾神秘不安、烈日焦灼压抑；细雨、暴雨、毛毛雨的通透度和雨滴大小密度不同。天气×情绪联动："窗外的暴雨和他内心的焦灼形成对照，雨水顺着玻璃扭曲了窗外的街景，像他混乱的思绪。"

## 4 科幻、奇幻、怪物：翻译成光影 + 粒子 + 质感

Seedance 不是物理引擎，不理解反重力、黑洞、时间扭曲，只理解光影、材质、空间关系。反重力飞行 → "霓虹灯的光污染映在湿漉漉的沥青路面上，巨型全息广告的光线穿过浓雾，飞行器的尾灯在雨夜中拖出长长的光轨"。魔法能量场 → "半透明的蓝色光膜像水波一样在城堡表面流动，空气中有发光的粒子缓慢飘浮"。
科技感不是加蓝光，是缺陷："全息界面有轻微扫描线抖动，边缘有像素化失真""飞行器表面有划痕和泥点"。怪物写运动规律和材质："皮肤像融化的蜡，呼吸时身体起伏不规则"；怪物出现前先写环境反应："灯管开始频闪，墙上的影子先变形"。裂隙类形态加"不出现眼球、瞳孔形态"（竖缝加放射纹易被读成眼睛）。

## 5 虚实与层次

前景虚化物体、中景主体、背景虚化环境，并有遮挡关系；进阶用光做层次（近处台灯暖光、中景半暗、远处黑暗）。虚掉的部分比清楚的部分更有力："镜头聚焦在一只沾满泥土的手上，背景的一切被柔和地融化在黄昏的橘色光晕里，只有温暖的光和朦胧的色块。" 记忆、梦境、情绪化内容尤其好用；模糊不是缺点，是视觉语言。

## 6 风格：一个词统领，签名落到表面

风格有清楚的主次，多个风格词只在承担独立且兼容的控制时保留；其余用具体描述补充，删掉空泛同义堆叠，不按词数定上限。可选：意大利新现实主义、新浪潮质感、韦斯·安德森、印象派油画、浮世绘扁平化、水墨留白晕染、马格南纪实、蜷川实花艳丽饱和。
风格签名要可观察：水墨保留笔触与留白（"浓墨沿球体曲面聚散，转动时灰白受光面显出体积，边缘散出干笔状细丝"），粘土保留浅浅的工具痕和宽柔高光，二维手绘保留线条起伏与纸面颗粒。参考图写实而提示词没风格词会漂成真人：写"3D 国风漫画 CG 风格"或"2D 日漫风格"，更精准时先把参考图转成目标风格。
成品 CG 的细致度五条（默认做到，不等用户说"别吝啬描述词"）：
1. 明确渲染方向：写实材质与风格化角色结合之类的表面、体积、光学处理，不只留"三维 CG 动画"；不加"高预算""院线级"标签。
2. 材质写出区别与响应：毛束密度与根部阴影、布料厚度与滞后褶动、金属弧面上的高光移动；保留角色风格化程度，不机械加毛孔、磨损。
3. 灯光与摄影写出画面结果：亮暗过渡、高光收束、暗部层次、间接光；景深、体积、运动模糊怎样保住主体和关键接点。渲染术语只配合可见结果。
4. 运动与特效写出材质行为：重量、惯性、毛发布料跟随；法术或破坏补空间厚度、遮挡、发光受体、形变与分阶段碎裂消散。
5. 交付核对：最终正文里渲染方向、材质差异、光影层次、光学读点、运动行为都还在；压缩媒介名称时不连带删掉这些控制。
覆盖表（适用时才写，不改景别去凑）：整片渲染 → 风格段（"电影级三维 CG 动画质感，冷蓝灰环境中保留肤色与衣料的细微色差，亮部柔和收束，帽檐和衣褶暗部保留层次"）；中近景可见的毛发 → 主体段写构造、镜内写受光运动；近景可见的皮肤 → 主体段写质感，镜内写受光；衣物道具环境表面 → 主体或场景段；物理光与纵深 → 场景写光源，镜内写受光；授权的动作 → 所属镜头写重量与跟随。
四个 owner：主体段放身份稳定的表面（脸、发、眼、服装、持物材质）；场景段放环境表面、植被、稳定光源、空气、纵深；风格段放媒介、渲染语言、色调、共享的材质行为；镜头段放当前裁切可见的光学、焦平面、曝光分离、局部受光与材料响应。远景不写虹膜湿润和唇纹；不发明痣、刺绣、天气、雾、新灯、秃头上的发丝。

## 7 视觉方案先于镜头

从观众最该记住的关系或动作出发，形成一个连贯方案，再排镜头：① 核心画面与变化（允许静止、微小变化、奇观展示，不强制冲突反转）；② 主体与场景（可辨轮廓、材质、空间尺度、动线、主光方向）；③ 力量与介质（法术先定来源、尺度、路线、覆盖、结果，再细粒子）；④ 观看方式（围绕当前信息选景别、观看侧、深度、遮挡、运镜）；⑤ 节奏与落点（镜头数与长短来自动作依赖和观看时间；结尾一个实际到达的状态）。
安静情绪片靠距离与光线变化成立；产品靠轮廓、表面和功能成立；不都变成魔法、烟雾与环绕。内部选了橙色包络、粒子衰减、地面响应，最终句子不能只剩"金色能量射线，电影级特效"。

## 8 叙事结构与声音暗示

三幕：建立 → 冲突 → 留白。30 秒例：黄昏的书房里老人安静地翻旧相册（建立）→ 翻到某页突然停住，手指抚过褪色的照片，眼眶微微泛红（冲突）→ 合上相册望向窗外渐暗的天空，画面缓慢拉远，书房的光融入窗外暮色（留白）。结尾给退出动作："镜头缓缓拉远，人物逐渐隐入黑暗。"
视觉通感：写声音的后果而不是声音本身，"他重重拍了一下桌子，桌上的咖啡杯剧烈晃动，液面泛起激烈的涟漪"；情绪氛围也可以从听觉翻译成视觉："空气里像有静电，细微尘埃悬浮不动。" 2.5 能出声音，但这套写法仍能让画面更有质感。

## 9 修复表

| 现象 | 修法 |
|---|---|
| 提示词里堆了好几个空画质词 | 保留用户锁定的措辞；其余合并成一个，把支持的可见事实写出来，不支持的删 |
| 同一材质、光或光学在多处重复 | 稳定构造和光源写一次；每镜只保留当前受光和裁切光学 |
| 细节超出裁切 | 从该镜删掉，或换成一个存在的可见受体 |
| 风格串味（写实人像出现在水墨任务） | 删掉漏进来的风格，恢复当前风格 |
| 结果语义对但质量差 | 提示词不动，走 `../review/diagnose.md`；不加通用画质或否定尾巴 |
